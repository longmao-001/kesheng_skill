# 手把手 AI 视频制作流程（Production Workflow）

> 面向现阶段 AI 视频工作台的端到端实操指南。两条主路径：**LibTV 节点画布**（剧本→分镜→视频一条画布跑完）和**单镜工具**（即梦/可灵/Vidu 等逐镜生成）。平台 UI 迭代很快，具体按钮位置以用户当前界面为准；流程骨架不变。

## 第 0 步：需求简报

用 `templates/brief.md` 向用户调研：话题、用途、受众、平台、时长、风格、素材、交付物。信息不全先问，不许猜。

## 第 1 步：科学理解（科学顾问主导）

执行 7 步深度理解法（`agents/scientist.md`），输出理解报告，达到 L2 以上才能继续。向用户索取论文/PPT/数据图表作为事实依据；先查 `kb/` 科学知识图谱（入口 `kb/index.md`），已有概念笔记直接复用。

**拿到 PDF/PPT 先全量抠图建参考图库**：客户的 PDF/PPT 里藏着产品外观、结构接口、原理示意、应用场景等图片，是全能参考/首帧生成的现成参考资产。开工前用脚本（PyMuPDF `page.get_images` / python-pptx 遍历 shape）把所有图一次性抠出，按"产品外观/结构接口/原理示意/数据图表/应用场景"分类存入项目目录的参考图库，并写一个 README 索引。数据图表只作内容参考、永不出镜；客户敏感页不入库。

**素材收集纪律（图像素材是视频制作的第一资产）**：
1. **全量收集**：客户给的素材一律收下不挑——文档、图片、视频、Logo/VI、实拍、规格书，哪怕暂时用不上
2. **分类入库**：产品外观/结构接口/原理示意/数据图表/应用场景/品牌资产（Logo、VI），写明每张的用途分级：**可直接入镜**（真实素材，信任度最高）/ **参考图**（喂模型做锚定）/ **内容参考**（数据图表，后期重绘，原图不出镜）
3. **充分利用**：分镜时每镜先问"素材库里有没有能用的"——真实素材能入镜的直接入镜（视频片段可剪入），能当参考的喂参考图，别啥都靠 AI 凭空生成
4. **缺素材上网找**：客户没给的（竞品公开图、应用场景氛围图、器件公开照片、文献示意图），上网检索公开素材补库，注明来源；只作参考不直接入镜（版权）
5. **生成资产命名规范**：`项目_镜号_内容_版本`（如 `R2_镜02_出光口特写_首帧.png`、`R2_镜01_开场_定版.mp4`）——生成物一多就乱，名字必须能回答"用在哪一镜、是不是定版"

## 第 2 步：制作方案（全会）

按会议协议产出方案（`templates/proposal.md`）。大项目（>6 分钟或多主题）先用 `templates/breakdown.md` 拆成子项目，逐个立项。

## 第 3 步：分镜表（全会）

视觉导演主导，产出 `templates/storyboard.md`。要点：
- 单镜 3-10 秒；口播稿按镜头切段（约 40 字/5 秒）
- 标记每镜生成路线：文生视频（微观穿越、概念可视化等"不可能机位"）/ 图生视频（精确结构、设备、角色，**默认优先**）
- 标出需要复用的角色/场景/风格元素，交给第 4 步做锚定

## 第 4 步：角色与风格锚定（一致性地基）

1. 有 recurring 角色/主持人/吉祥物：先用文生图生成**三视图**（正/侧/背），作为全片角色基准
2. **产品/关键道具/场景：备多角度示意图**（三视图/剖视/45°/特写）——以官方图或实拍为参考用文生图生成，全能参考类模型吃多角度图，一致性才稳
3. 生成 1-2 张**风格锚图**（定调的关键场景静帧），定死色彩、光影、质感
4. 定下**风格 token 块**：一句全片统一的风格描述（如"冷蓝生物荧光科学可视化风格，体积光，8K 超精细"），之后逐字粘贴进每条 prompt
5. 高频出镜且跨项目复用的角色/风格：可考虑在 LiblibAI 训练 LoRA（见 `playbooks/consistency.md`）

## 第 5 步：逐镜参考包与首帧图（图生视频路线的镜头）

> 全能参考类模型（Seedance 2.x 等）吃的是**参考包**不是单张首帧：一镜可挂多张图（产品外观+三视图+结构+场景），prompt 里写清每张图取什么。首帧只是参考包的一种用法。参考包按"这镜画面需要哪些资产"组装，不用每镜都出新图。

用文生图生成每镜首帧静帧。**生图模型首选 GPT Image 2**（指令遵循强、中文小字渲染好、2K）；备选 Nano Banana 2/Pro、Seedream 4.5（即梦图片，多图一致性最强）、LiblibAI/即梦/可灵图片模式。
- 角色镜：以三视图/参考图为基准生成（各平台的参考图功能，或 LoRA）
- 精确结构镜（蛋白、设备）：首帧图必须科学正确，科学顾问逐张验收
- 需要首尾帧衔接的相邻镜头：下一镜的首帧直接用上一镜的尾帧导出图微调
- **快速通道**：镜头多或想快速 previz 时，用宫格分镜技法一次生成全片九宫格分镜图，整图喂 Seedance 2.x 一次成片，或切开逐格当首帧——见 `playbooks/storyboard-grid.md`

## 第 6 步：逐镜视频生成

### 路径 A：LibTV 节点画布（适合整条片）

LibTV 是 LiblibAI 的视频工作台：无限画布 + 节点流，后端可选 Seedance 2.x / 可灵 / MiniMax 等模型。
1. 新建项目 → 剧本节点：粘贴文稿，让它辅助拆分镜
2. 分镜节点：把第 5 步的首帧图逐镜挂上去（或画布内直接生成）
3. 视频节点：选后端模型，粘贴 prompt 工程师给的逐镜 prompt（`playbooks/platform-prompts.md`）
4. 每镜生成 3-6 个变体（"抽卡"），选最好的一个
5. 复杂构图/多机位需求用"导演台"；有 3D 预演可走 Blender 插件导入
6. 团队版可把分镜表、角色图、风格资产存进共享资产库复用

### 路径 B：单镜工具（即梦/可灵/Vidu/海螺/Runway 等）

逐镜操作，每镜循环：
1. 选模式：有首帧图 → 图生视频（上传首帧）；无 → 文生视频
2. 粘贴该镜 prompt（含风格 token 块）+ 负面 prompt
3. 选时长档（通常 5s/10s）、比例（16:9 横屏 / 9:16 竖屏）
4. 生成 3-6 个变体抽卡，选最优
5. 翻车了按 `playbooks/platform-prompts.md` 的"常见失败→修复表"改 prompt 再来

## 第 7 步：衔接与延长

- **首尾帧衔接**：导出镜头 N 的最后一帧 → 作为镜头 N+1 的首帧，画面无缝延续（可灵首尾帧、即梦智能多帧、Vidu 多图首尾帧都支持）
- **单镜延长**：可灵"视频延长"可多次续接；即梦智能多帧最多约 10 个关键帧串成多节拍单条
- **多镜原生**：Seedance 2.x / 万相 2.6+ / Sora Storyboard / LibTV 分镜节点支持一次生成多镜头，主体场景一致性更好——但风格 token 块仍要写进 prompt

## 第 8 步：剪辑合成（剪映/CapCut）

1. 按分镜表顺序排列素材，修剪头尾
2. 配音：TTS 或克隆音色录口播稿；**逐句对齐镜头**
3. **图表层（科技类强制）**：参数表卡/曲线动画（用真实数据重绘，数值不得改动）/覆盖图/结构图解——全部后期制作，AI 不生成数据画面
4. **文案层（广告片强制）**：主 slogan/分段大字/数据字卡/落版，按 `knowledge/ad-copy.md` 规范压字
5. 字幕：自动识别 + 手动校对术语（术语错字是科研片重灾区）
6. 音乐音效：按 VI 风格表选（申报片=史诗/宏大，科普=轻快）；动感不够时先做速度斜坡和音效驱动剪辑，别回头重抽
7. 统一调色：全片套同一个 LUT，掩盖镜头间残余的风格漂移
8. 片头片尾：按 VI 模板（`knowledge/vi_styles/`）制作

## 第 9 步：质量门控 → 交付

过 `protocols/quality-gate.md` 的七维检查表和交付清单，全部通过才把成片+分镜表+prompt 表交付用户。

**门控必须真跑**：交付任何里程碑产物（方案/分镜/手册）前，把对应出口检查表**逐条写出来并逐项打勾**，贴在产物末尾。不许凭印象说"符合"。检查表更新后，回头刷新所有进行中的项目产物。

## 第 10 步：知识萃取入库（项目收尾）

交付完成后，科学顾问主导把本项目调研沉淀进科学知识图谱（15-30 分钟），严格执行 `kb/入库规则.md` 五步流程：三分法分拣（🟢 入库 / 🟡 脱敏后入库 / 🔴 一字不留）→ 按 `kb/_模板/概念笔记.md` 成文 → 过 `kb/隐私红线.md` 脱敏检查 → ``[[wiki-link]]`` 织网 → 更新领域索引与 `kb/index.md` 计数并 git 同步。
项目制品（分镜表/prompt 表/客户素材）留在项目目录，**永不复制进 skill 目录**。

## 常见翻车急救

| 症状 | 处方 |
|------|------|
| 某镜抽卡 6 次都翻车 | 改路线：文生视频 → 首帧图+图生视频；或简化 prompt 到 1 主体 1 动作 |
| 角色跨镜变脸 | 停用文生视频，全部改参考图/三视图锚定（见 consistency.md） |
| 旁白和画面对不上 | 回第 3 步重切文稿段落，别在剪辑里硬拉 |
| 术语发音错 | 改文稿同义词替换（质量门控标准处置），别指望 TTS 猜对 |
