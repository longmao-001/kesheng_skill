# 剧集生产手册（Series Production）

> **用途**：**剧集类项目**（多集连载：动画番／短剧／系列片／任何"第一季／EP01 起"的交付）从「立项 → 全季 → 分集 → 段/镜」的**唯一生产纪律手册**——把"**这是剧集，不是单条视频**"落成**可写、可查、可机器门控**的固定格式。
> **来源**：**红楼梦 EP01 暂停复盘（用户裁定 20260917）**。
> **裁定原文**：「**科生 skill 还缺"做剧集"的能力**——该项目是剧集，却被当成单集样片在跑。**先基于「做剧集」重做优化，本项目暂停。**」
> **本项目实证（暂停快照 §四）**：无全季规划 → 首集做完不知道第二集怎么接；无风格圣经 → 锚图/色板/字体/母题/OP·ED 固定资产无跨集复用依据；无跨集一致性门控；无剧集文件规范；无档期与发布节奏。
> **铁则一句话**：**没有全季规划，不许开第一集。**（单集能不能做，不取决于单集本身，取决于它在全季里的位置。）
> **触发判定**：交付规模＝**≥2 集**，或需求出现「第一季／季番／EP01／系列／连载／每集／更新」任一词——**一律必读本手册**；单条视频（一次交付一条成片）走 `playbooks/production-workflow.md`，不适用本手册。

  - **每集交付前** → 跑 §六 机器门控 + §十二 自检。

## 一、剧集 vs 单条的分野：为什么不能把剧集当单条跑

### 1.1 差别不是"更长"，而是**多了三个维度**

| 维度 | 单条视频 | 剧集 |
|---|---|---|
| **时间轴** | 片内 0→N 分钟 | **跨集**：EP01…EPnn 的连续时间线（人物会老、伏笔要还、钩子要接） |
| **一致性** | 片内跨镜（几十~两百镜） | **跨集跨镜**（几百~几千镜，且间隔数周至数月） |
| **资产** | 一次性生产、一次性用完 | **跨集复用摊薄**（锚图/字帖/母题/OP·ED 是一次投入、多集使用） |
| **门控** | 出口闸 PASS 即完 | 出口闸 PASS **≠** 剧集成立；还要过**跨集一致性闸**与**钩子接续闸** |
| **失败代价** | 重做一条 | **口径错一次，全季重做**（本项目：一天内出 9 批 KSP-C 变更，全部因"开局没定口径"） |

### 1.2 把剧集当单集跑，必然出现的四个断裂（本项目实证）

1. **结构断裂**：`brief.md` 定「先做1集样片」→ 全季集数、每集时长、改编边界**从未存在** → 首集做完，**第二集无从下笔**（不知道从哪回接、接多少、留什么钩）。
2. **资产断裂**：29 件锚图（角色 11＋道具 9＋场景 9）＋26 帖字帖＋OP/ED 全部按"这一集用完"生产 → 第二集要么重抽（成本翻倍）、要么无据可依（**F-42：51 件在库锚图里 39 件的采纳版 prompt 只活在对话里**）。
3. **口径断裂**：字系（简繁）、称谓、回目体例、色彩语义、专属空间标记**在单集内被反复改**（KSP-C 变更 ①~⑨ 一天内连发）——剧集里这些是**跨集契约**，改一次要全季回归验证。
4. **钩子断裂**：单条视频"结尾有 CTA"就够；剧集**集尾必须有钩、集首必须能接**——本项目集尾钩（黑底字卡「新任太爷…」＝EP02 吊钩）**是唯一按剧集逻辑做的设计**，恰恰反证了：**只有这一处做对了，其余全靠单集思维补**。

### 1.3 立项即判型（KSP-E0，硬规则）

**KSP-E0 剧集判型**（在 KSP-01 定档的**同一张卡**上完成，产出写进 `brief.md`）：

- **判型三问**（任一为"是"即判为剧集）：
  1. 这次交付**是否只做全片的一部分**？（"先做一集/先做样片/第一季前几集"＝是）
  2. 是否**存在下一集**（哪怕是"看效果再说"）？——**"看效果再说"仍判剧集**（本项目正是这么开始的）。
  3. 内容是否来自**可切分为连续单元的母体**（原著回目／系列选题／连续事件）？（是）
- **判型后的必做动作**（不许跳过）：
  1. `brief.md` 的「交付规模」字段**不许写"先做1集样片"**，改写为 `第一季 N 集（本批交付 EP01…EPnn）`，并写明 **EP01 是"全季的第一集"而不是"样片"**；
  2. 定档口径追加一句：**本项目的成功标准＝全季标准**（单集 PASS 不减损全季要求）；
  3. 立即排 **KSP-E1 全季规划**（§三）为**前置门控**——**KSP-E1 未过，不许进任何一集的 KSP-04（概念）**；
  4. 立即排 **KSP-E2 风格圣经**（§四）为**前置门控**——**KSP-E2 未过，不许抽任何一张锚图/字帖**（本项目先抽了 29 件锚图才回头补口径，全部面临重抽风险）。
- **产物**：`brief.md` 剧集段（判型结论＋集数＋更新节奏＋全季成功标准）＋ `STATE.md` 增加 `KSP-E1/E2` 待办行。
- **门控**：用户拍板（选项卡，见 §三.5 卡型）。

## 二、三层规划：全季 → 分集 → 段/镜

### 2.1 分层图（一条纵向规划线 ＋ 一条横向资产线）

```
【横向资产线·KSP-E2/E3】风格圣经 Show Bible + 跨集资产索引
        ↑ 约束                      ↑ 供给
【层1·全季】KSP-E1  season-outline.md        集数/时长/改编边界/分集大纲/回目体系
        ↓ 分解
【层2·分集】每集闭环（KSP-02…07 循环）        episode-brief → 方案 → 口播 → 分镜 → prompt → 出厂
        ↓ 分解
【层3·段/镜】段卡 + 分镜 + 逐镜 prompt        beat（10-15s 段）/ shot（3-10s 镜）
```

### 2.2 各层产物与门控（总表）

| 层 | 规划件（单一事实源） | 执行件 | 门控 | 过闸判据（一句话） |
|---|---|---|---|---|
| **KSP-E0 判型** | `brief.md` 剧集段 | — | 用户拍板 | 判型结论＋集数＋"按全季标准"写入简报 |
| **层1 全季 KSP-E1** | `season-outline.md`（§三） | — | **全季规划闸（用户拍板）** | 集数/时长结构/改编边界/分集大纲/回目体系**五项齐**且用户确认 |
| **横向 KSP-E2** | `show-bible.md`（§四） | 锚图/字帖/母题/OP·ED 出图清单 | **圣经闸（用户拍板＋美术会签）** | 十节齐备且**红线表**写死；新增设定走"先入圣经" |
| **横向 KSP-E3** | `series-asset-index.md`（§五） | `_shared/` 资产目录 | **资产索引闸（检察官 L1）** | 每件资产有 ID↔文件↔采纳版 prompt 溯源，复用集列全 |
| **层2 分集** | `episode-brief.md`（§七） | `EPnn-*/` 全部制品 | **每集出口闸（KSP-06）＋跨集一致性闸（KSP-E4）** | 本集自洽 ＋ 与全季口径一致 ＋ 钩子已接 |
| **层3 段/镜** | 段卡／分镜表／prompt 表 | `segments-*.md`／`EPnn-分镜表.md`／`prompts-*.md` | 既有机器门控（`check_prompt_delivery.py` D1–D13 等）＋文学闸 | 既有判据全绿（逐集跑，不得因"上一集绿了"豁免） |

### 2.3 分解三铁则

1. **规划只能自上层向下分解，不许自下层向上倒推**（先有分集大纲，才有本集剧本；不许"本集写完再回头编大纲"）。
2. **同层不许跨集借用单一事实源**：EP02 的时长/角色/色彩**引用**圣经与大纲，**不得各自另写一份**（F-29：多版本并存＝交付件漂移主因）。
3. **下层发现的问题必须回流到上层**：本集为叙事需要新增角色/场景/母题 → **先改圣经登记，再进本集 prompt**（口径变更走 KSP-C，注明影响全季哪些集）。

## 三、全季规划（KSP-E1）

> **产物**：`runs/<series-slug>/season-outline.md`（模板 `templates/season-outline.md`）。
> **门控**：**全季规划闸**——五项齐备 ＋ 用户拍板 ＋ 制片人裁决纪要（`decision-log.md`）。**未过闸不得写任何一集剧本/抽任何一张图。**

### 3.1 集数与每集时长（含 OP/ED 固定资产时长）

- **必写死的三个数**：`季集数 N` ／ `单集净时长` ／ `单集总时长 = OP + 正片 + ED`。
- **OP/ED 属"固定资产"**：**时长为先、内容为后**——OP/ED 一旦定长，**全季所有集不许变**（变＝观众体感断裂＋素材复用失效）。
  - 判据：`OP 时长` 与 `ED 时长` 写进圣经 §⑧ 与大纲每集行，**逐集核对必须逐秒相等**；
  - 本项目实证：EP01 OP 曾为「65s 素材＋25s 静场/叠化填充」，被甲方裁定**重写为 90s 满时长 24 镜**（填充＝废），**OP 从"拼盘"改成"一整套连贯片头"**——**这就是"OP 是固定资产"的反面教材**：OP 一旦当填充物做，全季都要重做。
  - **正片时长允许 ±N% 浮动**（推荐 ≤10%），但 **OP/ED 浮动＝0**；浮动超限走拍板卡 #14。
- **单集时长档建议表**（按平台与更新节奏选，写进大纲表头）：

| 形态 | 单集总时长 | OP/ED | 适用 |
|---|---|---|---|
| 短视频连载（竖屏） | 3–8 分钟 | 0–10s（可无 OP/ED） | 抖音/B站竖屏、日更 |
| 标准周更番剧 | 15–24 分钟 | 各 60–90s | B站/爱奇艺横屏 |
| 长剧集（月更/季更） | 30–45 分钟 | 各 90–120s | 长视频平台 |

### 3.2 改编边界（"某回=某集" 还是 "每集=若干回"）

**三种边界模型，选定一种并写进大纲表头（不得混用）**：

| 模型 | 写法 | 适用 | 判据 |
|---|---|---|---|
| **A 一回一集** | `第N回 = EPnn` | 原著名回目、每回戏量均衡 | 每回 ≥ 单集净时长的 80% |
| **B 多回一集** | `EPnn = 第x–y回（或 x回前半+y回后半）` | 回目短、需并线 | **切点必须能写出依据**（在事件边界切，不在情绪中间切） |
| **C 一拆多集** | `第N回 = EPnn–EPnn+2` | 单回戏量极大 | **拆点须有钩子**（每拆点＝一个集尾钩） |

- **边界三纪律**：
  1. **切点选"事件边界"**，不选"情绪中间"（切在段落收束处，观众不觉得断）；
  2. **每集首尾都要能独立看懂**（见 §八 受众可懂性）；
  3. **边界一经拍板＝全季契约**：中途改边界＝改集数＝重排全季（走 KSP-C，评估影响全季）。
- **本项目实证**：EP01 改编范围＝"第一回原著开篇"，并把第一回内部切成 **四副自拟回目（四章）**——即**"一集 = 一回"的模型 A 之下的"集内四章"**。这本是可行的，但**当时没有写"全季其余 119 回怎么分集"**，所以第一集做完即断。

### 3.3 分集大纲（每集五项必填）

每集一行（表见模板），**五项缺一不许进入本集制作**：

1. **主线情节**：本集讲完的那一件事（一句话，有主语有结果）；
2. **钩子（开集/集尾）**：开集 15s 抓什么／集尾留什么（类型见 §八）；
3. **情绪曲线**：起点值→峰值→谷底→收束值（0–10），并标**峰/谷落在第几分钟**；
4. **集尾钩子**：写清"钩的是什么"，并**点名它由哪一集的哪一拍兑现**（钩子必须有回收责任人，否则是空钩）；
5. **回目/章节卡**（见 §3.4）。

### 3.4 回目体系（原著回目／自拟回目／章节卡）

> **三层要分清，混用即口径事故**：

| 层 | 是什么 | 依据 | 产物 |
|---|---|---|---|
| **原著回目** | 母体的原有章节名（如《红楼梦》120 回回目） | 底本原文，逐字照录 | 大纲「改编范围」列 |
| **自拟回目** | 剧集为**集内子单元/单集标题**自撰的对仗联 | **必须过文学闸（六维）＋用字核对＋对仗判据** | 大纲「自拟回目」列 ＋ 剧本字卡字段 |
| **章节卡** | **上屏**的回目字卡（谶卡/验卡/集标题卡） | 字帖铁律（#32）＋字系分体例＋版式坐标 | 圣经 §⑥ 字帖登记 ＋ 本集 prompt |

**自拟回目四条硬判据**（本项目 `m4-回目复核.md` 实证得出，逐条打勾）：

1. **字数相等**（7/7、8/8；长短联各自对齐）；
2. **对仗工整**：地名对地名、动宾对动宾、词性相当（本项目第三回「癞头僧（人）对元宵夜（时间）」被文学闸判为**宽对**并打回）；
3. **尾字平仄**：上联尾仄、下联尾平（本项目四条回目尾字 世/莲、誓/灵、孺/家、客/茫 均合律——**合律是及格线，不是加分项**）；
4. **事实零硬伤、可回指底本行号**：
   - 本项目**回目三「元宵夜烈火焚甄家」被判必改**——丢女在元宵夜、焚家在**三月十五**，一句之内把两件事系于同时＝**时间错位误导**；改为「葫蘆廟烈火焚甄家」（地点对地点，且事实准）。
   - 本项目**回目四「风雪路双影赴北邙」被判必改**——北邙之约是僧道二人之事，与士隐无关，回目**暗示了原著没有的去向**；改为「風雪路雙影入蒼茫」（零误导）。
   - **通用警戒**：回目**不得暗示原著没有的因果/去向/身份**；写不出底本行号的回目＝不成立。
5. **章节卡版式＝跨集契约**：章节卡的**坐标、字号、字形分档、印位**由圣经 §⑥ 写死；同一版式**跨集不改**（观众"习得语法"靠的是版式恒定——本项目"上谶下验"双字卡对位即此设计）。
6. **字系分体例**（本项目甲方裁定，建议固化为剧集通用口径）：**古典体例一律繁体，现代功能提示用简体**；同一字帖清单内混用简繁＝口径事故，须上报拍板、禁静默处理。

### 3.5 全季规划闸（拍板卡）

- **证据先行**：把 `season-outline.md` **全表**贴给用户（集数/时长/边界/每集五项/回目），再给选项卡；
- **卡型**：`按此全季规划执行（Recommended）` / `改集数与时长结构` / `改改编边界（指出哪几集）` / `改分集大纲（指出哪几集）` / `自定义`；
- **过闸后**：规划件冻结为**单一事实源**，集内一切制品引用它；变更走 KSP-C。

## 四、风格圣经 Show Bible（KSP-E2）

> **产物**：`runs/<series-slug>/show-bible.md`（模板 `templates/show-bible.md`）。
> **门控**：**圣经闸**——十节齐备 ＋ **红线表写死** ＋ 美术会签 ＋ 用户拍板。**未过闸不许抽任何一张锚图/字帖。**

### 4.1 圣经 = 跨集统一的"固定资产清单"

剧集与单条最大的成本差别在这里：**单条项目每次都重新定风格；剧集项目只能定一次。**

| # | 固定资产 | 内容 | 跨集纪律 |
|---|---|---|---|
| ① | **锚图库** | 角色锚（含形态/年龄段/服装版本）、场景锚、道具锚 | **ID 全局唯一、跨集不变**；新增＝新 ID，不改旧 ID |
| ② | **色板与色彩语义** | 墨阶/色值 + **语义绑定**（某色＝劫/幻/情）＋ 配额（≤N% 画幅）＋ 豁免条款 | 语义与配额**逐集负面钉死**（专属空间标记不得串场） |
| ③ | **字体与字帖** | 字体分档（碑刻楷/馆阁体/魏碑意/篆书）＋ 字帖帖号登记 ＋ 字形负面分档 | **字帖 ID 跨集复用**；同一文本跨集出现**同一帖**（去重合并） |
| ④ | **笔触与留白级别** | 留白分级（甲/乙/丙）＋ 笔触分层（游丝/钉头/泼墨）＋ 反模式 | 分级**互斥、不混用**；逐集验收口径相同 |
| ⑤ | **母题登记册** | 转场母题／音效母题／构图母题／色彩母题，各带 ID | **母题 ID 全局唯一**；首次出现集＋复用集登记在册 |
| ⑥ | **OP/ED 固定资产** | 时长、镜数、逐镜清单、主题歌、片名/印、ED 回放素材 | **时长逐集相等**；素材**跨集复用**；片名/印不得中途改 |
| ⑦ | **说书人/叙事层身份节奏** | 旁白/说书人是谁、何时出现、语速/音色、"只说一句"的上限 | 叙事层**不得与剧中人混权**（谁在说这句台词） |
| ⑧ | **叙事与技术红线** | 全季禁项（无光之戏禁亮词／OP 禁浮空字卡／无后期…） | 红线**跨集继承**，不得因"这集特殊"临时开口 |

### 4.2 母题登记册（最容易被漏、复用价值最高）

四类母题，**每条一个 ID**，登记 `母题ID｜类型｜内容｜首次出现（集/镜）｜复用集｜使用纪律`：

| 类型 | 例（本项目） | 复用价值 |
|---|---|---|
| **转场母题** | 「枯笔扫」（全片唯一转场语法）／「墨晕晕开入梦」 | 跨集转场**不另造语法** → 集与集剪在一起像一部长片 |
| **音效母题** | 「十记落」换材质不换语法（石磬×2→步点鼓→掌心闷击→衣袂靴雪→抽空→墨滴「嗒」→洇→墨点「咚」→印「嗒」，之后**不再有落**） | 观众靠听觉认出"同一部剧" |
| **构图母题** | 「露泪直通镜」（全季版权镜）／同构图"人形留白"缺口 | 跨集回环呼应、预告与应验同构图 |
| **色彩母题** | 「泪＝全片唯一不褪之朱」（永久豁免褪色法则） | 跨集情绪抓手，第 N 集再出现即"观众懂了" |

- **母题纪律**：①**宁少勿滥**（母题多则观众不认）；②**复用必须可辨认**（同一语法换材质 ✓／换语法 ✗）；③**禁止无功能复现**（复现须显式声明 `【复现·回环】` ＋依据＋限次）。

### 4.3 OP/ED 固定资产

- **OP/ED 不是"每集现做"，是"一次做完、逐集复用"**：逐镜清单、时长表、主题歌段落（前奏/A段/B段/桥段/副歌/末副歌/末句）、片名/注音/印，全部写进圣经 §⑧。
- **跨集唯一允许的变化**：①**集数提示**（如需"第 N 集"）②**下集预告位**（ED 后 10–20s，用本集素材剪）③**前情提要位**（OP 前，可选，见 §八.3）。
- **OP 文字白名单**（硬规则 #33 跨集化）：OP 只允许 ①片头标题字 ②物件上的字；**浮空字卡一律移入正片**——本项目 OP 曾因"叠角悬四句诗"被判定**动画退化成图文排版**，24→19 镜整改。
- **ED 设计要点**：ED 是**回收位**（褪色回放/母题复现/片名改题），不是"再来一段画面"；ED 素材 60% 以上应来自**本集已产素材的变体**（成本≈0，本项目 OP/ED 29 镜中约 60% 可同素材变体复用）。

### 4.4 叙事层（旁白/说书人）身份节奏

- **写死三件事**：**谁在说**（叙述层／剧中人）／**什么时候说**（OP 内／正片开场／章节引子／集尾）／**说多少**（每集旁白字数或占比上限）。
- **不得混权**（硬规则 #31 六维①的剧集延长）：叙述层不得夺取剧中人文本，也不得让具名角色"唱/说"非其身份的文本。
- **本项目实证**：甲方拍板 **OP 内人声＝0 句**（旁白全部移出 OP，白话钩/主钩/定场白落**正片开场 0:00/0:04/0:08**，总长约 11s）——**"叙事层节奏"是跨集契约**，EP02 起必须照同一节奏（否则每集开头体感不一）。

### 4.5 纪律：新增设定必须先入圣经（"先入册，后开抽"）

> **硬规则（剧集专用）**：**任何本集新出现的角色／场景／道具／色值／字体／母题／叙事层变化，必须先登记进 `show-bible.md`（拿到 ID），才允许写进本集 prompt／出图／抽卡。**

- **为什么**：本项目 **39/51 件在库锚图的采纳版 prompt 只活在对话里**（F-42），且**口径一天改了 9 批**——根因都是"设定先落地、后入册"。
- **执行三步**：
  1. 分集简报时列「本集新增设定」清单（见 `templates/episode-brief.md` 资产状态段）；
  2. **先**在圣经对应节追加条目并分配 ID（角色 `C<序号>[-变体]`／场景 `S<序号>`／道具 `Y<序号>`／字帖 `#<序号>`／母题 `M-<类型><序号>`）；
  3. **再**在本集 prompt 内引用该 ID（引用格式与既有 @标记贯穿一致）。
- **未入册即出图＝流程事故**（等同 L1 素材检察官 FAIL）：产物**不得进交付包**，须补册后重出。
- **变更留痕**：圣经 §⑪ 变更记录逐条登记（日期／变更项／旧→新／依据／影响哪些集）。

## 五、跨集资产复用与索引（KSP-E3）

> **产物**：`runs/<series-slug>/series-asset-index.md`（跨集索引表）＋ `_shared/` 资产目录（真实文件）。
> **门控**：**资产索引闸**（检察官 L1 等价）——每件资产 **ID ↔ 文件 ↔ 采纳版 prompt 全文出处 ↔ 复用集** 四者对齐；对不上＝FAIL。

### 5.1 复用规则（四类资产，四套规则）

| 资产 | 复用规则 | 一次性判定 |
|---|---|---|
| **锚图**（角色/场景/道具） | **默认全季复用**；同角色不同形态/年龄段＝**派生变体**（`C1a`→`C1d-谷底态`），不重抽主锚 | 只服务单一镜的意象图（如"某镜专属闪帧"）＝一次性，标 `(单集)` |
| **音乐/音效** | **OP 主题歌＋母题音效＝全季复用**；集内情绪 BGM 可每集新配 | 单集专用的段落配乐＝一次性 |
| **字帖** | **同一文本跨集只出一帖**（去重合并），多集挂载同一文件；帖号跨集唯一 | 仅在单集出现的黑底字卡＝单集专用（可仍留档供后续集启用，标"备而不用"） |
| **转场/母题素材** | **母题素材＝全季复用**（墨晕对、枯笔扫帧等）；**禁止每集重造同功能素材** | — |

### 5.2 跨集资产索引表（字段写死）

| 字段 | 说明 |
|---|---|
| **资产 ID** | 全局唯一（角色 `C*`／场景 `S*`／道具 `Y*`／字帖 `#*`／母题 `M-*`） |
| **资产名** | 人可读名（如「士隐·主锚」） |
| **类型** | 角色锚／场景锚／道具锚／字帖／母题素材／OP-ED 件／音乐音效 |
| **文件** | `_shared/锚图/角色/C1a-士隐-主锚-v1.jpeg`（真实相对路径） |
| **版本** | `v1/v2…`；**改版必须新增文件、不覆盖**（旧版进 `_旧版归档/`） |
| **采纳版 prompt 全文出处** | `文件+条目号`（**不得写"对话里"**——F-42 铁则） |
| **参考组** | 该资产出图时用的参考图/字帖 ID 组合 |
| **首次出现** | `EP01/A-04` |
| **复用集** | `EP01,EP02,EP05` ／ `全季` ／ `(单集)` |
| **状态** | ✅在库可用／⏳待产／❌作废（作废件**留库作判废证据并注明"不得用于下游"**） |

### 5.3 三条索引纪律

1. **在库必须有出处**：素材在库、采纳版 prompt 不在库 ＝ **最高风险**（换人/换会话即不可重出）——凡"只在对话里存在、没落盘"的 prompt **一律登记待补**并标 ❌未落盘／⚠️仅要点／✅完整（F-42／硬规则 #30）。
2. **先建索引再选片交付**：交付前逐件核对索引与 `_shared/` 实际文件一致（文件名唯一、引用一律用 ID＋文件名）。
3. **一次投入、多集摊薄要算得出来**：索引表末附「复用次数」列——复用次数 ≥2 的资产即"全季固定资产"，其抽卡成本按集摊薄（§十）。

## 六、跨集一致性门控（KSP-E4）

> **为什么必须独立于每集出口闸**：每集的出口闸只看得到本集（跨集镜头隔着数周生产），**跨集漂移在单集视角下天然不可见**。

### 6.1 跨集校验清单（逐集交付前跑一次 ＋ 季末总检一次）

| # | 维度 | 校验内容 | 判据（可机器化） | 本项目风险例 |
|---|---|---|---|---|
| 1 | **人物·面容** | 同 ID 角色跨集是否同一锚图派生 | 每集 prompt 的角色镜**必挂同一 `C*` 锚**；未挂＝FAIL | 半工半泼、瞳孔高光、矢量描边＝三大 AI 翻车点 |
| 2 | **人物·服饰** | 服饰/道具版本是否随时间线正确演进 | 集号 ↑ → 版本号只增不退；**倒序即 FAIL** | 「袍色偏白」需派生补淡墨罩染词 |
| 3 | **人物·年龄变化** | 跨集时间跨度角色的年龄/形态锚 | 有年龄变化的角色**必须有 ≥2 个形态锚**并登记 `首用集` | 英莲 3 岁、士隐"谷底态"＝形态锚先例 |
| 4 | **色板** | 墨阶/色值/语义/配额跨集一致 | 每集 prompt 引用**同一色值锚**；新色值**必须先在圣经登记** | 「泪＝唯一不褪之朱」永久豁免条款 |
| 5 | **字形** | 字系分体例、字形分档、字帖 ID 跨集一致 | 古典体例繁体/功能提示简体；**同文本同帖**（帖号一致） | 一日内"字系分体例＋回目转繁＋片名换魏碑意"三改 |
| 6 | **母题** | 母题 ID、语法、复现限次 | 母题 ID 全局唯一；复现须 `【复现·回环】`＋依据 | 「枯笔扫」为唯一转场语法 |
| 7 | **音效** | 母题音效一致；集尾/集首声音接法一致 | 声音脊线母题从圣经取；**集尾不静默断** | 「十记落」换材质不换语法 |
| 8 | **时长结构** | OP/ED 秒数逐集相等；正片 ±N% 内 | `OP_EPnn == OP_season`，`ED` 同；正片偏差 ≤10% | OP 曾 65s＋25s 填充 → 改 90s 满时长 |
| 9 | **叙事层** | 旁白/说书人身份、语速、出现位 | 每集开场钩子落位秒数一致 | OP 人声＝0；正片 0:00/0:04/0:08 |
| 10 | **钩子接续** | 上集尾钩是否在本集被接/被兑现 | 大纲「钩子回收责任人」逐条核对 | EP02 吊钩＝黑底字卡「新任太爷…」 |
| 11 | **口径** | 称谓/术语/专名/回目体例跨集统一 | 专名表（圣经附）逐词一致；**同词两写＝FAIL** | 「蘆廟 vs 葫蘆廟」「茫茫 vs 茫」类误伤（F-47） |

### 6.2 机器门控思路（落地形态）

**分两层跑，互不替代**：

```
# ① 单集层（既有通用门控，逐集跑；不得因"上一集绿了"豁免）
python -X utf8 scripts/check_prompt_delivery.py <runs/<slug>/EPnn> --animation-baseline   # D1–D13
python -X utf8 scripts/check_prompt_sheet.py      <runs/<slug>/EPnn>
python -X utf8 scripts/check_prompt_sop.py        <runs/<slug>/EPnn>
python -X utf8 scripts/check_delivery.py          <runs/<slug>/EPnn>                      # 版本收敛
python -X utf8 scripts/check_asset_pack.py        <runs/<slug>/EPnn>                      # 零意外自包含

# ② 剧集层（本手册规定·脚本待工具批落地；未落地前用手工清单 §6.1 逐集核对并留痕）
python -X utf8 scripts/check_series_consistency.py <runs/<slug>>   # 读 series-config.json，做 §6.1 的跨集判定
```

**`runs/<series-slug>/series-config.json`（剧集专属词表，仿 `prompt-delivery-config.json` 的做法：项目专属词只进 run 内，不写进脚本）**：

| 字段 | 用途 |
|---|---|
| `series_slug` / `episodes[]` | 剧集标识与集号清单（门控据此遍历） |
| `op_seconds` / `ed_seconds` / `feature_min_seconds` / `feature_tolerance` | 时长结构契约（§6.1-8） |
| `anchor_registry` | 角色/场景/道具锚 ID ↔ 文件 ↔ 允许出现的集 |
| `text_card_threads` | 字帖帖号 ↔ 文本 ↔ 允许出现的集（同文本同帖校验） |
| `motif_registry` | 母题 ID ↔ 类型 ↔ 首次出现集 ↔ 允许复现集/限次 |
| `naming_terms` | 专名/称谓白名单（同词两写＝FAIL；配 F-47 三禁令：禁叠字归并、替换式长串优先＋词边界、改后逐点 diff） |
| `hook_ledger` | 每集集尾钩 ↔ 兑现集/镜（空＝FAIL） |
| `red_lines[]` | 全季红线（**跨集继承，不得单集开口**） |

**剧集层判据（D-S1–D-S8）**：

| 项 | 判据 | 不达标 |
|---|---|---|
| D-S1 时长结构 | 逐集 OP/ED 秒数相等，正片在容差内 | FAIL |
| D-S2 锚复用 | 角色镜挂载的 `C*` 属本集允许集，且与首用集同版本 | FAIL |
| D-S3 字帖一致 | 同文本跨集帖号一致；字系分档一致 | FAIL |
| D-S4 母题唯一 | 母题 ID 唯一；复现未声明即 FAIL | FAIL |
| D-S5 钩子账本 | 每集有集尾钩且回收责任人有集号 | FAIL |
| D-S6 专名一致 | `naming_terms` 内的词跨集写法逐字一致 | FAIL |
| D-S7 新增入册 | 本集出现的锚/帖/母题 ID 均已在圣经登记 | FAIL |
| D-S8 红线继承 | 全季红线在每集 prompt 负面中在位 | FAIL |

> **门控与真实格式对齐（F-30 教训）**：剧集层门控实现时，字段标记/参考图语法必须沿用**生产在用的格式**（`【字段】`、`@图片N=<文件名>`），**误报＝脚本过时，不是制品不过关**——修脚本，不迁就脚本。

### 6.3 人工闸（不可省）

- **跨集一致性检察官**（独立上下文，只看证据不听辩护）：逐集交付前出报告；**季末总检**出《全季一致性裁决书》（各集评分＋打回清单＋三态：PASS/CONDITIONAL/BLOCK）。
- **闸序**：**文学闸 → 红队前置闸 → 单集检察官（L1–L4.5）→ 跨集一致性检察官（KSP-E4）→ 用户签收**。
- **不得以"动画性更好看／这集特殊"为由放行跨集漂移**。

## 七、每集制作闭环（与既有 KSP 的映射）

### 7.1 单集闭环（六段循环）

```
① 分集简报（templates/episode-brief.md）
      ↓ 继承圣经/大纲 ＋ 列本集差异与新增设定
② 剧本（本集结构＝大纲那一行的展开；自拟回目过文学闸）
      ↓
③ 分镜（段卡 → 分镜表；动画类必读 animation-motion-design.md）
      ↓
④ prompt（逐镜；单一 SOP 合并块；@贯穿；字帖前置）
      ↓
⑤ 出片（陪跑抽卡；抽卡台账；废片归因回写 prompt）
      ↓
⑥ 出口闸 → 归档（含跨集一致性闸）
```

### 7.2 哪些 KSP 关卡在剧集里"循环执行"，哪些"只跑一次"

| 关卡 | 季内频次 | 剧集内的执行口径 | 集级产物 |
|---|---|---|---|
| **KSP-E0 判型** | **季一次** | 判型结论写进简报 | `brief.md` 剧集段 |
| **KSP-E1 全季规划** | **季一次** | 全季规划闸 | `season-outline.md` |
| **KSP-E2 风格圣经** | **季一次（增量更新）** | 新增设定走"先入册后开抽" | `show-bible.md` |
| **KSP-E3 资产索引** | **季一次（增量更新）** | 每件资产四者对齐 | `series-asset-index.md` |
| **KSP-01 定档** | 季一次 | 继承季档（不逐集问） | — |

## 八、集尾钩子与追更设计（KSP-E5）

> **单条视频的结尾是 CTA；剧集的结尾是"你还得回来"。**

### 8.1 集尾钩子类型（选定并写进大纲「集尾钩子」列）

| 类型 | 做法 | 兑现责任 | 本项目例 |
|---|---|---|---|
| **① 悬念钩** | 事件未完／出现新变量（常配黑底字卡） | 下一集开头 3 分钟内 | 黑底字卡「新任太爷…」＝**EP02 发行吊钩** |
| **② 预告钩** | 下集关键意象/画面**前置 0.5–2s 快闪**（不剧透结果） | 下一集中段 | OP 式四谶快闪（但注意 #33：海报式浮空字卡不入 OP） |
| **③ 伏笔回收钩** | 本集回收上集伏笔 ＋ **埋下新伏笔**（一还一埋） | 本季第 K 集 | 「露泪直通镜」为全季版权镜 |
| **④ 情绪钩** | 人物命运到不可逆节点，戛然而止（无字卡） | 下一集开头 | 谷底→「走罢」 |
| **⑤ 章回体钩** | 回目悬念＋「且听下回分解」式收束（字卡/旁白） | 下一集开头 | 四副回目＝章节卡体系 |

- **钩子三纪律**：①**一集一主钩**（多钩＝无钩）；②**钩子必须有回收责任人**（写不出"哪一集哪一拍兑现"＝空钩，大纲门控 FAIL）；③**钩子不许靠"删掉本集结尾"制造**（必须是大纲层设计的事件/伏笔）。

### 8.2 与下一集开头的接法（四种，选定并登记）

| 接法 | 做法 | 成本 | 适用 |
|---|---|---|---|
| **硬接** | 上集尾帧 → 下集首帧**同镜延续**（首尾帧衔接；注意只对以首尾帧为机制的平台用） | 低 | 事件被切成两集（模型 C 拆集） |
| **母题接** | 用**母题**承上启下（同一转场母题/音效母题/构图母题） | 极低（复用） | 默认推荐——集与集像一部长片 |
| **重述接** | 上集回顾 15–30s（**全部复用素材**） | 低 | 更新间隔 >7 天 或 单集 >15 分钟 |
| **字卡接** | 「前情提要」字卡（功能简体组） | 极低 | 需要快速补背景的强连续剧 |

### 8.3 追更留存要点（含"上一集回顾"判据）

1. **"上一集回顾"是否需要——给判据，不给习惯**：
   - **需要**：单集总时长 >15 分钟 **或** 更新间隔 >7 天 **或** 上一集有 ≥2 个未解钩子；
   - **不需要**：单集 ≤8 分钟 且 周更以内（观众记得住，回顾反而拖节奏）；
   - **形体**：**15–30s、全部复用上集素材**（成本≈0）；**放在 OP 之后、正片之前**（不做"OP 前回顾"）。
2. **集首 15 秒钩子（剧集版"前 5 秒钩子"）**：上一集钩子必须在**本集前 15 秒内**被接住或点明（否则观众流失）；本项目把三句旁白（白话钩/主钩/定场白，约 11s）放在**正片 0:00/0:04/0:08**——即此纪律的实例。
3. **下集预告**：ED 后 10–20s，**只用本集已产素材**剪；**禁剧透结果**（只给意象/冲突）。
4. **新观众可懂性**（受众提醒，见 `episode-brief.md`）：每集必须能"**从中间进来也看得懂**"——判据三条：①本集主线一句话说得清；②关键人物首次出现有"一次性身份提示"（服装/旁白/字卡任一）；③上集核心信息在本集前 1/3 被隐含复述（不靠观众补课）。
5. **更新节奏与追更留存**：节奏由 §十 排产倒推确定（**周更/双周更/月更**）；**节奏一经定下写进大纲**，因为它决定"回顾是否需要""钩子强度""资产复用窗口"。
6. **封面/标题/集号**：每集交付必带**封面图（可从本集锚图变体派生）＋标题（自拟回目）＋集号**；同一套封面版式（跨集统一，写进圣经 §⑧）。

## 十、成本与排产（KSP-E6）

### 10.1 单集抽卡额度估算（模型）

**单集抽卡总量 ≈ 以下五项之和**（每项按"抽卡次数"计，1 次＝1 个可采纳候选）：

| 项 | 估算式 | 本项目 EP01 参照 |
|---|---|---|
| ① **风格基线（九宫格）** | 季一次：`8 格 × 1–2 抽` | 8 格（含 3 个"生死格"） |
| ② **锚图生产** | `新增角色 × 2–3 抽 ＋ 新增场景 × 2–4 抽 ＋ 新增道具 × 1–2 抽` | 角色 11＋道具 9＋场景 9（多件 2–4 抽才定） |
| ③ **字帖** | `新增文本条数 × 1–2 抽` | 26 帖（最终 19 镜挂载） |
| ④ **段故事板** | `段数 × 1–2 抽` | 67 段段卡 |
| ⑤ **镜头** | `镜数 × 3–6 抽`（+ **高风险镜追加 ×2**） | 178 镜；20 次"测试镜额度"（8 九宫格＋12 高风险） |
| ⑥ **OP/ED** | 季一次：`OP 镜数 × 4–6 抽 ＋ ED 镜数 × 4–6 抽`（高风险：坠落/墨浪/扩散类） | OP 24 镜 / 90s＝满时长，禁填充 |

**风险加权**：扩散类/物理反常类镜头（墨浪上涌、局部雨幕、露→泪一镜、同构图"人形留白"缺口）**废片率最高**——**必须预留追加额度并**在制作前备好**降级路径**（如：三帧法→拆两镜；雨幕边界画死→雨只落僧肩）。

### 10.2 可复用素材如何摊薄（剧集的经济命门）

- **一次性投入（季级）**：风格九宫格＋锚图全量＋字帖＋母题素材＋OP/ED → **按集数摊薄**。
- **每集边际成本（EP02 起）**：`本集镜数 × 抽卡 ＋ 新增锚/帖（通常 EP01 已覆盖 70–90%） ＋ 高风险追加`。
- **摊薄算式**（写进季预算表）：`单集均摊成本 = 季固定成本 / N ＋ 单集变动成本`；**N 越大越便宜**——这直接解释了"为什么不能只做一集试水"：**只做一集＝季固定成本全压在一集上**（本项目 29 件锚图＋26 帖＋OP/ED 全部压给 EP01，且因无全季规划，这些成本**无法向 EP02 摊薄**）。
- **复用率指标**：`锚图复用率 = Σ(复用集数−1) / 资产数`；季末复盘必报（低于 0.5 说明资产生产过度定制）。

### 10.3 批量生产（同一批锚图/字帖/母题服务多集）

**"季批先行，集批随后"排产法**：

| 批次 | 内容 | 时机 | 理由 |
|---|---|---|---|
| **B0 圣经批** | 风格九宫格 → 冻结风格 token | 第 0 周 | 不冻结不许开抽（本项目教训） |
| **B1 锚图批** | **全季**所有角色/场景/道具锚**一次性排产** | B0 后 | 一次性冻结 → **跨集漂移最小、单价最低**；同一批还可共用负面词与参考组 |
| **B2 字帖批** | **全季**所有要上屏的文本 → 一次出帖（**同文本去重合并**） | 与 B1 并行 | 帖号跨集唯一；避免每集重出同字 |
| **B3 母题批** | 转场/音效/构图/色彩母题素材 | 与 B1 并行 | 全季复用，重造即浪费 |
| **B4 OP/ED 批** | OP/ED 逐镜（一次做完） | B1 后 | 固定资产、逐集复用 |
| **B5 集批** | 逐集：段故事板 → 镜头 | B1–B4 后按集排 | 集批内可并行多集（各自独立上下文） |

**排产表（写进 `season-outline.md` 末）**：`集号 × {简报, 剧本, 分镜, prompt, 出片, 出口闸, 跨集闸} × 周次`；并标注**更新节奏**（周更/双周更/月更）与**每集可用工时**。

### 10.4 产能与节奏反推

1. **先定节奏，再反推每集预算**：`周更` → 每集可用工期 ≈ 5–6 天（含抽卡等待）；`双周更` → 10–12 天。
2. **每集抽卡预算 = 每集可用抽卡工时 × 单位时间抽卡数**；**预算不足时的削减顺序**（写死）：**削减非钩子镜 → 合并段 → 减少变体数（3→2）→ 降级高风险镜路径**；**不许削减**：锚图/字帖/OP·ED 固定资产、跨集一致性校验、钩子镜。
3. **产能不足的三种正解**：①**放慢更新节奏**（写进大纲）②**减少季集数**（改大纲需重过全季规划闸）③**延长季固定成本摊销期**——**不许**用"跳过圣经/索引/一致性闸"来省时间。

## 十三、与既有铁律的关系（本手册不推翻任何既有条款）

| 既有铁律 | 剧集层的姿态 |
|---|---|
| **无后期原则**（#26） | **不放宽**：口播/对白/字卡/音效一律模型原生生成；失败改法只有改参考组/改措辞/重抽 |
| **动画性纪律**（#28） | **逐集执行**：三层动＋动作动机；动画类剧集每集都必读 `animation-motion-design.md` |
| **文学闸**（#31） | **逐集执行**：动作/情节/回目全过六维；未过闸的动作不得写入 prompt |
| **字帖铁律**（#32） | **全季共用帖库**：同文本同帖；字卡镜无帖不得开抽 |
| **OP 文字白名单**（#33） | **OP 为全季固定资产**：浮空字卡＝0，谶语句一律移正片 |
| **禁亮词/无光之戏**（#34） | **跨集继承**：红线不得因"这集特殊"临时开口 |
| **拍板选项卡**（#8） | 全季规划闸/圣经闸/每集出口闸**一律选项卡＋证据先行** |
| **runs 只放项目**（#15） | 剧集＝一个项目 run（季 slug），下设 `EPnn/`；非项目物不进 runs |
| **知识只进图谱**（#9） | 剧集层知识（跨集一致性经验）走域片段→重建图谱，不新建概念卡 |

**优先级顺序（冲突时）**：**科学/文学/品牌红线 → 全季口径与时长契约 → 色彩配额与专属空间纪律 → 留白与无光之戏 → 运镜白名单 → 动画性设计 → 单集节奏偏好**。
**一句话**：**剧集里，"好看的一集"永远让位于"接得上的全季"。**
