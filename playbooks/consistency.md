# 跨镜头一致性工具箱（Consistency）

> AI 视频最常见的翻车不是单镜难看，而是**镜头之间不像同一条片**：角色变脸、色调乱漂、场景对不上。专业做法是从下面工具箱里组合 2-3 件一起用，而不是指望运气。

## 1. 角色三视图（人物/主持人/吉祥物）

- 开拍前用文生图生成角色三视图（正面/侧面/背面），作为全片角色基准资产
- 之后每个有角色的镜头：以三视图为参考图生成该镜首帧，再图生视频
- 平台对应功能：Vidu 参考生视频、即梦全能参考（@引用）、可灵面部模型/多图参考、Runway Gen-4 References、Sora 角色/cameo

## 2. 首帧锚定（铁律）

**重复出现的角色/场景/设备，绝不用文生视频逐镜碰运气。**
一律：先生成正确静帧（文生图 + 参考图）→ 科学顾问验收（科研片结构必须对）→ 图生视频。

**全能参考类模型（Seedance 2.x 全能参考、即梦全能参考等）的补充**：上传图是"参考资产"而非钉死的首帧，可按需三选一——① 单图参考：画面主体=锚图，prompt 只写运动；② 多图参考：组合多张已有锚图进同一画面，prompt 写清每张取什么（"图片1的光点+图片2的箱体"）；③ 专用首帧：画面含资产库里不存在的元素且构图要求精确时，仍以锚图为参考先生成专用首帧。判断依据：这镜画面和锚图像不像。

## 3. 风格 token 块

全片写死一句风格描述，逐字粘贴进每镜 prompt，例如：
> "冷蓝生物荧光科学可视化风格，体积光，浅景深，8K 超精细"

换平台也带着走（Runway 翻成英文："cold-blue bioluminescent sci-viz style, volumetric light, shallow DoF, 8K ultra-detailed"）。

## 4. 种子复用 + prompt 模板化

- UI 暴露 seed 时：同一镜头的抽卡变体换 seed，满意的镜头定稿后同 seed 微调
- 全片 prompt 用同一模板骨架，只换主体/动作/运镜 clause

## 5. LoRA（硬一致性需求）

- 跨项目复用的主持人/吉祥物/品牌风格：在 LiblibAI 训练角色或风格 LoRA（Wan/SD/FLUX 底模，本地 ComfyUI 亦可）
- 适合系列化内容（日更科普账号、品牌栏目），单条一次性片子不必上 LoRA

## 6. 首尾帧衔接链

- 导出镜头 N 的尾帧 → 镜头 N+1 的首帧，无缝连续
- 可灵首尾帧、即梦智能多帧（≤10 帧串多节拍）、Vidu 多图首尾帧、Pika Pikaframes 都支持
- 首尾帧图之间保持同场景同构图，只改一个元素，否则过渡必崩

## 7. 多镜原生模型

- Seedance 2.x、万相 2.6+、Sora Storyboard、LibTV 分镜节点：一次生成内含多个镜头，主体/场景/氛围天然一致
- 仍要在 prompt 里写明分镜结构 + 风格 token 块

## 8. 后期兜底

- 全片统一 LUT 调色（剪映），掩盖残余色调漂移
- 同一配音音色 + 同一背景音乐风格，听觉一致性会"脑补"掉视觉小瑕疵

## 组合建议

| 项目类型 | 推荐组合 |
|---------|---------|
| 无角色的科学可视化短片 | 3（风格 token）+ 7（多镜原生）+ 8（LUT） |
| 有主持人/角色的科普片 | 1（三视图）+ 2（首帧锚定）+ 3 + 8 |
| 系列化栏目/品牌内容 | 5（LoRA）+ 3 + 6 + 8 |
| 申报片（设备/设施实拍感） | 2（首帧锚定）+ 6（首尾帧链）+ 8 |
