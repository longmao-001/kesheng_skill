## 1. OP/ED 是 C∩B：音乐驱动 ＋ 剧集约束（双层）

OP/ED **同时受两层约束**（这是"交集"的实际含义）：

| 层 | 来源 | 对 OP/ED 的约束 |
|---|---|---|
| **C 层（音乐驱动）** | `playbooks/mv-production.md` | 音乐先行；主产物＝卡点表；无对白；文字白名单；素材复用优先；卡点对齐；留白呼吸 |
| **B 层（剧集约束）** | `playbooks/series-production.md`＋硬规则 #33／#35–#40 | **固定资产·逐集逐秒相等**；登记进圣经 §⑧；跨集红线继承；集尾钩子与追更；跨集一致性门控 |

**判据（一句话）**：**问"这一刀为什么在这里切？"**
- 答＝**"因为歌到这里是重音"** → **C 层生效**（本文与通用手册）
- 答＝**"因为要接住正片开场／因为下集钩子要留悬念"** → **B 层生效**（剧集结构纪律）

> **禁令**：**不得把 C 规则外溢到正片**（正片不按卡点排刀）／**不得把正片规则外溢到 OP/ED**（OP/ED 不编四场脊椎）。**硬规则 #43／#44②**。

### 1.1 挂在哪两关之下（不可自立门户）

OP/ED **不新增关卡**，它挂在剧集通道既有两关之下：

| 挂靠点 | 管什么 | 对 OP/ED 的约束 |
|---|---|---|
| **KSP-E2 风格圣经**（`templates/show-bible.md` §⑧·硬规则 #36） | **资产规格与登记** | OP/ED 的逐镜清单／时长表／主题歌段落／片名·注音·印**必须登记在册**；母题入 §⑦、文字入 §⑥、锚图入 §④⑤——**同一套登记，不另建体系** |
| **KSP-E1 时长预算**（`templates/season-outline.md`·硬规则 #39③） | **时长契约** | OP/ED 秒数＝**季契约**，**逐集逐秒相等**；写进 `templates/series-config.json` 的 `op_seconds`／`ed_seconds`，由 **D-S1** 逐集比对 |

> **纪律**：OP/ED 的任何"新规格"（改时长／改镜数／改文字位）**先入圣经**（`playbooks/series-production.md` §4.5「先入册，后开抽」），**未入册不得开抽**。

### 1.2 剧集侧实证（本项目 EP01）

## 2. 特化一：OP/ED 是固定资产

| 项 | 规定 |
|---|---|
| **性质** | OP/ED ＝ **固定资产**：**时长为先、内容为后**；**一次生产、全季复用** |
| **不是"每集现做"** | 逐镜清单、时长表、主题歌段落（前奏／A段／B段／桥段／副歌／末副歌／末句）、片名／注音／印，**全部写进圣经 §⑧** |
| **排产位置** | **B4 OP/ED 批**（在 B1 锚图批之后、B5 集批之前）——见 `playbooks/series-production.md` §10.3 |
| **每集只替换定制位** | 见本文 §4；**OP/ED 不得"每集现做"**（每集重产＝E-16） |
| **为什么** | 一变长，**素材复用失效 ＋ 观众体感断裂**（"这一集片头好像拖了"）＋ **发布节奏与平台排播无法固化**（承 F-57／E-05） |

**跨集唯一允许的变化**（与 §4 同源）：①**集数提示**（如需"第 N 集"）②**下集预告位**（ED 后 10–20s，用本集素材剪）③**前情提要位**（OP 前，可选）——**这三项之外逐格冻结**。

## 3. 特化二：逐集逐秒相等（时长契约）

| 项 | 规定 | 门控 |
|---|---|---|
| **逐集相等** | **全季所有集 OP/ED 秒数完全相等**，**浮动＝0** | **D-S1**（`scripts/check_series_consistency.py`） |
| **正片** | 允许 ±N% 浮动（推荐 ≤10%） | D-S1（容差内） |
| **契约落点** | `series-config.json`：`op_seconds`／`ed_seconds`／`feature_min_seconds`／`feature_tolerance` | 模板 `templates/series-config.json` |
| **集别定制位** | **每集只允许"集别定制位"可变**（§4） | 圣经 §⑧＋`templates/op-ed-mv-sheet.md` |
| **超限处置** | 浮动超限走**拍板卡 #14**（时长预算）＋**KSP-C** 变更记录 | 硬规则 #39③ |

**为什么浮动＝0**：OP/ED 一变长，**素材复用失效 ＋ 观众体感断裂**＋**发布节奏与平台排播无法固化**（承 F-57／E-05）。

> **与通用手册的关系**：`playbooks/mv-production.md` §4 给出**通道 C 时长与版本矩阵**（横竖版／15–90s／逐片契约）；**本文这一节是它在 C∩B 的收紧形式**——**从"每版各自契约"收紧为"逐集逐秒相等、浮动 0"**。

## 4. 特化三：集别定制位（唯一可变格）

**除下列定制位外，OP/ED 逐格冻结**：

| 定制位 | 例 | 可变性 |
|---|---|---|
| **集号** | "第 N 集"／"EP0N" | 每集变（若采用） |
| **回目小字** | 本集回目（承 `playbooks/series-production.md` §3.4 回目体系） | 每集变（**字形仍锁字帖**） |
| **定制镜** | 1–2 镜"本集专属闪帧"（如本集关键意象一帧） | 每集可换（**Slot 内换素材，Slot 外不动**） |

> **纪律**：定制位**不得挤占契约时长**——定制镜的总秒数**从 OP/ED 自身预算里扣**（不是"加长"），且**换素材不改镜长**（改了镜长＝改了卡点＝违约）。
> **填法**：写进 `templates/mv-beat-sheet.md` **表四·4.2 定制位小表**（集别定制位），并同步 `templates/op-ed-mv-sheet.md`。

| 情形 | 规则 |

| **跨季再版（第 2 季新 OP/ED）** | **允许**，但**必须走 KSP-C** 并**评估对已交付季的影响**（承 #37③"复用不等于冻结"） |

## 5. 特化四：与正片的接法（衔接镜·形态区分）

### 5.1 OP → 正片：衔接镜

- **OP 末镜必须设计为"可接正片开场"的衔接镜**：OP 收在**一个可延续的动作／意象／视线**上，正片开场从它的**结果／反向／同构图**接住。
- **禁"OP 自己讲完一个小故事再切正片"**——OP 的收束是**"进入"**（入戏／入红尘），不是**"结束"**（承 `playbooks/mv-production.md` §七：**OP 是预告，不是正片的摘要**）。
- **核对接续表**：`OP 末镜 → 正片首镜如何接` 逐对写清（写在圣经 §⑧／`templates/episode-brief.md`）。
- **本项目实证**：OP 脊椎「**被携带·入红尘**」（石阵如城·阵末一格空缺→僧道踏雪携石·托石于掌·袖石而去→墨滴入水→群像两拍→落纸→题名）→ 落纸、题名，正片开场以**白话钩／主钩／定场白**（0:00/0:04/0:08）接过。

### 5.2 ED → 下集钩子

- **ED 是回收位**（褪色回放／母题复现／片名改题），**ED 之后**接 ①**下集预告位**（10–20s，用本集素材剪）或 ②集尾钩子（承 #39）。
- **集尾钩子不得消费下一集正片的关键揭晓**（承 #39④）：**钩子给"问题"，不给"答案"**。
- **ED 与钩子的分工写死**：ED ＝ **情绪回收**（回望本集）；钩子 ＝ **向前牵引**（预告下一集）。**两者不得互相顶替**。

### 5.3 同一素材两处形态区分（防"重复看同一镜"）

> **这是 OP/ED 复用最容易被观众发现的漏洞**：同一镜在 OP 出现过，正片又原样出现一次 → 观众体感"这段我看过了"。

**四条纪律**：
1. **"同一镜"不等于"同一素材"**：同一素材在 OP 与正片**必须形态不同**——景别／速度／方向／调性**至少变一项**（换法见 `playbooks/mv-production.md` §3.3 二次构图）。
2. **禁"完全相同镜头"两处出现**：景别＋速度＋方向＋调性**四项全同**＝**重复镜**，验收打回。
3. **OP 优先用"结果镜／局部镜"，正片保留"过程镜／完整镜"**：OP 给**暗示**（局部／结果／剪影），正片给**兑现**（完整过程）——**OP 是预告，不是正片的摘要**（承 #39④：不剧透）。
4. **核对表**：交付前逐条核 `OP/ED 素材 × 正片素材` 重叠项，每项注明**形态差异点**（写进 `templates/mv-beat-sheet.md` 表三"形态区分点"列）。

## 6. 失败模式（剧集 OP/ED 视角·引用本项目实证 E-xx）

> **编号约定**：与 `playbooks/series-production.md` §十一（E-01–E-14）**同用一套 E-xx**；本节＝**剧集 OP/ED 视角**，与 `playbooks/mv-production.md` §八（通道 C 通用视角·E-15–E-19）**同号**——**同一失败在两侧同号，勿另起号**。

## 7. 交付前自检（OP/ED 特化项·10 条）

> **通用 10 条见 `playbooks/mv-production.md` §九／`templates/mv-beat-sheet.md` 末**——本节是**叠加在通用 10 条之上**的剧集特化项。**两组全为"是"才可提交验收。**
