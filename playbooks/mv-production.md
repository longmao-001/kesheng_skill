# 🎵 通道 C · MV／音乐驱动制作手册（横向能力）

> **来源＝用户（甲方）裁定 20260921「能力结构」＋甲方追加裁定（范围升级）**
> **核心裁定**：**MV 不是剧集的分支，而是「通道 C · 横向能力（音乐驱动）」——与通道 A、通道 B 都相交**。

## 0. 一句话定位

**通道 C ＝ 音乐驱动的横向能力**：它以**歌的段落与卡点**为主驱动源，**可以挂在通道 A（广告）上，也可以挂在通道 B（剧集）上**，还可以独立存在（纯单曲 MV）。

**判别式（唯一一条）**：**问"这一段的每一刀为什么在这里切？"**
- 答案＝**"因为歌到这里是重音／段落转换"** → **通道 C**（音乐驱动）
- 答案＝**"因为这里要传递这条信息（说了什么）"** → **通道 A**（文案／信息驱动）
- 答案＝**"因为人物在这里做了这个决定（谁做了什么）"** → **通道 B**（戏剧动作驱动）

> **三种驱动源可以混在同一部片子里，但不能混在同一个段落里**——一个段落只能有一个主驱动源，否则节奏会"两头不靠"（既不像歌，也不像戏）。**硬规则 #43**。**C 段的驱动源写死＝音乐。**

**何时必读**：任何"以歌定节奏"的片子——品牌／产品音乐片、主题曲 MV、活动 MV、音乐营销片、**剧集 OP/ED**、插入歌、角色曲 PV、预告 MV、独立单曲 MV——**在写第一镜 prompt 之前**。

**配套**：卡点表模板 `templates/mv-beat-sheet.md`（**唯一**卡点表模板，通道 C 全档通用）；剧集侧特化实例 `playbooks/op-ed-mv.md`（**通道 C 在剧集的应用实例**）＋填法说明 `templates/op-ed-mv-sheet.md`。

## 一、定位与三形态关系（文案驱动 A／戏剧驱动 B／音乐驱动 C）

### 1.1 三种产物形态 ↔ 三种驱动源（用户裁定原表）

| 形态 | 驱动源 | 属哪条通道 | 主产物 |
|---|---|---|---|
| **口播稿** | **文案／信息**（"说了什么"） | **通道 A** 广告／科普／科研视频 | 口播文案＋分镜＋prompt（沿用既有 `templates/narration-formula.md`、`knowledge/ad-copy.md`、`templates/product-prompt-formula.md` 等） |
| **剧本** | **戏剧动作**（"谁做了什么"） | **通道 B** 剧集正片 | 文学剧本→分镜→prompt（沿用既有 `m4-剧本` 体例、SOP 场景制） |
| **MV／音乐片** | **音乐**（歌的段落与卡点） | **通道 C · 横向能力** | **卡点表＋镜头表＋素材复用清单**（`templates/mv-beat-sheet.md`） |

### 1.2 通道 C 是"横向"的：两个交集 ＋ 一个纯 C

**C 不是一个纵向链路（不新开一条 KSP-E 式通道），而是一条"横向能力带"**——它与 A、B **相交**：

| 归属 | 典型形态 | 主驱动源 | 挂靠的事实源 |
|---|---|---|---|
| **C ∩ A**（广告侧） | **品牌／产品音乐片、主题曲 MV、活动 MV、音乐营销片** | **音乐**（品牌叙事**靠歌承载**，而非口播） | 品牌 VI／产品手册＋**广告法合规**（`scripts/ad_forbidden_words.py`）＋产品精确数据源 |
| **C ∩ B**（剧集侧） | **OP/ED、插入歌、角色曲 PV、预告 MV** | **音乐** | **《风格圣经》**（`templates/show-bible.md`）＋跨集资产复用索引 |
| **纯 C** | **独立单曲 MV** | **音乐** | 自成一体的视觉概念（无 A 的品牌约束、无 B 的剧情约束） |

> **交集的含义**：交集段**同时受两侧约束**——`C∩A` 段**既要"音乐先行"（本手册），又要过广告法合规与品牌 VI（通道 A）**；`C∩B` 段**既要"音乐先行"，又要守圣经与剧集红线（通道 B）**。

### 1.3 C 与 A／B 的边界（不得互相外溢）

**硬规则 #44**：**C 的规则（卡点／文字白名单／无对白）不得外溢到 A 的口播片与 B 的正片**。

| 规则 | 通道 C 段 | 通道 A 的口播段 | 通道 B 的正片段 |
|---|---|---|---|
| **节奏依据** | **歌的卡点** | 文案的信息节拍／钩子结构 | 戏剧动作的因果节奏 |
| **文字** | **白名单**（标题／副题／印／物件字／品牌 lockup 视交集而定） | slogan 卡／产品落版／参数卡／数据卡（TVC 常规语法） | 字幕＝口播逐句；字卡按 #27／#32 |
| **对白** | **无对白**（人声只属于歌） | 口播（有） | 对白／旁白（有） |
| **时长** | **版本契约**（15/30/60/90s；逐集/逐片相等） | 多版本各自唯一（`_archive/` 归旧版） | 单集浮动（容差内） |

> **一句话**：**C 段里没有口播、没有对白**；**A 的口播片与 B 的正片里不按卡点排刀**。混在同一支片子里时，**分段标明主驱动源**（哪段是 C、哪段是 A／B）。

### 1.4 判定与登记（与 A／B 判型的衔接）

**判定问句（KSP-01 同卡完成）**：本片／本段**是否音乐驱动**？

- **是** → 判 `C` 或 `C∩A`／`C∩B`，**写进 `brief.md`**（承 #44②）：写明是 **C∩A** 还是 **C∩B**，以及**哪几段属 C 段**（时间码范围）。
- **否** → 按原有 A／B 判型（承 #42④ 判型先行；**模棱两可默认走 A**）。
- **A／B 项目内出现 C 段**（如广告片尾 15s 品牌音乐段、正片插入歌）→ **标注为 C 段并只对 C 段适用本手册**，**不等于整个项目转成 C**；转 C 走 **KSP-C 记录**。

## 二、音乐先行流程（六步不可跳）

> **总纪律**：**音乐先行**——歌不到终稿，卡点表不出；卡点表不出，镜头表不定；镜头表不定，不写 prompt。**反向做（先排镜头再配歌）＝用错驱动源**，是通道 C 的头号失败模式（见 §八·E-15）。

### ① 词曲（歌词 → 曲 → 编曲）

| 子步 | 产物 | 拍板／闸 |
|---|---|---|
| **①-1 歌词** | 歌词候选（多方案） | 摘用既有文本／原著句子／他人词句时，**必过「歌词／引文闸」**——见 `playbooks/animation-motion-design.md` §2b.4（**先过闸，再谈作曲配唱**） |
| **①-2 曲** | 旋律小样（Demo） | 用户拍板（曲风／人声性别／是否有词） |
| **①-3 编曲** | **终稿音频（唯一事实源）** | **编曲终稿锁定后，波形即为卡点表的唯一依据**——禁"按旧版编曲排镜头、后来换编曲" |

**歌词三问（出卡点表前必须答完）**：
1. **谁在唱**（叙述层／剧中人／品牌代言声线）——**不得混权**（承 #31 六维①：具名角色不得唱非其身份的文本）。
2. **歌词与画面文本重复吗**——同句在片内其他位置的出声点**必须实测标出**（避免"歌里唱过、片子再念一遍"的重复消耗）。
3. **有没有摘用既有文本**（原著句／他人词句／品牌既有口号）——有则**先过闸再作曲配唱**（§2b.4）。

### ② 卡点表（歌曲段落 ↔ 时间码 ↔ 重音／静默点）

> **卡点表＝通道 C 的"剧本"**。它是**主产物**，不是附属表格。落 `templates/mv-beat-sheet.md` 的**表一**。

| 列 | 填什么 | 判据 |
|---|---|---|
| **段落** | 前奏／主歌／副歌／间奏／尾句（细分：A段／B段／桥段／末副歌） | 段落名须与**编曲终稿**段落一致 |
| **时间码** | `mm:ss.s – mm:ss.s`（**起止都写**，0.1s 精度） | 相邻段落首尾相接、**无空档无重叠** |
| **卡点／静默点** | **卡点**＝重音落点（`●`）／**静默点**＝抽空处（`○`） | **静默点必须显式标出**——它是留白与呼吸的依据（§三·留白呼吸） |
| **镜头数** | 该段配几镜（整数） | 与镜头表总行数对账 |

**两条硬纪律**：
- **静默点不许"补镜头"**：歌抽空的那一拍，画面**必须跟着抽空**（停一拍／留白／黑场／极简空镜）——**用镜头填满静默点＝卡点与画面不同源**（E-17）。
- **时间码总和＝契约时长**：`Σ(段落时长) ≡ 版本契约秒数`（**逐秒相等**），误差 0。总和对不上＝卡点表作废重排。

### ③ 镜头节奏（每卡点配几镜·镜头数与节拍对齐）

> 落 `templates/mv-beat-sheet.md` 的**表二**（镜头表）。**先定节奏骨架，再谈画面内容**。

**节奏设计三问**：
1. **每卡点配几镜**？——**重音卡点＝1 刀（1 镜）**；**长音／持续段＝可容多镜**（2–4 镜）；**静默点＝0 刀**（不切）。
2. **镜头数与节拍怎么对齐**？——镜长**按节拍取整**（整拍／半拍），**禁"按感觉随便给秒数"**；同一段内镜长分布应体现"疏—密—疏"的呼吸，而非均匀切分。
3. **总镜数怎么对账**？——`Σ镜头数 ≡ 镜头表实际行数`；剧集侧另须与 `show-bible.md` §⑧ 登记的**镜数**一致。

**节拍—镜长对照（速查；具体 BPM 按歌定）**：

| 音乐事件 | 建议刀数 | 建议镜长 | 理由 |
|---|---|---|---|
| **重音卡点**（鼓／镲／字头） | 1 刀 | 0.5–1.5s（短镜） | 卡点本身就是冲击，短镜交付冲击 |
| **段落转换**（主歌→副歌） | 1 刀（可加 1 过渡镜） | 1.5–3s | 段落切换需要"视觉换气" |
| **长音／延音** | 0–1 刀 | 3–6s（长镜） | 长音要长镜托住，切碎＝疲软 |
| **静默点／抽空** | **0 刀** | 1–2s（不切） | 呼吸位（承 §三·留白呼吸） |
| **尾句收束** | 1 刀 | 收在歌的终点 | 与接法／钩子对齐（§六／§七） |

### ④ 素材盘点（三类来源＝正片/剧集素材复用、品牌资产复用、专用新产）

> 落 `templates/mv-beat-sheet.md` 的**表三**（素材复用清单）。**这一步决定通道 C 的成本**。

**优先级写死（自上而下，不得跳级）**：

| 优先级 | 来源 | 说明 |
|---|---|---|
| **P1 正片／剧集素材复用** | 已产镜头的**同素材变体**（换景别／速度／方向／调性——见 §三·二次构图） | **C∩B** 主力；**达标线 ≥60%** |
| **P2 品牌资产复用** | 品牌 VI 件／官方产品图／官方影像／logo 标准件／已有 campaign 素材 | **C∩A** 主力；**须有授权状态**（无授权只作参考不入镜） |
| **P3 专用新产** | ①**标题字帖**（`refs/锚图/字帖/字帖-<文本>.png`，承 #32）②**印章／印帖** ③**C 段专属空镜／母题转场** ④**P1／P2 覆盖不到时的全新镜** | **仅当 P1／P2 无法覆盖该卡点时才新产**；新产须**逐条写明新产理由**（写进表三"新产理由"列） |

**三条纪律**：
- **素材一律走唯一索引**：复用前**先在 `assets_index.json` 检索**（承 #37「开工先查索引」／#41「入库即标签」）——**索引里查不到＝不许凭记忆重画**。
- **复用素材必须有 sidecar 与 `trace_status`**：`verbatim` 才可复用；`reconstructed` 须显式标注；`missing` **不得用于交付**（承 #41·禁伪造"逐字"）。
- **P3 专用固定资产也要入册**：**C∩B** 入圣经（字帖入 §⑥、母题入 §⑦）**再开抽**；**C∩A** 入品牌资产台账（授权状态＋官方来源）。**未入册即出图＝流程事故**。

### ⑤ 逐镜 prompt（沿用既有门控·不另造一套）

**纪律**：通道 C 的 prompt **不新造体例**，**完全沿用既有链路与门控**：
- 写法＝**单块 SOP 合并块**（`templates/prompt-sop.md` 十步·硬规则 #23／#24）——**禁第二版本 prompt**；
- `@标记贯穿`＋实名上传顺序（硬规则 #25）；
- **无后期**（硬规则 #26·AI 原生路径）：口播／字卡／音效一律模型原生生成，失败改法只有**改参考组／改措辞／重抽**；**有专业后期时改"AI 原生优先，专业后期为可选增强"**；
- **字帖铁律**（硬规则 #32）：**字卡镜无帖不得开抽**（**C∩A 的品牌名／产品型号／参数数字同样须先用字帖锁字形**，见 §六）；
- **OP 文字白名单**（硬规则 #33）：**仅 C∩B 的 OP/ED 段**适用；**C∩A 允许 slogan 卡／产品落版／参数卡／品牌 lockup**（TVC 常规语法）；
- **禁亮词**（硬规则 #34·仅无光源风格项目）：水墨／版画类项目按替换词表；
- **动画性纪律**（硬规则 #28·动画类项目）：三层动＋`动作动机＝…`；**C 段的"动作动机"要指向音乐**（如 `动作动机＝副歌重音处的鼓点，托起"入红尘"的意象`），**不是指向剧情因果**。

**机器门控**：`scripts/check_prompt_delivery.py`（D1–D13）＋ `scripts/check_prompt_sop.py` ＋ `scripts/check_prompt_sheet.py`。

### ⑥ 装配与验收

| 步 | 动作 | 门控／判据 |
|---|---|---|
| **⑥-1 装配** | 按卡点表把镜头对上时间码；**逐卡点核刀**（每刀落点＝卡点表标的重音） | 卡点表 ↔ 时间轴**逐点对齐**（不对齐＝E-17） |
| **⑥-2 时长核** | `实测秒数 ≡ 版本契约秒数` | **逐片/逐集相等**；剧集侧 **D-S1**（`scripts/check_series_consistency.py`） |
| **⑥-3 文字核** | 画面内文字**全部属白名单**（按交集定白名单口径） | 硬规则 #33（C∩B）／广告法合规（C∩A） |
| **⑥-4 素材核** | 逐镜素材**在索引中可查**、`trace_status` 非 `missing`；品牌资产**授权状态齐** | `scripts/check_asset_labels.py` |

## 三、MV 语法（七条）

### 3.1 卡点对齐

- **每一刀都要有音乐理由**：刀的落点＝卡点表上的「卡点／段落转换／尾句」。**"这里需要换个画面"不是理由**。
- **卡点密度决定镜头密度**：副歌卡点密 → 镜短、刀多；主歌卡点疏 → 镜长、刀少。
- **对齐是可核的**：镜头表的"时间码＋镜长"与卡点表的时间码**逐行可对**——两表对不上＝验收不过。

### 3.2 母题回环

- **同一动作／意象在片中两处呼应**（C∩B：**OP 出现、ED 回环**；C∩A：**主歌出现、末副歌回环**）——观众靠这个认出"同一支片子"。
- **回环必须是"可辨认的同一语法"**：同一构图换材质 ✓／换语法 ✗（承 `playbooks/series-production.md` §4.2 母题纪律：**宁少勿滥、复用必须可辨认、禁止无功能复现**）。
- **复现须显式声明**：写 `【复现·回环】` ＋依据 ＋限次。

### 3.3 素材复用与"二次构图"

**同一素材换形态＝"二次构图"**（成本≈0，是通道 C 的性价比核心）。**四种换法**：

| 换法 | 做法 | 风险 |
|---|---|---|
| **换景别** | 同素材裁切／推近／取局部 | 分辨率下限——**不达标的素材不做大推近** |
| **换速度** | 同素材变速（慢放／加速／速度斜坡） | 变速后**卡点必须重对**（速度变了，落点也变） |
| **换方向** | 水平镜像／翻转 | **含文字的镜头禁镜像**（字会反）；**含 logo／印章的镜头禁用**（品牌形制不得镜像） |
| **换调性** | 同素材褪色／抽色／加母题转场 | 色板须在圣经配额（C∩B）或品牌色规范（C∩A）内 |

> **纪律**：**二次构图不是"重复用同一镜"**——同一个"镜头（完全相同的景别＋速度＋方向＋调性）"**不得在两处出现**（见 §七·形态区分）。

### 3.4 留白与呼吸（禁卡点轰炸）

- **静默点必须留白**：歌抽空的那一拍，画面跟着抽空——**停一拍／留白／黑场／极简空镜**。
- **禁"每秒一刀"**：全程卡点轰炸＝**观众疲劳**，且把"卡点"降级成"平均切分"（听起来像 PPT 翻页）。**疏密相间才是节奏**。
- **留白与既有风格纪律并存**：水墨留白／无光之戏（#34）／运镜白名单／色彩配额**不被 MV 语法推翻**，MV 语法在其内部生效。

### 3.5 无对白

- **C 段内无对白／无旁白（口播口径下"无口播"）**：人声**只属于歌**。
- **旁白移出 C 段**（C∩B 本项目裁定：OP 内人声＝0 句，旁白落正片开场）；**C∩A 的品牌主张由歌承载**，不另配口播（否则＝用文案驱动做音乐片）。
- **不得混权**（承 #31 六维①）：具名角色／代言声线不得说唱非其身份的文本。

### 3.6 文字白名单

**分交集定白名单（不得一刀切）**：

| 交集 | 白名单（画面内允许的文字） | 禁 |
|---|---|---|
| **C∩B（剧集 OP/ED）** | ①**片头标题字**（片名＋注音副题＋落印）②**物件上的字**（玉面镌字／石面刻字／印章） | **浮空字卡／诗句字幕／谶语逐字上屏**（一律移入正片）——硬规则 #33 |
| **C∩A（品牌音乐片）** | ①**品牌 lockup／产品名落版**②**slogan 卡**③**参数卡／数据卡**④**物件上的字**（产品机身刻字／包装字） | 与产品真实形制不符的自造字样；**精确数据必须逐字＝手册原文**（承 #16④） |
| **纯 C（独立 MV）** | ①**曲名／歌手名**②**歌词作为设计元素**（若采用，须过歌词／引文闸）③**印章／物件字** | 自创文案（无出处）；解说性字幕（＝退化成图文排版） |

**执行四条**（承 #33，C∩B 照原文执行）：
1. **判定"该不该有字"先于"字怎么写"**——白名单外的文字**一律删出**，改写为「**本镜无字卡，纯视觉意象**」；
2. **prompt 正文（【时间轴】）里连"字卡"这个词都不要出现**（正文提"字卡"＝招字的诱因），禁字只写进【负面】；
3. **字卡镜清单与字帖清单同步**——被删出的镜**移出 `text_card_shots`**（照**非字卡镜**分档），并联动字帖清单；
4. **机器门控 D12**（`scripts/check_prompt_delivery.py`）——OP 条目／段块的【时间轴】禁「字卡／逐字书写／字位书写／字卡位／字幕」等字样。

### 3.7 禁卡点轰炸（与留白配对的独立禁令）

- **不得用"密集卡点"冒充"节奏好"**：卡点轰炸**同时毁掉"留白"和"卡点"**——每次都卡＝没有一次是重音。
- **硬指标（自检用）**：**静默点留白率＝100%**（每个 `○` 都必须有画面侧的呼吸响应）；**相邻两刀最小间隔 ≥ 0.5s**（除刻意"三连击"设计，且须在卡点表注明）。

## 四、时长与版本（横竖版、15/30/60/90s、逐集/逐片时长契约）

### 4.1 版本矩阵（C∩A 常有多版本；C∩B 为固定资产）

| 项 | 规定 |
|---|---|
| **画幅版本** | **横版 16:9**（主版）／**竖版 9:16**（社媒）；**同一条歌可出两版**，但**卡点表共用一份**（时间码同源，只改构图与安全区） |
| **时长版本** | **15s／30s／60s／90s**（按平台与投放位选）；**每版各自唯一契约秒数** |
| **版本纪律** | **卡点表以最长版为准**（母表），短版＝**母表的节选＋重收尾**（**不得另排一套卡点**）；短版删段**不得破坏母题回环**（回环位优先保留） |
| **C∩B（剧集 OP/ED）** | **固定资产·逐集逐秒相等**（浮动＝0）——见 `playbooks/op-ed-mv.md` §四 |
| **纯 C** | 按歌的自然时长（不裁歌）；**歌变长＝重排卡点表**（不是拉伸镜头） |

### 4.2 时长契约的落点

- **C∩B**：写进 `series-config.json` 的 `op_seconds`／`ed_seconds`，由 **D-S1** 逐集比对（`scripts/check_series_consistency.py`）。
- **C∩A／纯 C**：写进 `brief.md`（多版本各自唯一，承 #40 限定语：**每个版本内部只有一份定稿**，旧版归 `_archive/`）。
- **超限处置**：走**拍板卡 #14**（时长预算）＋ **KSP-C** 变更记录。

### 4.3 为什么时长是契约而不是"感觉"

**时长一变，卡点全废**：歌的段落结构不变，但"每段分到几秒"变了 → 镜头表要重排、素材复用清单要重算、**素材复用失效＋观众体感断裂**（"这次片头好像拖了"）。故：**时长为先、内容为后**。
