> prompt 工程师的工作手册。平台迭代快，时长上限/模型版本号以用户当前 UI 为准；**prompt 公式是稳定的**。
>
> **⚠️ 交付口径先读 §〇**（红楼梦EP01·用户裁定 20260915）：**交付格式＝单一 SOP 合并块**（禁止另写"平台 prompt"第二版本）、**@标记贯穿**、**无后期原则**、**镜头连贯性**、**空间与色彩专属铁律**——这五条是交付判废项，优先于本节以下的平台语法内容。

## 〇、交付格式与口径铁律（红楼梦EP01·用户裁定 20260915）

> 本节五条来源＝**红楼梦EP01·用户裁定 20260915**，是"每镜 prompt 怎么交到用户手里"的写死规则。**机器门控**：`scripts/check_prompt_delivery.py`（D1 字段完整／D2 @标记贯穿／D3 负面同块／D4 禁词／D8 后期表述归一）。

### 0.1 交付格式＝单一 SOP 合并块（**禁止再另写"平台 prompt"第二版本**）

- **正文即一个合并块**：`【参考】【风格】【时间轴】【口播】【声音】【负面】` ＋「参数」**合并为同一个代码块**——**整块复制即用＝终稿**。
- **负面词内嵌同块末尾**（`【负面】：…` 写在同一个代码块内），**禁止另起一个代码块/另起一节放负面**。
- **⛔ 禁止再另写"平台 prompt"第二版本**（如 `【视频prompt】` /「平台prompt」/「对照」等第二条成句版本）：**两套写法＝用户困惑源**（用户不知道复制哪条、两条不一致时以谁为准）。**同一镜只有一条可复制文本**。
- **平台差异处理方式**：平台差异**不靠第二条 prompt 表达**，而是——
  - 一个平台一个文件（`prompts-<平台>.md`，见 `templates/prompt-sheet.md` §一）；
  - **平台词序按 §分平台公式**在**同一块内**调序即用（如海螺把运镜方括号置顶、即梦把运镜放句首），**不产生第二条文本**；
  - 需要说明时写在代码块**外的散文行**（说明不是 prompt 本体，用户不复制）。
- **判据**：一镜出现两个可复制 prompt 块 ＝ D1/交付格式判废；负面在代码块外 ＝ **D3 WARN→整改**。机器门控：`scripts/check_prompt_delivery.py` **D11 交付格式**（**默认关，项目如需硬拦"第二版本"在 run 内配置 `check_second_prompt=true`**）＋ D1/D3；项目专属词表（专属空间标记/字卡镜号/校勘红线/动画阈值）走 `runs/<项目slug>/prompt-delivery-config.json`，用法见 `scripts/README-check_prompt_delivery.md`。

### 0.2 @标记贯穿 ＋ 上传顺序映射（禁"指代与正文脱节"）

- **素材指代段与正文各镜头必须同步使用 `@图片N`**：**禁止**"素材指代段只写 `图片2`、正文另写'取自图片2'的脱节写法"。
- **【参考】字段逐条写实名＋取放**：`@图片N=实际文件名（取哪→放哪）`
  例：`@图片3=C3a-僧道仙形-主锚-第1抽.jpeg（取全身轮廓→放画面中央偏左中景）`
- **字段末另起一行写上传顺序**：`（上传顺序：@图片1=<实际文件名>；@图片2=<实际文件名>；…）`
- **实名来源**：以项目《参考挂载对照表》与实际 `refs/` 文件名为准；**库内未生成的件须标【库内未生成·待补 对照表§N】**——**禁止编造文件名**；编号只能靠参考字段顺序推定的，行末标 `（编号依参考字段顺序推定）`。
- **每个参考的用途与落位，在正文含 @ 引用处一并交代**（不能只在参考字段说用途）。
- **判据**：提到 `图片N` 而全文无 `@图片N` ＝ **D2 FAIL**；只写 `@图片N` 不带角色/取哪放哪 ＝ **裸引用 FAIL**（见 `templates/prompt-sop.md` 步3）。

### 0.3 无后期原则（口播/对白/字卡/音效一律模型原生生成）

- **口播、对白、字卡、音效一律由视频模型原生生成**——写进**时间轴**（含口吻与秒位）与音频符号（`{台词}`／`(音乐)`／`<音效>`／`【字幕】`）。
- **⛔ 禁止任何"后期"表述**：**后期配音／后期叠／后期合成／后期贴字／后期字卡／后期遮罩／后期转场／后期LUT** 等一律禁止。
- **⛔ 禁止把"后期合成"写成失败降级路径**（如"若生成不出就后期合成"）——**失败改法只有三种**：**改参考组／改措辞／重抽**。**项目中不存在任何后期工序**。
- **表述归一（D8 机器门控）**：

| 旧表述（禁止） | 归一为 |
|---|---|
| 后期配音 / 后期音轨 / 后期贴尾腔 | **声音工序处理**（`＋尾腔（声音工序处理）`）；口播音轨由模型原生生成 |
| 后期贴字 / 后期字卡 / 后期压印 / 后期板 | **字卡（印文）含于 prompt 由模型原生生成** |
| 后期贴片 / 后期做（字、灯点、道具等非字件） | **含于 prompt 由模型原生生成** |
| 后期遮罩 / 后期字幕 / 后期转场 / 后期插入 / 后期裁掉 / 后期跳接 | **剪辑遮罩 / 剪辑字幕 / 剪辑转场 / 剪辑插入 / 剪辑裁掉 / 剪辑跳接** |
| 后期 LUT / 后期调淡 / 后期统一 / 后期动效 / 后期层 / 后期框 | **剪辑 LUT / 剪辑调淡 / 剪辑统一 / 剪辑动效 / 剪辑层 / 剪辑框** |
| 全后期 / 留待后期 | **含于 prompt 由模型原生生成** |

> **例外（不判 FAIL）**：**规则自述行**（本表、"禁用后期表述"条文本身）与**变更／废止／禁止／作废 记录行**不受此限。
> **剪辑工序不是后期工序**：剪辑层/剪辑转场是**剪辑台**上的合法动作，写"剪辑 X"合规；写"后期 X"违规。

### 0.4 镜头连贯性（连续运动镜＝一镜到底＋机位跟随主体）

- **连续运动的镜头一律写**：**"一镜到底＋机位跟随主体"**。
- **⛔ 禁止引用"格 N"作为分段单位**——引用格号＝**诱发切镜**（模型按格切），是动镜被切碎的根因。
- **多图参考的动镜以 3–6 张为宜**，且**每张明确分工**：**顺序参考／造型参考／质感参考／结构参考／版式参考**（每张在【参考】字段写明"取哪→放哪"与承担的职责）。
- **故事板在动镜 prompt 中降为"节拍／顺序参考"**，并须注明 **"运镜必须连续，绝不分切"**。
- 与 `playbooks/animation-motion-design.md` 配套：连贯性管"不切"，动画性管"在演"——**两者同时成立才是合格动镜**。

### 0.5 空间与色彩专属铁律（专属标记与色彩语义须逐段负面钉死）

- **专属空间标记不得串场**：凡某空间标记是**某段专属**（如"**墨浪＝某段专属空间**"），则**其他各段一律不得出现**——**须在各段【负面】钉死**（例：`墨浪, 海浪, 波涛, 水纹`），且**各镜参考组与画面描述也不得出现**该标记（改挂该段自己的场景锚）。
- **色彩语义须钉死**：凡有语义的色彩（如"**某色＝劫／幻／情**"、"唯一不褪之某色"），须：
  1. **逐段负面钉死禁用范围**（如 `蓝色水彩, blue watercolor, blue sky, cyan`）；
  2. **写明豁免条款**（哪一段／哪一镜例外、限在哪几镜几格、是否限定占比）；
  3. **配额写死**（如"某色 ≤N% 画面、只色不发光"）。
- **优先级**：色彩配额与专属空间纪律 **优先于** 动画性设计与运镜偏好（冲突时动画性让步，见 `playbooks/animation-motion-design.md` §七）。
- **判据**：跨段出现他段专属标记 ＝ 红队前置闸 FAIL；色彩语义无负面钉死/无豁免条款 ＝ 打回。

### 0.6 字卡镜／非字卡镜负面对照（第4条摘要，全文见 `playbooks/animation-motion-design.md` §4.3）

| 镜型 | 【负面】写法 | 理由 |
|---|---|---|
| **字卡镜**（时间轴/口播含 回目／谶文／定场诗／片名／印文／镌字 者） | 钉 **`简体字, 字形残缺, 字形错误`**；**移除** `文字/题字/text/calligraphy/characters` 类禁项 | 该镜**该有字**——禁"文字"会与"字卡由模型原生生成"自相矛盾 |
| **非字卡镜** | **保留** `文字, 印章, 题字` | 该镜**不能有杂字** |

> 逐镜判断，**不得一刀切**；字卡镜时间轴还须写"**逐字书写而出**"（禁 弹出／叠加／上屏）。机器门控 D9（负面分档）＋ D10-d（书写性）**两项同时满足才算过**。

#### 0.6.1 分档之前先分「该不该有字」——OP 段文字白名单（甲方裁定A 20260915）

| 段位 | 文字纪律 | 负面写法 |
|---|---|---|
| **片头／OP 段** | **画面内禁浮空字卡／诗句字幕**；只允许 ①**片头标题字**（片名＋注音副题＋落印）②**物件上的字**（玉面镌字／石面刻字／印章）。谶语／诗词句的逐字上屏**移到正片** | 照**非字卡镜**档：`文字, 字幕, 字卡, 浮空字卡, 题字, 书法, 印章`（+ 动画性禁项） |
| **正片字卡镜** | 照 §0.6 上文：书写性 + 字帖 + 字形类负面 | 钉 `简体字, 字形残缺, 字形错误` |

> **prompt 正文（【时间轴】）里连"字卡"这个词都不要写**——正文提"字卡"＝招字的诱因；禁字只进【负面】，正文只写"本镜纯视觉意象"。机器门控 **D12** 硬查此项（白名单词：片名／注音／印章／落印／玉面／玉背／镌字／印文／石面刻字，**同句豁免**）。

#### 0.6.2 「无光之戏」＝禁亮词（甲方裁定B 20260915）

- **水墨无光源**：正文禁 「**一亮／发亮／闪光／高光／辉光／反光／发光**」等**正面**亮词；**变化只能用墨的语言**——**渐浓／渐沉／洇开／褪淡／沉深一分／退回原色**。
- **替换表**：一亮／发亮→沉深一分／墨色渐浓；闪光→洇开一瞬；高光／辉光→焦墨凝住；反光→映墨（"积水**映墨**"）；发光（正面）→渐浓／褪淡。
- **负面补钉 6 词**：`一亮, 闪光, 高光, 辉光, 反光, 发光`（与既有英文 `glowing gold／light rays／lens flare` 同源合流）。
- **不误伤**：**否定式是正确写法、一律保留**（"只色不发光"／"无瞳孔高光"／"绝无高光"／"无金属反光"）；**负面禁项枚举**与**判废／失败改法／参数／台账等 QC 行整行豁免**。机器门控 **D13**。

## 通用公式（所有中文平台收敛于此）

```
主体(描述) + 动作/运动 + 场景(描述) + 镜头语言(景别+运镜+视角) + 光影 + 风格/氛围
```

一条连贯自然的话。具体名词、物理上合理的运动。**禁用抽象词**："电影感""高级感""震撼"——全部替换成具体视觉事实。

## 分平台公式与范例

### LibTV（LiblibAI 视频工作台）

节点画布工作流，后端模型可选（Seedance 2.x / 可灵 / MiniMax 等）——**prompt 按所选后端模型的公式写**。优势在流程：剧本节点→分镜节点→视频节点，分镜图直接作为视频节点的首帧参考。团队版有共享资产库。适合整条片的生产线；prompt 层面无独立语法，看下面具体后端。

### 可灵 Kling

- 文生视频：`主体(主体描述) + 运动 + 场景(场景描述) + (镜头语言 + 光影 + 氛围)`
- 图生视频：`主体 + 运动，背景 + 运动`（**只写运动，不复述画面**）
- 有独立负面 prompt 字段；支持首尾帧、运动笔刷、视频延长、面部/多图参考
- 范例（文生视频）：
  > 一条发光的 DNA 双螺旋在幽暗的核内空间中缓慢旋转，两条链解旋分开，碱基对逐个点亮荧光；背景是深蓝色的细胞核内部，漂浮着微小蛋白颗粒；中景缓慢推镜头推进至螺旋特写，浅景深；冷色生物荧光照明，体积光；科学可视化风格，精密、神秘
  > 负面 prompt：变形，文字，水印，模糊

### 即梦 Jimeng（Seedance 引擎）

- 运镜公式：`【运镜动作】+【节奏/速度】+【景别/角度】+【主体/场景】+【画质/氛围】`
- 运镜放前面；运镜 ≤2-3 个；支持首尾帧、智能多帧（≤10 帧）、全能参考（@ 引用最多 12 个参考文件：`主体是@图1中的……`）
- 范例：
  > 缓慢推镜头，匀速，由中景推至特写：一台透射电子显微镜的物镜下方，病毒样品的截面图像在屏幕上逐层显现，实验室冷白色顶光，金属质感，高清写实，4K。运镜平稳，无抖动。

### Vidu

- 公式：`主体 + 场景细节 + 镜头运镜 + 动态效果 + 风格氛围`
- 招牌是**参考生视频**：上传角色/道具参考图，prompt 只写新动作新场景（"同一主体，全新故事"）
- 范例（参考生视频，上传研究员角色图后）：
  > @图1中的女研究员在超净工作台前操作 CRISPR 试剂盒，移液器精准点样，镜头缓慢横移环绕工作台，冷色无影灯照明，纪实科教风格。

### 海螺 Hailuo / MiniMax（Director 模型）

- **运镜指令必须放在 prompt 最开头**，方括号包裹，**最多 2 条**，英文逗号分隔
- 范例：
  > 【推进，轻微上升】镜头穿过培养皿液面，缓慢逼近一个正在分裂的干细胞，细胞膜凹陷、缢裂成两个子细胞，显微摄影质感，暗场照明，科学纪录片风格。

### Runway Gen-3/4（英文）

- 结构：`[camera movement]: [establishing scene]. [additional details]`
- 关键词家族：camera（low angle / overhead / FPV）、lighting（diffused / silhouette / lens flare）、speed（slow motion / hyperspeed）；Gen-4 References 做角色一致性
- 范例：
  > Slow motion dolly-in: a ribosome assembles a glowing polypeptide chain inside a translucent cell, bioluminescent blues, volumetric light, macro cinematography, shallow depth of field. Diffused lighting, sterile laboratory ambience, photorealistic CGI.

### 通义万相 Wan

- 官方 7 要素词典：景别 / 视角 / 镜头 / 运镜 / 速率 / 氛围 / 风格，按要素组装
- 首尾帧 API：传首帧+尾帧图，prompt 只写运动
- 范例（图生视频，首帧=显微照片）：
  > 镜头匀速推进，载玻片上的水熊虫缓慢爬行，腿部划水动作清晰，其余画面元素保持静止，显微摄影，侧光，纪录片氛围。

### Seedance 2.0 / 2.5（火山引擎，官方文档核实版）

> 多镜分镜模板（时间轴公式、产品展示/动效/延长/编辑模板、@引用语法、氛围关键词库）见 `knowledge/seedance-template-library.md`。

LibTV 和即梦 Pro 的核心后端。**团队统一按 2.5 写法**（整数秒时间戳）；2.0 仅为旧后端兼容说明：

| 项 | 2.0 | 2.5 |
|---|---|---|
| 单次时长 | 4-15s | **4-30s，可多轮延长**（⚠️ 单次生成 ≤30s；时间轴总长超 30s 必须分段+延长，见"长镜头分段生成"流程） |
| 参考素材 | 共 15 个（9 图+3 视频+3 音频） | 共 50 个（30 图+10 视频+10 音频），新增纯音频参考 |
| 分辨率 | 480p / 720p / 1080p / 4K（标准版） | **仅 480p / 720p**（暂时倒退；第三方"2.5 原生 4K"与官方文档矛盾） |
| 时间控制 | **响应整秒分段**（`0-2秒…2-5秒…`，按段理解节奏，实测有效）；不响应秒以下精调；也可用"镜头 N"序号 | 响应整数秒时间戳（`0-3s…3-7s…`，时间轴必须连续） |
| 画幅 | 6 档固定 | 6 档 + `adaptive`（编辑/延长/首尾帧任务必须用 adaptive） |

**参考素材语法**：上传后按同类素材顺序用 `图片1`/`视频1`/`音频1`（或 `@图片1`）指代；任务关键词决定任务类型——
- 参考生新视频：`参考图片1中的主持人，生成…` / `参考视频1的环绕运镜`（部分参考要写清参考哪一部分：`参考视频1中施法的动作，视频2的环绕式运镜`）
- 编辑：必须含「编辑/增加/删除/修改/更换/改成」之一，且直接写 `视频1`，**不要写"参考视频1"**（会被误判为参考任务）
- 延长：必须含「向前/向后延长/续写」之一
- 音频符号：`{台词}`、`(音乐)`、`<音效>`、`【字幕】`；非中英台词标语种

**多镜头写法**：2.0 用 `0-X秒` 整秒段（时间轴公式，按段理解节奏）或"镜头1/镜头2/…"按事件顺序（每镜四要素：运镜+主体动作+空间变化+音频，段粒度理解，不响应秒以下精调）；2.5 可用镜头序号或整数秒时间戳，单镜只指定 1 种运镜。官方推荐结构：素材指代 → 一句话概述（主体+地点+事件+风格）→ 分镜逐段 → 贯穿性约束收口。

范例（2.5，15s，3 镜科普片）：
```
一句话概述：微观科学科普短片，写实科教纪录片风格，电影级光影。
镜头1（0-5s）：大全景，傍晚的生物实验室，暖色顶灯，镜头缓慢推近实验台，穿白大褂的研究员俯身调节显微镜，<离心机低鸣声>。
镜头2（5-10s）：特写切至显微镜目镜视野，细胞样本在视野中缓缓漂移，焦点从细胞壁平滑移到细胞核，研究员画外音说道{看，这就是线粒体}。
镜头3（10-15s）：镜头推进细胞内部转为3D分子动画，蛋白质链缓缓折叠、ATP分子亮起蓝色辉光，镜头环绕分子半圈后定格，（轻柔的钢琴环境乐渐起）。
全程写实科教风格，画质高清、细节丰富；人物面部稳定不变形；保持无字幕、不要生成Logo、不要生成水印。
```

**Dos**：运镜直写标准术语（推/拉/摇/移/跟/环绕/一镜到底/希区柯克变焦/FPV/子弹时间）；动作写肢体部位+幅度力度（`缓慢抬手、微微低头`）；情绪用具象身体细节（✅"眼眶泛红、手指无意识攥紧衣角" ❌"很悲伤"）；人物参考大头照+全身照分开给；素材 4-5 个为宜，别用满上限。

**动感三来源（广告片强制自检）**：① 运镜——单镜 ≤2 种，但要用**变速**（由快到缓收稳/骤然放缓/急速俯冲急停悬停）和**复合运镜**（环绕+上升、推近+旋转）；② 画面内部运动——光扫/粒子/前景遮挡物掠过/元素展开；③ 剪辑节奏——动作匹配剪辑（环绕动势接推近动势）、快慢相间。只写"缓慢推近"的匀速单运镜=PPT 式视频，不合格。
> **⚠️ 动画类项目（红楼梦EP01·用户裁定 20260915）**：**动感三来源是底线，不是达标线**——动画／动漫／角色戏一律再加 **三层动（主体表演＋次级运动＋动作曲线）＋ 动作动机（动作不是装饰，是台词）**，见 `playbooks/animation-motion-design.md`；只满足"动感三来源"仍可能是 PPT 式视频。

**Don'ts（官方失败模式）**：2.0 别写秒以下的精确控制（停顿 0.3 秒/微秒级不响应——用整秒段 `0-2秒…2-5秒…` 或镜头N）；单镜别堆多种运镜；别把完整剧本直接当 prompt（要精简）；台词别中英混用，多音字换同音常用字；人物多视图合一参考在 2.0 易 ID 漂移（官方对宫格分镜参考的建议：≤15 格、火柴人/线稿为宜；要严格对齐逐格用关键帧写法 `以图片1至图片7的顺序作为关键帧…`）；别直接多次续写模型产物（画质叠加劣化，官方建议先转纯白 3D 模型视频再续写）；剪映拼接防跳变：前段末尾减 6 帧、后段开头减 1 帧；**真人脸参考图会被审核直接拦截**——用授权素材/虚拟人像/线稿分镜规避（见 `playbooks/storyboard-grid.md`）。

## 负面 prompt 清单（按需要选，用具体排除项）

```
变形，扭曲，多余的手指，面部扭曲，文字，字幕，水印，logo，
模糊，低清晰度，抖动，画面撕裂，闪烁，过曝，死黑，卡通化（写实片用）
```

不写空泛的"不要/避免"，要给具体排除项。

**字卡镜／非字卡镜分档（红楼梦EP01·用户裁定 20260915）**：负面**不是一刀切**——**字卡镜**钉 `简体字, 字形残缺, 字形错误`（该镜该有字）；**非字卡镜**保留 `文字, 印章, 题字`（该镜不能有杂字）。写法与理由见 §0.6。

**动画类项目必加的 7 项（红楼梦EP01·用户裁定 20260915）**：`静止帧, 幻灯片式切换, 元素瞬间闪现, 匀速无变化, 画面定格, 与叙事无关的空洞特效, 无意义的风吹草动`（见 `playbooks/animation-motion-design.md`）。

## 常见失败 → 修复

| 失败 | 修复 |
|------|------|
| prompt 又长又密，出来四不像 | 砍到 1 主体 + 1 动作 + 1 运镜 |
| 堆了多个运镜，镜头乱飞 | 运镜 ≤2 个 |
| 全是抽象形容词 | 每个抽象词换成一个具体视觉事实 |
| 图生视频里复述画面内容 | 只写运动；画面交给首帧图 |
| 首尾帧差异太大，过渡崩坏 | 保持同场景同构图，只改一个元素 |
| 手部/多人互动穿帮 | 简化成单主体；或用参考图/表演迁移 |
| 跨镜风格漂移 | 按 `playbooks/consistency.md` 上锚定组合 |
| **同一镜交付两套 prompt（SOP 块＋"平台prompt"）→ 用户困惑** | **只留一条可复制文本**（§0.1）：SOP 合并块即终稿，平台差异靠"一平台一文件＋块内词序"表达 |
| **素材指代写 `图片2`、正文另写"取自图片2"→ 挂错/对不上** | **@标记贯穿**：指代段与正文同步 `@图片N=实际文件名（取哪→放哪）`＋另起一行上传顺序（§0.2） |
| **失败改法写"不行就后期合成"** | 后期路径**不存在**：改法只有 **改参考组／改措辞／重抽**（§0.3） |
| **只写运镜不写主体表演 → PPT 感** | 时间轴先写"主体在做什么"（三层动 a/b/e），见 `playbooks/animation-motion-design.md` |
| **动效无动机 → 空洞** | 每镜写 `动作动机＝…`（对应台词/谶语/情绪），无动机的动作删 |
| **动镜用"格1/格2/格3"分段 → 被切成幻灯片** | 改"一镜到底＋机位跟随主体"＋注明"运镜必须连续，绝不分切"（§0.4） |
| **他段专属空间标记/色彩串场** | 各段【负面】钉死专属标记与色彩语义＋写明豁免条款（§0.5） |
