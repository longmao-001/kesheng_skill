# 各平台 AI 视频 Prompt 手册（Platform Prompts）

> prompt 工程师的工作手册。平台迭代快，时长上限/模型版本号以用户当前 UI 为准；**prompt 公式是稳定的**。

## 通用公式（所有中文平台收敛于此）

```
主体(描述) + 动作/运动 + 场景(描述) + 镜头语言(景别+运镜+视角) + 光影 + 风格/氛围
```

一条连贯自然的话。具体名词、物理上合理的运动。**禁用抽象词**："电影感""高级感""震撼"——全部替换成具体视觉事实。

## 分平台公式与范例

### LibTV（LiblibAI 视频工作台）

节点画布工作流，后端模型可选（Seedance 2.x / 可灵 / MiniMax 等）——**prompt 按所选后端模型的公式写**。优势在流程：剧本节点→分镜节点→视频节点，分镜图直接作为视频节点的首帧参考。团队版有共享资产库。适合整条片的生产线；prompt 层面无独立语法，看下面具体后端。

### 可灵 Kling

- 文生视频：`主体(主体描述) + 运动 + 场景(场景描述) + (镜头语言 + 光影 + 氛围)`
- 图生视频：`主体 + 运动，背景 + 运动`（**只写运动，不复述画面**）
- 有独立负面 prompt 字段；支持首尾帧、运动笔刷、视频延长、面部/多图参考
- 范例（文生视频）：
  > 一条发光的 DNA 双螺旋在幽暗的核内空间中缓慢旋转，两条链解旋分开，碱基对逐个点亮荧光；背景是深蓝色的细胞核内部，漂浮着微小蛋白颗粒；中景缓慢推镜头推进至螺旋特写，浅景深；冷色生物荧光照明，体积光；科学可视化风格，精密、神秘
  > 负面 prompt：变形，文字，水印，模糊

### 即梦 Jimeng（Seedance 引擎）

- 运镜公式：`【运镜动作】+【节奏/速度】+【景别/角度】+【主体/场景】+【画质/氛围】`
- 运镜放前面；运镜 ≤2-3 个；支持首尾帧、智能多帧（≤10 帧）、全能参考（@ 引用最多 12 个参考文件：`主体是@图1中的……`）
- 范例：
  > 缓慢推镜头，匀速，由中景推至特写：一台透射电子显微镜的物镜下方，病毒样品的截面图像在屏幕上逐层显现，实验室冷白色顶光，金属质感，高清写实，4K。运镜平稳，无抖动。

### Vidu

- 公式：`主体 + 场景细节 + 镜头运镜 + 动态效果 + 风格氛围`
- 招牌是**参考生视频**：上传角色/道具参考图，prompt 只写新动作新场景（"同一主体，全新故事"）
- 范例（参考生视频，上传研究员角色图后）：
  > @图1中的女研究员在超净工作台前操作 CRISPR 试剂盒，移液器精准点样，镜头缓慢横移环绕工作台，冷色无影灯照明，纪实科教风格。

### 海螺 Hailuo / MiniMax（Director 模型）

- **运镜指令必须放在 prompt 最开头**，方括号包裹，**最多 2 条**，英文逗号分隔
- 范例：
  > 【推进，轻微上升】镜头穿过培养皿液面，缓慢逼近一个正在分裂的干细胞，细胞膜凹陷、缢裂成两个子细胞，显微摄影质感，暗场照明，科学纪录片风格。

### Runway Gen-3/4（英文）

- 结构：`[camera movement]: [establishing scene]. [additional details]`
- 关键词家族：camera（low angle / overhead / FPV）、lighting（diffused / silhouette / lens flare）、speed（slow motion / hyperspeed）；Gen-4 References 做角色一致性
- 范例：
  > Slow motion dolly-in: a ribosome assembles a glowing polypeptide chain inside a translucent cell, bioluminescent blues, volumetric light, macro cinematography, shallow depth of field. Diffused lighting, sterile laboratory ambience, photorealistic CGI.

### 通义万相 Wan

- 官方 7 要素词典：景别 / 视角 / 镜头 / 运镜 / 速率 / 氛围 / 风格，按要素组装
- 首尾帧 API：传首帧+尾帧图，prompt 只写运动
- 范例（图生视频，首帧=显微照片）：
  > 镜头匀速推进，载玻片上的水熊虫缓慢爬行，腿部划水动作清晰，其余画面元素保持静止，显微摄影，侧光，纪录片氛围。

### Seedance 2.0 / 2.5（火山引擎，官方文档核实版）

> 多镜分镜模板（时间轴公式、产品展示/动效/延长/编辑模板、@引用语法、氛围关键词库）见 `knowledge/seedance-template-library.md`。

LibTV 和即梦 Pro 的核心后端。**选模型先看版本差异**：

| 项 | 2.0 | 2.5 |
|---|---|---|
| 单次时长 | 4-15s | 4-30s，可多轮延长 |
| 参考素材 | 共 15 个（9 图+3 视频+3 音频） | 共 50 个（30 图+10 视频+10 音频），新增纯音频参考 |
| 分辨率 | 480p / 720p / 1080p / 4K（标准版） | **仅 480p / 720p**（暂时倒退；第三方"2.5 原生 4K"与官方文档矛盾） |
| 时间控制 | 不响应精确时间戳，用"镜头 N"序号 | 响应整数秒时间戳（`0-3s…3-7s…`，时间轴必须连续） |
| 画幅 | 6 档固定 | 6 档 + `adaptive`（编辑/延长/首尾帧任务必须用 adaptive） |

**参考素材语法**：上传后按同类素材顺序用 `图片1`/`视频1`/`音频1`（或 `@图片1`）指代；任务关键词决定任务类型——
- 参考生新视频：`参考图片1中的主持人，生成…` / `参考视频1的环绕运镜`（部分参考要写清参考哪一部分：`参考视频1中施法的动作，视频2的环绕式运镜`）
- 编辑：必须含「编辑/增加/删除/修改/更换/改成」之一，且直接写 `视频1`，**不要写"参考视频1"**（会被误判为参考任务）
- 延长：必须含「向前/向后延长/续写」之一
- 音频符号：`{台词}`、`(音乐)`、`<音效>`、`【字幕】`；非中英台词标语种

**多镜头写法**：2.0 用"镜头1/镜头2/…"按事件顺序（每镜四要素：运镜+主体动作+空间变化+音频，不指定时长）；2.5 可用镜头序号或整数秒时间戳，单镜只指定 1 种运镜。官方推荐结构：素材指代 → 一句话概述（主体+地点+事件+风格）→ 分镜逐段 → 贯穿性约束收口。

范例（2.5，15s，3 镜科普片）：
```
一句话概述：微观科学科普短片，写实科教纪录片风格，电影级光影。
镜头1（0-5s）：大全景，傍晚的生物实验室，暖色顶灯，镜头缓慢推近实验台，穿白大褂的研究员俯身调节显微镜，<离心机低鸣声>。
镜头2（5-10s）：特写切至显微镜目镜视野，细胞样本在视野中缓缓漂移，焦点从细胞壁平滑移到细胞核，研究员画外音说道{看，这就是线粒体}。
镜头3（10-15s）：镜头推进细胞内部转为3D分子动画，蛋白质链缓缓折叠、ATP分子亮起蓝色辉光，镜头环绕分子半圈后定格，（轻柔的钢琴环境乐渐起）。
全程写实科教风格，画质高清、细节丰富；人物面部稳定不变形；保持无字幕、不要生成Logo、不要生成水印。
```

**Dos**：运镜直写标准术语（推/拉/摇/移/跟/环绕/一镜到底/希区柯克变焦/FPV/子弹时间）；动作写肢体部位+幅度力度（`缓慢抬手、微微低头`）；情绪用具象身体细节（✅"眼眶泛红、手指无意识攥紧衣角" ❌"很悲伤"）；人物参考大头照+全身照分开给；素材 4-5 个为宜，别用满上限。

**动感三来源（广告片强制自检）**：① 运镜——单镜 ≤2 种，但要用**变速**（由快到缓收稳/骤然放缓/急速俯冲急停悬停）和**复合运镜**（环绕+上升、推近+旋转）；② 画面内部运动——光扫/粒子/前景遮挡物掠过/元素展开；③ 剪辑节奏——动作匹配剪辑（环绕动势接推近动势）、快慢相间。只写"缓慢推近"的匀速单运镜=PPT 式视频，不合格。

**Don'ts（官方失败模式）**：2.0 别写精确秒数；单镜别堆多种运镜；别把完整剧本直接当 prompt（要精简）；台词别中英混用，多音字换同音常用字；人物多视图合一参考在 2.0 易 ID 漂移（官方对宫格分镜参考的建议：≤15 格、火柴人/线稿为宜；要严格对齐逐格用关键帧写法 `以图片1至图片7的顺序作为关键帧…`）；别直接多次续写模型产物（画质叠加劣化，官方建议先转纯白 3D 模型视频再续写）；剪映拼接防跳变：前段末尾减 6 帧、后段开头减 1 帧；**真人脸参考图会被审核直接拦截**——用授权素材/虚拟人像/线稿分镜规避（见 `playbooks/storyboard-grid.md`）。

## 运镜词表（中英对照）

| 中文 | English | 中文 | English |
|------|---------|------|---------|
| 推 | dolly-in / push in | 环绕 | orbit / 360° arc |
| 拉 | dolly-out / pull out | 升降 | crane / jib |
| 摇 | pan / tilt | 甩 | whip pan |
| 移 | truck / lateral move | 变焦 | zoom |
| 跟 | follow / tracking | 希区柯克变焦 | dolly-zoom |
| FPV 穿越 | FPV flythrough | 一镜到底 | single take / oner |
| 固定镜头 | locked-off shot | 手持 | handheld |

速度修饰：缓慢 / 匀速 / 急速；稳定语："运镜平稳，无抖动"；画质后缀习惯："4K，60fps"。

## 负面 prompt 清单（按需要选，用具体排除项）

```
变形，扭曲，多余的手指，面部扭曲，文字，字幕，水印，logo，
模糊，低清晰度，抖动，画面撕裂，闪烁，过曝，死黑，卡通化（写实片用）
```

不写空泛的"不要/避免"，要给具体排除项。

## 常见失败 → 修复

| 失败 | 修复 |
|------|------|
| prompt 又长又密，出来四不像 | 砍到 1 主体 + 1 动作 + 1 运镜 |
| 堆了多个运镜，镜头乱飞 | 运镜 ≤2 个 |
| 全是抽象形容词 | 每个抽象词换成一个具体视觉事实 |
| 图生视频里复述画面内容 | 只写运动；画面交给首帧图 |
| 首尾帧差异太大，过渡崩坏 | 保持同场景同构图，只改一个元素 |
| 手部/多人互动穿帮 | 简化成单主体；或用参考图/表演迁移 |
| 跨镜风格漂移 | 按 `playbooks/consistency.md` 上锚定组合 |
