# 宫格分镜图技法（Storyboard Grid）

> 网上流行的"九宫格分镜"工作法：一次生成一张 3x3 宫格分镜图（常用黑白线稿），整条片的镜头构图一次定型，然后**整图喂多镜原生视频模型一次成片**，或**切开逐格当首帧**逐镜生成。本手册含生图工具选择、即拿即用的模板、两条成片路径、坑与对策。
>
> **⚠️ 故事板铁律前置（红楼梦EP01·用户裁定 20260915）**：故事板 prompt 必须遵守 **§故事板五铁律**（总指令前置／等分格／参考≤3张且只取轮廓／每格【景别·运镜】／简单意象改文字描述）。这五条是**判废项**，不是选项——**故事板写成"水墨渲染"或"彩色稿"＝整板废，直接重抽**（机器门控见 `scripts/check_prompt_delivery.py` D5）。

## 什么时候用

- 快速 previz：方案刚定，几分钟看到全片镜头感觉，开分镜会时直接看着图辩论
- 强一致性需求：一张图里生成全部镜头，角色/风格/调性天然统一
- 配合多镜原生模型（Seedance 2.x / Sora 2）：整图直接"演绎"成视频

## 故事板五铁律（红楼梦EP01·用户裁定 20260915｜逐条写死，违一条即重抽）

### 铁律① 总指令前置（第一句就写死线稿性质）＋ 负面钉死

- **prompt 开头第一句**必须是：**"手绘分镜草稿，黑白单线线稿，明暗仅用简单排线"**（不得把风格句放在逐格内容之后）。
- **负面必须钉死这 7 项**：`水墨, 晕染, 泼墨, 飞白, 灰阶渲染, 彩色, 黑色块`。
- **为什么**（本项目事故根因）：故事板 prompt 里若出现"水墨／写意／质感"类词，模型会把**成片的水墨质感**画进分镜稿——**糊成一团、格线消失、无法对格**。故事板是**构图工具**，不是风格稿；色彩与质感由**成片风格 token＋定稿锚图**负责，故事板只负责**顺序与构图**。
- **判据（D5）**：出现"故事板"字样的 prompt，须含**"线稿"**、须要求标注**"景别/运镜"**，负面须含**"水墨"/"印章"**类钉死词。

### 铁律② 等分格：`N 列 × M 行共 K 个等大矩形格子、严格等分`

- 写死句：**"<N> 列 x <M> 行共 <K> 个等大矩形格子，严格等分，均匀白边分隔（细黑边框）"**。
- 不写死＝模型随意拼贴、格子大小凌乱、格数与镜数对不上（对格验收直接失效）。
- 分辨率 **2K 起步**：格内小字（镜头号／景别运镜标注）才可读。

### 铁律③ 参考 ≤3 张，且每条参考后必须写"只取其轮廓造型"

- **单板参考图上限 3 张**（**多图同挂致线稿风格摇摆与质感污染**）。
- 优先挂**"造型最具体、形准最要紧"的 3 项**（如关键道具／火形／主体形），**简单意象改由文字描述承担，不占参考位**（铁律⑤）。
- **每条参考后必须原句追加**：**"只取其轮廓造型，绝不带入其色彩与水墨质感"**——否则参考图会把成片质感污染进故事板。
- **故事板 prompt 本身也必须带参考 @**：画的对象要用已采纳定稿锚图当形（禁止凭空文生），按 `@图片N=实际文件名（取哪→放哪）` 写法（见 `playbooks/platform-prompts.md` §@标记贯穿）。

### 铁律④ 每格必须标注【景别·运镜】，禁止同一景别刷到底

- **每格标注格式**：`【景别·运镜】`，如 `【远景·固定】`、`【近景·缓缓推近】`、`【中景·横移】`。
- **整板禁止同一景别刷到底**——全板同景别＝分镜废（成片必然 PPT 感）。
- **同机位段落也要有变化**：用**"景别／距离差 ＋ 主体占比"**体现变化；"同机位"仅指**不跳轴的路径底相同**，不等于"每格都中景固定"。
- 与 `playbooks/animation-motion-design.md`（三层动／动作曲线）配套：故事板定**构图与顺序**，动镜时间轴定**怎么动**。

### 铁律⑤ 简单意象改文字描述，不占参考位

- **雪野孤影／空景／纯留白意境**等简单意象 → **用文字描述**，**不挂参考图**。
- 参考位只留给"形准最要紧"的对象；**参考位是稀缺资源**（≤3），被简单意象占掉就会挤掉真正需要锁形的项。

## 生图工具选择

| 工具 | 地位 | 关键特性 |
|------|------|---------|
| **GPT Image 2**（ChatGPT Images 2.0 / `gpt-image-2`，2026-04 发布） | **首选** | 指令遵循强；中文小字渲染好（格内标注可读）；比例 3:1~1:3 任意；出 2K；单格翻车可用"继续编辑"只重画那一格；官方把分镜制作列为典型场景 |
| Nano Banana 2 / Pro | 备选 | "底图扩九宫格"玩法最流行（喂一张角色/产品图扩成 9 格）；彩色网格直出效果好 |
| Seedream 4.5（即梦图片） | 备选 | 主打多图一致性（官方实测 9 宫格角色五官近乎零偏差）；与 Seedance 同在即梦工作台，联动最顺 |

## 为什么用黑白线稿

1. **规避真人审核**：Seedance / Sora 2 等平台会拦截真人脸参考图，线稿分镜不触发
2. **线稿只当视觉骨架**：视频模型会按 prompt 把黑白构图重新渲染成彩色成片——网格管构图/动作/叙事，不管最终色调
3. 线稿分镜本来就是影视 previz 的惯例
4. **（红楼梦EP01·用户裁定 20260915）线稿是"不可污染"的**：故事板一旦沾上水墨／彩色，就不再是构图工具，且会把成片质感带偏——见 §故事板五铁律①

## Image2 五段式 prompt 结构

① 基础设置（比例、几列几行共几格、**严格等分**）→ ② 风格方向（**总指令前置：手绘分镜草稿／黑白单线线稿／明暗仅用简单排线**）→ ③ 逐格镜头（**【景别·运镜】**＋动作，从分镜表逐行搬）→ ④ 视觉规范（角色一致性约束＋**参考"只取轮廓造型"**）→ ⑤ 底部信息栏（角色设定、情绪基调、每格时间码）

要点：
- 中文直接写；**写死"3 列 x 3 行共 9 格，等大矩形、严格等分、格间清晰白边分隔"**，否则模型随意拼贴（铁律②）
- 分辨率选 2K，格内小字才可读
- 几何关系：3x3 排布 16:9 格子，整图正好也是 16:9
- **负面钉死 `水墨, 晕染, 泼墨, 飞白, 灰阶渲染, 彩色, 黑色块`**（铁律①）
- **每格必须带【景别·运镜】**，且全板景别不可雷同（铁律④）
- **参考 ≤3 张**，每条后写"只取其轮廓造型，绝不带入其色彩与水墨质感"（铁律③）
- 单格翻车：用"继续编辑"补一句"只重画第 5 格，改成低角度仰拍，其余格子保持不变"，**不重抽整图**

## 即拿即用模板（科研主题示例）

```
你是一位专业影视分镜师。请生成一张 16:9 的手绘分镜草稿（storyboard），黑白单线线稿，明暗仅用简单排线。
严格按 3 列 x 3 行共 9 个等大矩形格子排列，严格等分，格间以均匀白边（细黑边框）分隔，每格是一个 16:9 镜头画面。
风格：黑白线稿，线条干净，明暗仅用简单排线；不施水墨、不做晕染、不上彩色。
故事：【科普短片《基因编辑小麦》——科学家用 CRISPR 培育抗旱小麦】
参考：@图片1=<实际文件名>（取<主体造型>→放第4/6格主体位）；每条参考只取其轮廓造型，绝不带入其色彩与水墨质感。
（上传顺序：@图片1=<实际文件名>）
角色一致性：同一角色（白大褂女科学家，齐肩短发）贯穿 9 格，外貌服装不变。
逐格内容（按从左到右、从上到下，每格标注【景别·运镜】）：
第1格【大远景·固定】｜干旱龟裂的麦田，枯苗
第2格【中景·固定】｜女科学家蹲下捻起干裂土壤，神情凝重
第3格【特写·微距缓推】｜培养皿中绿色麦苗嫩芽
第4格【中景·横移】｜实验室内，科学家操作移液器，背景全息 DNA 双螺旋
第5格【特写·固定】｜屏幕上 CRISPR 基因序列高亮编辑动画
第6格【近景·过肩】｜科学家与农民在试验田边交谈，指向远方
第7格【全景·无人机升镜】｜对比画面：左侧枯田、右侧绿油油的抗旱麦田
第8格【中景·缓拉】｜金色麦浪中科学家捧起饱满麦穗微笑
第9格【大远景·固定】｜夕阳下丰收麦田，字幕留白区
每格左上角标注镜头号（1-9），格内下方用一行小字标注【景别·运镜】。
底部信息栏：角色设定、整体情绪基调（希望感）、每格约 1.5 秒时间码。
负面：水墨, 晕染, 泼墨, 飞白, 灰阶渲染, 彩色, 黑色块, 真实照片质感, 3D渲染
```

使用时替换故事、角色、逐格内容（直接从分镜表搬）。格数可变体：**四宫格**（简单场景/LibTV 剧情推演）、九宫格≈15s 短片、十六宫格≈30s、二十五宫格≈60s（格子用 A1-C3 坐标编号，便于"把 B2 格重绘成单张 4K"式提取）。

> **参考位分配示例（铁律③⑤）**：九宫格里"形准最要紧"的若只有 2 项（如某道具＋某角色），就只挂这 2 张；其余（雪地／空景／纯意境）**改文字描述**，不占参考位。

## 成片路径（二选一）

### 路径 A：整图一次成片（Seedance 2.x / Sora 2）

把宫格图作为参考图上传，prompt：
> 参考 @图片1 的九宫格分镜，按从左到右、从上到下的顺序演绎成一段 15 秒的视频，保持画面风格一致，转场流畅自然。

- **必须写明"按从左到右、从上到下顺序演绎成一段视频"**，否则模型可能输出"9 个格子各自在动"的网格动画
- 进阶：加运镜描述、时间轴（场景1 0-3秒…）、甚至"参考 @视频1 的运镜节奏"
- Seedance 官方对宫格参考的建议：≤15 格、火柴人/线稿为宜；要严格对齐逐格，用关键帧写法：`以图片1至图片7的顺序作为关键帧…`

### 路径 B：切开逐格当首帧（即梦/可灵/Vidu/LibTV）

1. 切图：在线九宫格切图工具/PS 等分裁剪；更推荐 **AI 提取**——把网格图发回生图模型："把第 5 格重绘为独立高清 16:9 图"（可指定 4K）
2. 逐格作为首帧进图生视频，每镜按 `playbooks/platform-prompts.md` 的 I2V 公式写**运动** prompt
3. 黑白线稿首帧 → 在视频 prompt 里写明最终彩色风格（风格 token 块），模型会重新上色

> **⚠️ 动镜与故事板的关系（红楼梦EP01·用户裁定 20260915）**：故事板在**动镜 prompt 中降为节拍／顺序参考**，并须注明 **"运镜必须连续，绝不分切"**；**禁止在动镜 prompt 里引用"格 N"作为分段单位**（引用格号＝诱发切镜）——连续运动镜一律写 **"一镜到底＋机位跟随主体"**。详见 `playbooks/platform-prompts.md` §镜头连贯性。

## 坑与对策

| 坑 | 对策 |
|---|---|
| **故事板写成水墨渲染/彩色稿 → 糊成一团** | **总指令前置"手绘分镜草稿／黑白单线线稿／明暗仅用简单排线"＋负面钉死 `水墨, 晕染, 泼墨, 飞白, 灰阶渲染, 彩色, 黑色块`**（铁律①）；已糊＝整板重抽，不改措辞抢救 |
| **参考图把成片质感污染进线稿** | 每条参考后必写"**只取其轮廓造型，绝不带入其色彩与水墨质感**"；参考 ≤3 张（铁律③） |
| **格子大小凌乱/格数对不上** | 写死"N 列 x M 行共 K 个**等大矩形格子、严格等分**、均匀白边细黑边框"（铁律②） |
| **整板同一景别刷到底（PPT 感）** | 每格标注【景别·运镜】；同机位段用"景别／距离差＋主体占比"体现变化（铁律④） |
| **简单意象占满参考位** | 简单意象（空景／孤影／纯留白）改文字描述，不挂参考（铁律⑤） |
| 模型无视网格指令、随意拼贴 | 写死"3 列 x 3 行共 9 格排列"，生成 2K |
| 格内标注小字糊/乱码 | 2K 起步；每格文字尽量短；标注放安全边距内、不压主体 |
| 整图喂视频模型变成"9 格各自动" | 写明"按从左到右、从上到下顺序演绎成一段视频"；或改切片路线 |
| 某一格翻车 | "只重画第 N 格，其余保持不变"；或 AI 提取单格重绘，不重抽整图 |
| **动镜被"格 N"切碎** | 动镜 prompt 禁用"格 N"分段；改"一镜到底＋机位跟随主体"＋注明"运镜必须连续，绝不分切" |
| 跨格角色/产品漂移 | 上传参考图 + prompt 锁死"场景/产品/人物统一"；或换 Seedream 4.5 |
| 网格线渗色、格子大小不均 | 要求"格间留白/粗白边分隔"，高分辨率重抽 |
