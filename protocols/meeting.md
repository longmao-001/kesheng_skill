# 多 Agent 辩论会议协议（Meeting Protocol）

> 设计依据：Du et al. 多 agent 辩论（arXiv:2305.14325，独立初稿→互评→更新，3-4 轮后收益饱和）、MAD（arXiv:2305.19118，针锋相对+裁判，自适应停止，禁止"每点必杠"）、MetaGPT（交接制品而非对话）、Anthropic 多 agent 工程实践（盲并行独立提案、制品落盘、成本约 15× 于单聊，所以按里程碑分层开会）。

本协议适用于所有里程碑会议。制片人（主席）负责执行本协议。

## 会议分层（按风险配成本，不许层层都开全会）

| 层级 | 适用场景 | 出席 | 辩论强度 |
|------|---------|------|---------|
| **全会** | 三个里程碑门控：方案定稿、分镜定稿、交付前审查 | 制片人+科学顾问+编剧+视觉导演+prompt工程师+观众代言人+红队 | 完整 Phase 0-5 |
| **小组会** | 单镜头/单段落级问题 | 制片人 + 相关 2 个角色 + 红队 | 1 轮辩论 |
| **单人打磨** | 低风险润色（措辞、格式） | 1 个角色自查自改（生成→自评→修改） | 无辩论 |

## 出席招募

不是每场都全员。按议题招募：涉及科学表述必须有科学顾问；涉及分镜必须有视觉导演和 prompt 工程师；红队**每场必到**。单次会议桌 ≤7 人（人多了互相记不住观点，辩论质量反而下降）。

## 会议阶段

### Phase 0 — 简报确认（主席）

主席复述需求简报：话题、用途、受众、投放平台、时长、风格、硬约束（甲方必须出现的元素/绝不能出现的元素）。
**预注册评审标准**：在任何人提方案之前，写下本次裁决用的 3-5 条标准（如：科学准确性、钩子强度、一次看懂率、可制作性、甲方约束符合度）。先定标准后有方案——防止裁决时为喜欢的方案临时编理由。
输出：brief v1（`templates/brief.md`）。简报关键信息缺失 → 停下来问用户，不许猜。

### Phase 1 — 盲独立提案

每个出席角色**在看不到别人方案的情况下**独立写自己的立场/方案草案，每条方案末尾附自己认为的前 3 大风险。
（宿主支持子 agent 时，这一步用并行子 agent 生成，主席只收最终文本，保证真独立、防锚定。）
输出：每角色一份立场块。

### Phase 2 — 辩论第一轮（交叉质询）

固定发言顺序：编剧 → 视觉导演 → 科学顾问 → prompt 工程师 → 观众代言人 → **红队永远最后**。
每次发言的合法格式（三段式，缺一不可）：
1. **钢炼**对手最强的论点（先准确复述对方观点的最强形态）
2. **按 Phase 0 标准**反驳或支持
3. **给出一个具体的制品改动**（改哪段文稿/哪行分镜/哪条 prompt）

空泛发言（"我觉得挺好的""建议再优化一下"）视为无效发言，主席要求重写。

### Phase 3 — 辩论第二轮（更新与再反驳）

每个角色必须明确声明：**"我在 X 问题上改变立场，因为 Y"** 或 **"我坚持，因为 Z"**。
强迫可见的立场更新——这是防止"沉默地随波逐流"的审计线索。

### 停止规则（自适应）

- 默认 2 轮；某轮结束后没有任何新论点出现 → 立即进入裁决
- 硬上限 3 轮（研究表明超过 3-4 轮收益饱和，且创意任务没有标准答案，多加轮次只会产生"共识表演"）
- 3 轮后仍有阻塞性分歧 → 双方立场原样记录，升级用户

### Phase 4 — 裁决（主席）

主席按 Phase 0 预注册标准逐条打分，选择或合并方案。
**事实性争议不许折中、不许平均**——查证或升级用户。
输出：会议纪要（`templates/decision-log.md`），必须包含：决议、理由（对照预注册标准）、被否方案及原因、**少数派报告（原样保留，不许和稀泥）**、未决风险、升级事项、下阶段验收标准。

### Phase 5 — 制品交接

更新制品文件（brief → 理解报告 → proposal → storyboard → prompt 表），并附上下一场会议必须确认的验收清单。
**交接的是制品，不是对话记忆**——所有重要结论必须落在文档里。

## 反"假共识"机制（七条，主席负责执行）

1. **盲独立立场先行**：先量出真实分歧，再允许交叉讨论
2. **指定轮换红队**：每场必到、每场必攻当前领先方案、攻击视角逐场轮换
3. **有原则的针锋相对**：反对必须引用预注册标准；禁止"每点必杠"（为赢而辩会极化，比不辩更糟）
4. **异议配额**：达成合法共识前，至少 3 条实质性异议被提出并解决
5. **提前共识警报**：裁决轮发现所有人全程零立场变化 → 主席必须宣布疑似假共识，注入红队加赛一轮或升级用户
6. **裁判纪律**：主席只能用 Phase 0 之前定下的标准裁决，不许临时造标准
7. **制品增量才算数**：一轮发言没有产生任何改动/异议/评分 → 该轮无效

## 升级给用户（甲方）的情形

- 简报关键信息缺失（受众/平台/时长/用途）——Phase 1 前必问
- 事实/科学性争议内部无法裁决——科学视频的头号风险，绝不折中
- 品味、品牌、价值观取舍；有争议的叙事框架
- 3 轮硬上限后仍有阻塞分歧
- 范围冲突（如分镜镜头数超出可行制作量）
- **每个里程碑的会议纪要必须交给用户确认后才推进下一阶段**
