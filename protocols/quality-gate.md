# 质量门控（Quality Gate）

> 出片前/交付前的强制检查。**门控执行协议**：M4 出口前与 M5 出口前各一闸，闸门由**独立上下文的红队/Reviewer subagent** 执行（未参与创作，只读黑板制品+预注册标准），制片人主持收尾。全维度不过不许交付。

## 〇、门控执行协议（v2 新增）

| 闸 | 时机 | 执行者 | 检查依据 | 产出 |
|---|---|---|---|---|
| 前置拦截闸 | M4 prompt 定稿后、交付用户前 | 红队 subagent（独立上下文） | 硬性违规：科学错误/伪造数据/无出处/品牌禁区/平台审核红线/数据画面交给 AI 生成 | `runs/<项目>/m4-gate-red.md`：pass/fail + 逐条违规（镜头号+问题+修改要求） |
| 出口评审闸 | M5 交付前 | Reviewer subagent（未参与创作的独立上下文） | 下述七维检查表 + 里程碑验收清单 + 预注册标准 | `runs/<项目>/m5-gate-red.md`：**评分单（每项 0.0-1.0 + 一句理由）+ 三态裁决 + 打回意见** |

**三态裁决**：
- **PASS** ≥0.85 且无 BLOCK 级项 → 可交付
- **CONDITIONAL** 0.70-0.84 或存在可修正项 → 按意见修改后**只重跑对应项**，最多再验 1 次
- **BLOCK** <0.70 或存在硬性违规（科学错误/数据无出处/审核红线）→ 打回对应环节（M4 打回分镜/prompt；M3 打回方案），**最大循环 2 次**；2 次后仍 BLOCK → 升级用户决策
- 循环计数与裁决记录进 `templates/decision-log.md`

**评审纪律**：引用预注册标准编号逐条打分，不许凭感觉；每条意见附"推翻条件"；只评制品不评人；**事实性争议不折中**（查证或升级）。

## 一、七维检查表

| 维度 | 标准 | 不通过的处置 |
|------|------|-------------|
| 画面相关性 | 分镜画面与文稿 ≥80% 匹配 | 加【画面建议】标注，重生成该镜 |
| **Prompt 公式合规（产品/设备类）** | 逐镜 prompt 套 `templates/product-prompt-formula.md` 八段；产品=干净/功能=复杂；保真实造型（@参考图不变、禁改形）；参考图"取哪部分→放哪位置"写显式；AI 直出文字写死、精确数据 `⚠️核对=手册原文`；无抽象词、单镜≤2 运镜+变速 | 打回对应段重写 |
| 配音准确度 | 术语发音正确、无歧义读音 | 改写文稿（同义词替换掉易错词） |
| 旁白信息价值 | 参数都有价值翻译（客户得到什么）、术语首次即译、无炫技词、数字已口语化（按 NarrationRule 逐条过） | 打回编剧改稿（参数价值/术语/克制三处） |
| 节奏感 | 单镜头 ≤10 秒 | 拆分或合并文稿段落 |
| 镜头动感 | 无"PPT 式视频"：每镜有变速/复合运镜或画面内部运动（广告片按 dop.md 动感三来源逐项过） | 退回分镜重排运镜；成片不足时剪辑侧用速度斜坡+音效驱动补救 |
| 信息密度 | ≥3 个信息点/分钟 | 删冗余、补干货 |
| 开头吸引力 | 前 5 秒有钩子 | 重写开头 |
| 品牌一致性 | 符合选定 VI 规范 | 调整色彩/字体/转场 |
| 视觉克制 / 反 AI 感 | 风格**根植内容**（能讲出"为什么这个内容配这个色"，非随大流"高级感"）；单强调色、系统≤3 色；无默认 AI 审美反模式（白底紫渐变/海军金/卡片圆角投影堆砌/emoji 当图标/默认蓝强调）；字幕白字描边≤10字/屏、强调色不上正文；片头/封面为"可辨识的视觉身份"而非"通用 AI 输出" | 打回美术按 `templates/visual-baseline.md` 重定风格基线 |
| 总时长 | 符合模板/简报要求 | 调整文稿长度 |

## 二、里程碑验收清单

### 方案定稿前（M3 出口）

- [ ] 科学顾问的理解报告达到 L2 以上，"待确认"项全部有去向（已查证/已删除/已升级用户）
- [ ] **素材库已建立并分级**：客户素材全量收集、分类、标注用途分级（可直接入镜/参考图/内容参考）；缺口素材已上网检索补充；分镜候选镜头已对照素材库勾选可用素材
- [ ] 受众模式已锁定，且全文术语处理、数据密度、类比用量与该模式一致
- [ ] 钩子在简报约束下成立（与正文衔接，不标题党）
- [ ] 会议纪要完整，少数派报告已呈现给用户

### 分镜+prompt 定稿前（M4 出口）

- [ ] 每个镜头：景别/运镜/时长/画面/文稿/prompt 六要素齐全
- [ ] **痛点链成立（产品/商业片强制）**：每个亮点能回答"受众的什么任务需要它"（任务→需求→亮点→证据）；答不上来的亮点删
- [ ] **图表层已设计（科技类强制）**：参数表卡/曲线动画/覆盖图/结构图解，全部后期制作，AI 不生成数据画面
- [ ] **真实素材优先**：有真实照片/视频/测试数据的段落，AI 只做延伸不做替代；多角度示意图（三视图/剖视/场景）已为关键主体备好
- [ ] 每个精确结构镜头都走了首帧图+图生视频路线（不靠文生视频碰运气）
- [ ] **三视图/多角度示意图已备**：所有重复出现的产品/道具/场景，正/侧/俯（或 45°/剖视/特写）参考图已生成并登记进分镜表
- [ ] **参考图选片已按对位需求完成**：每镜参考图按 `templates/reference-selection.md` 选出——列了对位需求（主体/动作状态/机位角度/必看清部件/材质/场景）+ 标了「角色＋部位对应＋位置」＋依据口播哪句；**锚图优先**（三视图/角色锚跨镜复用，非每镜新挑主体图）；引用 `assets-inventory.md` 条目号（非凭记忆）；无水印/竞品/团队照/模糊/未授权入选（一票否决）
- [ ] 全片风格 token 块统一，逐字复用于每镜 prompt
- [ ] 一致性方案明确：角色三视图/首尾帧衔接链/参考图清单已列出
- [ ] 每镜 prompt 符合目标平台公式（对照 `playbooks/platform-prompts.md`），负面 prompt 已写
- [ ] **Prompt 公式合规（产品/设备类）**：套 `templates/product-prompt-formula.md` 八段；产品=干净/功能=复杂；保真实造型（"保持真实造型=@参考图不变"在主体+约束）；参考图"取哪部分→放哪位置"写显式；AI 直出文字写死+位置；精确数据 `⚠️核对=手册原文`；无抽象词、单镜≤2 运镜+变速（见 ORCHESTRATION §5 硬规则 16）
- [ ] 抽卡预算合理（每镜建议 3-6 次），失败改 prompt 策略已备注

### 交付前（M5 出口）

- [ ] 七维检查表逐项过一遍，结果与评分单记录在案（`m5-gate-red.md`）
- [ ] 科学顾问终审全片：无编造、无夸大、无误导性类比
- [ ] 观众代言人以目标受众身份完整过一遍成片（或脚本的最终朗读版）
- [ ] 用户（甲方）已签收会议纪要
- [ ] 项目收尾知识萃取完成：通用知识已过脱敏检查入库 `kb/`，项目专有信息零入库（见 `kb/隐私红线.md`）

## 三、执行方式（快速对照）

1. M4 出口：派红队 `subagent`（独立上下文）跑前置闸 → fail 则打回对应段（≤2 循环）→ 制片人复核后交用户。
2. M5 出口：派 Reviewer `subagent`（未参与创作）跑出口闸 → 按三态裁决处置 → 用户签收 → 知识萃取。
3. 全自动模式下由 `kesheng_workflow.js` 阶段 G/H 自动产出两闸报告，制片人仍需复核并走用户关卡。
