# 制作方案模板（Proposal）

> M3 里程碑产出。全会辩论定稿后按此结构交付用户。

## 一、项目定位
- 核心卖点（一句话）
- 叙事策略
- 情感基调

## 二、目标受众画像
- 主要受众关心什么、会被什么打动
- 受众模式（EXP/GOV/PUB/STD/IND）及对应的术语/数据密度/类比策略

## 三、文案（口播稿/字幕稿）
按「镜头号 - 画面描述 - 时长 - 文稿」的表格形式输出

| 镜头号 | 画面描述 | 时长 | 文稿 |
|--------|---------|------|------|
| 1 | | | |

## 四、分镜概览
- 总镜头数约多少支
- 节奏曲线
- 视觉风格建议（引用 VI 模板）
- 素材来源规划（已有/需生成/需补充）

## 五、执行计划
- 制作平台与路径（LibTV 节点画布 / 单镜工具）
- 预计产出物
- 预计耗时
- 迭代轮次
