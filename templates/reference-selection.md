# 参考图选片法（Reference Selection）— 每镜挑「该用的那张」

> 用途：面对素材库一堆候选图，给某一镜挑出「该用的 ≤3 张参考图」。这是连接「素材库(素材分级)」与「参考图用法(标角色+部位对应+放哪位置)/图文对位 R12」的**选图**一环。
> 铁则：**参考图必须按该镜的对位需求选出**——先定"这镜参考图必须提供什么"，再在候选里挑；不是随手拿一张好看的。锚图优先（三视图/角色锚先复用），辅助参考（机位/场景/质感）才新挑。
> 依据：科生 `Rule:图文对位` / `素材分级` / `ProcessRule:参考包组装` / `playbooks/consistency.md`（三视图锚定）。

## 一、先定「对位需求」（每镜必填，选图前）

从该镜**口播 + 分镜**提取，这镜参考图必须能提供：

| 需求项 | 填什么 | 例子 |
|---|---|---|
| 主体 | 哪台设备/哪个角色/哪个场景（名称+型号/版本） | 量测机台左控制器+右灯室 |
| 动作/状态 | 口播讲它「在做什么/处于什么状态」 | 光带扫过控制器→灯室 |
| 机位/角度 | 正/侧/俯/45°/剖视/特写（分镜机位） | 45° 侧俯 |
| 必看清的部件/细节 | 哪些 logo/接口/结构片要在图上可辨 | 出光窗、散热鳍片、RS-485、logo |
| 材质/质感 | 银白拉丝铝/冷蓝光/深空底… | 银白拉丝铝、出光=白光 |
| 环境/场景 | 若是场景参考，要什么背景 | 实验室暗环境、灰底冷蓝 |

## 二、候选池

素材库/参考图库中**包含该主体或所需部件**的候选清单（来自 `assets-inventory.md` 条目，**逐条引用条目号，禁止凭记忆翻文件夹**）。

## 三、打分（每候选按 8 维，0-1）

| 维度 | 判据 | 权重 |
|---|---|---|
| ① 对位度 | 含**确切的**主体＋口播讲的**動作/状态**（不是近似） | 最高 |
| ② 信息完整·清晰 | 必看清的部件/细节在图上清晰可辨（不糊/不裁/不遮挡） | 高 |
| ③ 角度匹配 | 机位/角度与分镜一致，或可支撑该角度 | 高 |
| ④ 光影/环境匹配 | 光环境/背景与该镜设计匹配，或可作生图基底 | 中 |
| ⑤ 主体占位 | 主体占比/构图接近该镜需求（不边角/过小） | 中 |
| ⑥ 合规 | 无水印/竞品/团队照/模糊；已授权可商用 | 硬性 |
| ⑦ 唯一性 | 同镜不重复；跨镜优先复用已选锚图，不新挑 | 中 |
| ⑧ 可溯源 | 能引用素材库条目 + 来源/授权 | 硬性 |

**一票否决（任一命中即弃，不看总分）**：主体对不上口播 / 无授权 / 有水印·竞品·团队照 / 模糊到看不清部件 / 商标原理图示（作参考喂模型埋雷）。

## 四、入选（≤3 张）＋标「角色＋部位对应＋位置」

选分数最高的 ≤3 张，逐张标清楚（这是入手 prompt 的**硬检查项**）：

| @图 | 角色 | 部位对应 | 放哪位置 | 依据口播哪句 |
|---|---|---|---|---|
| @图1 | 主体（整机） | — | 全片主体锚 | "……" |
| @图2 | 部件参考 | 参考图【散热鳍片】＝主体【机身鳍片】 | 第3镜特写 | "……" |
| @图3 | 场景参考 | 图中【右上角】机台=主体，其余背景 | 第1镜环境 | "……" |

> 角色：主体（整机）／部件参考（X＝X'）／场景参考（用于背景环境）／质感参考。
> **场景参考若含主体**：注明"图中<位置>的<主体>是主体，取该主体，其余为背景"。
> 产品/设备类：**三视图/角色锚图是唯一主体参考**，优先复用；机位/场景/质感才新增辅助参考。

## 五、登记 + 交接

- 选图结果写进 `assets-inventory.md` 的「选中为参考」标注 + 分镜表「参考图/首帧」列（引用编号），避免凭记忆。
- 交接给 prompt 工程师：`@图N 角色+部位对应+位置` 逐字进 prompt 的【参考】字段（见 `templates/video-prompt-formula.md`）。
- 摄影指导/美术指导/分镜师**逐镜**出选片；prompt 工程师不自行换图（换了必须回选片法重过）。

## 六、自检（选完过一遍）

- [ ] 每镜参考图**都列出了对位需求**，不是凭空挑。
- [ ] 入选的每张都标了 角色／部位对应／位置／依据口播哪句。
- [ ] 主体一致性用了三视图/角色锚图（不是每镜新挑一张主体图）。
- [ ] 无 水印/竞品/团队照/模糊/未授权 图入选。
- [ ] 引用的是 `assets-inventory.md` 条目号（非记忆）。
