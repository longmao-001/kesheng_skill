# 素材库清单（Assets Inventory）—— 智能入库版

> 用途：把客户/网上收集到的**素材图/视频**按科生需求**分类 + 命名 + 多模态拆解 + 反推AI提示词 + 质量分**建台账，让「选图/做图」按文字标签匹配，一眼定位、可溯源、合规。
> 铁则：**文件名即条目ID**（编码 用途/类型/主体/视角）；**每张入库必须三件套**：①多模态拆解标签 ②**AI合成反推提示词** ③**质量分**（后续选图/做图用文字标签+高分优先）；**禁用红线素材（水印/竞品/团队照/未授权/商标原理图）在 brief 阶段列入禁用清单，不入库**。

## 〇、素材智能入库 SOP（三件套，逐张必做）

对每张素材（用 `read_image` 看真图，**别只读文件名**）：

1. **多模态拆解**（识别内容 → 结构化标签）：
   - 物品：主体/对象（含部件名）｜任务：在做什么/什么用途｜场景：环境/背景｜结构：组成/两件套/内部腔体｜质感：材质/表面｜数据：图上数值/曲线（若有）｜品牌：logo/用字/VI｜实拍：真机实拍 or 渲染/CG/AI
2. **AI 合成反推提示词**：写一段**描述"怎么用 AI 再生出这张图"的 prompt**（主体+构图+光线+风格+细节+负面）。这是**文字检索键**，也直接可复用为生成稿。
   - 例（产品图）：`主体=量测机台(左控制器+右灯室，银色拉丝铝)；构图=45°侧俯、主体居中占画面60%；光线=冷蓝体积光、深空灰底；风格=科技渲染写实；细节=出光窗/散热鳍片/蓝色水冷管；负面=无文字/无人物/无霓虹`
3. **质量分**（0-1 → ★1-5）：清晰度/主体完整/构图/光影/用途匹配 加权 + 合规一票否决。

> 这三件套落进台账，选图/做图时靠**文字标签 + 反推prompt + 高分**快速命中，不再一张张看。

## 一、分类体系（两轴：用途分级 × 内容类型）

**用途分级（决定怎么用）**：
| 用途 | 含义 | 怎么用 |
|---|---|---|
| **直接入镜** `IN` | 真实素材（官方渲染/实拍/测试），信任度最高 | 直接剪入成片 |
| **参考图** `RF` | 喂模型做锚定（外观/结构/场景/质感） | 进参考包/三视图/首帧 |
| **内容参考** `CT` | 数据图表/原理示意，只作内容依据 | 后期重绘，**原图永不出镜** |

**内容类型（决定是什么）**：
| 类型 | 编码 | 举例 |
|---|---|---|
| 主体锚（整机/角色/三视图/多角度） | `MAIN` | 产品三视图、角色正侧背 |
| 部件/局部 | `PART` | 散热鳍片、出光窗、接口、logo |
| 场景/环境 | `SCENE` | 实验室、流水线、装机现场背景 |
| 质感/材质 | `TEXT` | 银白拉丝铝、磨砂塑料表面 |
| 结构/原理 | `STR` | 机身爆炸图、接口示意（多为内容参考） |
| 数据图表 | `DATA` | 规格表、温漂曲线、测试数据 |
| 品牌资产 | `BRAND` | Logo、VI、标准色 |
| 实拍素材 | `RAW` | 客户实拍视频/照片 |

## 二、命名规范

**源素材文件**：`<用途编码>_<类型编码>_<主体>_<视角或部位>[_<版本>].<ext>`（主体用项目简称，视角用 `正/侧/俯/45°侧俯/剖视/特写`）
- 例：`RF_MAIN_量测机台_45°侧俯_01.png`（参考图/主体锚/45°侧俯）
- 例：`RF_PART_散热鳍片_特写_实拍_02.png`
- 例：`IN_RAW_量测机台_装机现场_客户_03.mp4`（直接入镜/实拍）
- 例：`CT_DATA_温漂曲线_产品手册_01.png`（内容参考/数据图表，永不出镜）

**生成资产**：`<项目>_镜<号>_<内容>_<版本>`，例 `R2_镜02_出光口特写_首帧.png`。

**命名纪律**：文件名要能回答三问——**干什么用（IN/RF/CT）、是什么（MAIN/PART/SCENE/TEXT/STR/DATA/BRAND/RAW）、拍什么（主体+视角/部位）**；改用途/类型就改名。

## 三、素材质量分（入库即打分）

**评分维度**（各 0-1，加权 → 质量分 0-1，再映射 ★）：
| 维度 | 判据 | 权重 |
|---|---|---|
| 清晰度 | 分辨率够、不糊、可放大用 | 0.25 |
| 主体完整 | 主体完整、无遮挡、无截断 | 0.25 |
| 构图/画面 | 主体占位合理、无杂乱、有负空间 | 0.15 |
| 光影/色彩 | 光影清晰、与目标风格匹配度 | 0.15 |
| 用途匹配 | 最适合 直接入镜/参考图/内容参考 的哪级 | 0.20 |
| **合规** | 无水印/竞品/未授权 | **一票否决（0 分/禁用）** |

**★ 映射**：≥0.85=★5｜0.70-0.84=★4｜0.50-0.69=★3｜0.30-0.49=★2｜<0.30=★1｜合规不过=禁。

## 五、台账纪律

1. **先建禁用红线清单**：brief 阶段把 水印/竞品/团队照/未授权/商标原理图 列为禁用（`REF_SKIP`），不入库/参考。
2. **全量收集**：客户给的都收，但每张必须 分类 + 多模态拆解 + 反推prompt + 质量分 + 来源/授权；无来源网图只作 `CT/构图参考` 不入镜。
3. **文件名唯一**：文件名=条目ID，引用一律用文件名。
4. **「选图/做图」按文字匹配**：候选池 = 从台账按 **内容标签/反推prompt 命中对位需求** 筛（见 `templates/reference-selection.md`），**高分优先**（≥★4 优先，★<3 除非无替代）；用完把「选中为参考」标注回台账。
5. **敏感页/敏感数据不入库**：客户机密页/涉密曲线只作内容理解，登记引用不存图。
6. **更新**：改用途/内容/分 → 同步文件名/台账；批量改（如品牌词）走 `check_residual.py` 全局扫描替换。
