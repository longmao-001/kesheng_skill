# 产品镜头 Prompt 公式（Product-Lens Prompt Formula · 科生可复用模板）

> 用途：写**产品/设备/仪器类 AI 图生视频、图片生成**的逐镜 prompt 时，一律套本公式。
> 来源：2026 调研（Seedream 5.0/5.0 Pro/Lite、GPT Image 2、即梦 4.5）＋ 科生工艺（动感三来源、图表层、首帧锚定、素材分级、参考图三用法）。
> 用途边界：只用于"产品/设备/科研仪器"类镜头；纯人物/剧情/科普叙事另按 `knowledge/tvc-ad-templates.md` 或叙事公式。

## 〇.5、**先出产品三视图（锚定优先，最稳的一招）**

> 产品/设备类镜头**先用官方/实拍参考图生一套【三视图】（正/侧/顶，+45°、剖视、特写）作主锚定**；之后所有镜头只引用这一三视图作**主体锚**，就不用在一堆产品照片里纠结"谁是主体"。三视图 = 唯一主体参考，其余（机位/场景/质感）作辅助。
> 依据：`playbooks/consistency.md`、`playbooks/storyboard-grid.md`（"产品/道具备多角度示意图（三视图/剖视/45°/特写）——全能参考类模型吃多角度图，一致性才稳"）。**先出三视图，再逐镜出图**，跨镜一致性靠三视图兜底。
> 三视图生成 prompt：`以 @参考图（官方产品照）为基准，还原产品真实造型（勿改形），出一张 16:9 的三视图/多角度示意图：正面、侧面、顶面（45° 立体图 + 正/侧/顶正交三视图），银白拉丝铝，玦芯 logo、出光窗、LED 行、开关、RS-485、氮气/水冷/光纤接口、蓝水冷管齐全，深空底，灰底偏蓝冷光，标注部件名（小字）—— 保持真实几何/比例/材质，禁改形。`

## 〇、公式（每格 prompt 用这八段，顺序写死）

```
【参数】画幅(16:9/9:16)｜分辨率(2K/4K)｜风格(写实摄影/CGI)
【镜头】焦段(mm)｜景别(微距/特写/近景/中景/全景/大远景)｜机位(平视/俯视N°/仰视N°/斜俯N°带倾斜)｜光圈(f值)｜景深(浅/深，焦点在哪)
【灯光】主光(色温K/方向)｜轮廓光(rim 角度)｜补光(挡位)｜特殊光(等离子/自发光，hex)
【主体】产品名/设备名｜材质写到位(M如"银白拉丝铝，发丝纹≈0.1mm，哑光颗粒")｜部位位置(如"出光口置右1/3")
【场景/构图】背景(深空炭黑/深邃暗底)｜构图(对称居中/三分法/对角线/满幅/留白比例/引导线)
【动效】运镜(缓推/环绕/聚焦转移)＋画面内部运动(光扫/光轨/粒子/呼吸)＋剪辑节奏(单镜≤2运镜+变速)
【文字】要 AI 直出的字(型号/铭牌/数据卡/术语标签)，字写死+位置；不直出则写"后期"
【强制约束】无人物｜无变形无穿模｜无霓虹/暖调洗墙/彩色渐变｜数据/数字核对=原文｜一致性(产品形态跨镜不变)
```

## 一、两条铁律（套公式时必须遵守）

1. **产品展示＝干净 / 功能展示＝复杂**
   - 展示外观/身份/材质/原理：**画面干净**（留白多、单一主体、产品自己发光），公式里"场景/构图"留白比例给大。
   - 展示功能/性能/应用：**画面复杂**（加机制/结果/环境细节），"主体/动效"信息密度给满。
2. **绝不改造设备真实造型**：以参考图锁定产品**真实几何/部件位置/logo/材质**（"保持真实造型(硬约束)：左控制器+右灯室/玦芯logo/出光窗/LED行/开关/RS-485/氮气/水冷/风扇格栅 位置形态同@参考图，完全不变；禁任何造型改动/新增部件/歪曲比例/掉色"）。只动布光/机位/背景/构图/加字，不改产品本体。

## 二、参考图用法（标"角色" + 部分↔部位对应 + 放哪位置）

```
【参考-角色】@图N＝主体参考（图就是物品）／部件参考（取某部件）／场景参考（用于背景环境）／质感参考（学某种光或质感）。
【参考-部位对应】@图N 参考图<部位X>＝主体<部位X'>（如"参考图一出光窗＝主体出光口"）＋ 放哪位置。
```
- **先标角色**：`@图1 是主体（系统整机）`；`@图2 是场景参考，用于深空底+金属台`；`@图3 是部件参考：散热鳍片＝主体机身鳍片`。
- **若参考图"包含主体"**（场景/环境图里也有主体，如场景图中的机器/人物）：注明主体在图中的位置——`@图2 是场景参考，但图中【右上角】的量测机台是主体，取该机台；其余为背景`。
- **再写部位↔对应 + 位置**：`@图1（主体）参考图【出光窗】＝主体【出光口】；【控制面板】＝主体【左控制器前脸】`。
- 产品镜头必须"参考图锚定"（避免 AI 凭空改形）；有真实素材的镜头不用文生图硬猜。
- 参考图上限：图片节点 3 张/次（选该镜最需要的 3 张）；逐镜视频节点可更丰富。
- 水印图/竞品图/团队合影/带商标原理图：**禁入镜、禁作参考喂模型**（只能内容参考）。

## 三、产品镜头·分段示例（以"出光口微距"为例，完整套公式）

```
【参数】16:9 ｜ 2K ｜ 写实摄影
【镜头】平视微距 90mm，f/1.8，ISO 100，浅景深只留出光口一条清晰焦面
【灯光】冷白顶光 6500K + 出光口暖白 #F4EFE4，边缘冷白辉光/轻微色散；金属高光呈细长拉丝
【主体】石英出光窗（SM 内螺纹金属接口/平行散热鳍片/水冷接头/银白拉丝＝@s22_图片_7 不变），窗内等离子小球＝明亮暖白核+冷蓝外晕（@s17 光斑 0.1mm 椭圆）
【场景/构图】深空近黑底，出光口置右 1/3（三分法），左 2/3 纯黑负空间，金属高光锐利
【动效】静止微距，冷光在金属上流动高光
【文字】出光窗下方 DIN 无衬线白字「玦芯 PHO-SC4」，右下角等宽小字「套刻量测」
【强制约束】无人物｜出光=白光非激光束｜无变形无穿模｜出光口结构=参考图不变
```

## 四、校验清单（交 prompt 前自检）

- [ ] 八段齐全（参数/镜头/灯光/主体/场景构图/动效/文字/强制约束）
- [ ] 产品=干净 / 功能=复杂（该镜属于哪类，密度对不对）
- [ ] 真实造型锁死（"保持真实造型=@参考图不变"是否写入约束）
- [ ] 参考图：取哪部分→放哪位置，写清；水印/竞品/团队照/商标原理图已排除
- [ ] 文字：AI 直出的字写死+位置；精确数据（±0.2%/10000h/170-2500nm 等）生成后核对=手册原文
- [ ] 无抽象词（无"高级感/震撼/电影感"，换具体视觉事实）｜单镜≤2 运镜+变速（动感三来源）
- [ ] 科学红线（发光点=0.1mm 椭圆非大光球/出光=白光非激光束/数据后期或核对/无人物）
