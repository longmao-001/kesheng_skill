# 视觉风格基线（Visual Baseline）— 美术指导用

> 用途：在 九宫格风格预览 / M4 分镜批复之前，用这张表把全片"长什么样"彻底定死，防风格漂移、防"通用 AI 感"。
> 出处：参考 MiniMax Design 的设计系统（根植内容、单强调色、反默认 AI 审美、克制），按科生场景改写。
> 铁则：**风格决策必须根植于内容与目的**——配色/字体"因为贴合内容"而选，绝不"因为看起来高级/安全"而选。

## 一、总则（先读）

1. **根植内容**：先回答"这片子在讲什么、给谁看、要达到什么目的"，再定风格。深青+米色≠专业，衬线+米色≠优雅；一个因为贴合内容而选的颜色，永远胜过因为"看起来安全"而选的颜色。
2. **极简**：能用一种强调色就不加第二种；能删的装饰都删。**一页做到"没有东西可删"才算完成**。
3. **风格 token 块**：定稿后把背景/强调/文字三色 + 字体两款 + 禁忌写进分镜表表头与 prompt 风格 token，全片逐字复用，禁漂移。

## 二、内容信号 → 基调 → 色板（起点表）

按本片定位选一行作为起点，再按项目微调（微调必须注明"根植于____"）。

| 内容信号 | 基调 | 背景 | 强调色 | 文字 |
|---|---|---|---|---|
| 科研 / 仪器 / 硬核分析 | 权威 | 深墨 `#0F1F2E` | 青绿 `#00B4A6` | 暖白 `#F0EDE6` |
| 商业 / 策略 / 融资方案 | 自信 | 近黑 `#1C1C2B` | 琥珀 `#E8A020` | 米白 `#F5F2EC` |
| 创意 / 概念片 / 作品集 | 表现 | 深紫 `#1A0A2E` | 珊瑚 `#FF6B6B` | 薰衣草白 `#FAF5FF` |
| 科普 / 教育 / 论文解读 | 学术 | 暖白 `#FAFAF7` | 海军蓝 `#2C4A7C` | 深墨 `#1A1A2E` |
| 医疗 / 健康 / 居家 | 冷静 | 淡薄荷 `#F5F9F8` | 森林绿 `#2D8B72` | 深绿 `#1E3830` |
| 深色科技 / 产品评测 | 暗房 | 深海军 `#151C27` | 钢蓝 `#4A6FA5` | 暖白 `#F0EDE6` |
| 技术文档 / 开发者工具 | 终端 | 近黑 `#0D1117` | 霓虹绿 `#39D353` | 冷白 `#E6EDF3` |
| 机构 / 品牌宣传 / 年度 | 杂志 | 暖亚麻 `#F2F0EC` | 深海军 `#1C3557` | 近黑 `#0D1A2B` |
| 通用 / 不出错 | 中性 | 暖米白 `#F8F6F1` | 深灰 `#3D3D3D` | 黑 `#1A1A1A` |

**强调色纪律**：
- 只用**一个**强调色；出现在 封面/片头图形、章节规则、数据卡表头、覆盖图高亮，**别处不用**。
- 强调色与背景对比 ≥4.5:1（WCAG AA）。
- **不要默认用蓝色**（AI 生成里最被滥用的强调色，除非内容确实指向海军蓝/科技蓝且非默认）。

## 三、字体配对（两款封顶）

| 基调 | 标题字（display，片头/字卡/落版） | 正文字（text，旁白字幕/图表/正文） |
|---|---|---|
| 权威 | Playfair Display / 思源宋体 Heavy | IBM Plex Sans / 思源黑体 |
| 自信 | Syne / 思源黑体 Black | Nunito Sans / 思源黑体 |
| 表现 | Fraunces / 方正粗宋 | Inter / 思源黑体 |
| 学术 | EB Garamond / 思源宋体 | Source Sans 3 / 思源黑体 |
| 冷静 | DM Serif Display / 思源宋体 | DM Sans / 思源黑体 |
| 暗房 | Playfair Display / 思源宋体 Condensed | EB Garamond / 思源黑体 |
| 终端 | Space Mono / 等宽 | Space Mono / 等宽 |
| 杂志 | Playfair Display / 思源宋体 | EB Garamond / 思源黑体 |
| 中性 | 思源宋体 Medium | 思源黑体 Regular |

> 科学/科普类中文优先 思源宋体（标题）+ 思源黑体（正文）；英文产品名/术语用配对里的西文字体。
> 全片字体 ≤2 款；片头/字卡/落版用标题字，其余用正文字。

## 四、反模式（出现即打回，红队/检察官硬查）

| ❌ 必避免 | 为什么 |
|---|---|
| 白/浅底 + 紫渐变 | 最典型的"AI 生成"默认审美 |
| 海军蓝 + 金 | 烂大街企业风 |
| 全黑底 | 打印差、画面憋 |
| 系统 ≥3 色 | 视觉噪音 |
| 强调色上正文/字幕 | 毁可读性（字幕要白字描边/黑底，不用强调色） |
| 卡片堆砌 / 圆角胶囊 / 大面积投影 | 像模板、不像设计；只允许 ≤4px 圆角且仅提示框 |
| emoji 当图标字 | 出片质感崩、模型渲染不稳 |
| "高级感/震撼/电影感"等抽象词 | 必须换成具体视觉事实（见 product-prompt-formula 无抽象词） |

## 五、克制即品质

- 强调色只出现在"章节/封面/数据卡表头/高亮"上，不铺满。
- 无卡片、无圆角（例外 ≤4px 提示框）、无投影。
- 数据卡=强调色表头 + 交替底纹 + 仅外框；图表配色取自全片强调色，不自设。
- 字幕≤10字/屏断行，白字+描边（或黑底白字），与背景对比清晰；信息卡=数值+单位+出处。

## 六、质量线（出口过）

**一个设计师不屑于递出去的东西才算合格**：封面/片头有清晰视觉身份、不是"通用 AI 输出"；整册一致；每镜风格 token 相同；强调色每页平均 <8 次；无元素出画/重叠/截断。

## 七、填写模板（美术指导出「风格基线」时用）

```
## 风格基线
- 内容信号: （选一行）+ 一句话"为什么"（根植于: 产品定位/受众/内容重点）
- 基调:     （权威/自信/表现/学术/冷静/暗房/终端/杂志/中性）
- 色板:     背景=__ 强调=__ 文字=__   （单强调色，对比≥4.5:1，注明非默认蓝依据）
- 字体:     标题=__ 正文=__  （≤2 款）
- 风格 token 块(视觉部分): <一段逐字复用的描述>
- 禁忌:     （反模式命中项，逐条写死：禁紫渐变/禁≥3色/禁卡片圆角投影/禁emoji/禁抽象词/禁默认蓝）
- 依据:     链接到 brief 的重点/受众/预注册标准
```
