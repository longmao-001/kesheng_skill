# prompt 分段文件模板（templates/prompt-file.md · v2）

> M4「prompt 分段并行」阶段的**唯一文件结构模板**。每个 prompt 工程师按本骨架写 `prompt-<section>.md`（段内 3 镜左右），**格式跨文件必须一致**；内容按项目实情填。
> 实测来源：`runs/20260830-phosc4/prompt-1/2/3.md`（本模板的成稿样例，含全部 9 镜完整写法）。

---

## 文件骨架（逐节照抄）

```
# prompt 段N(镜X–Y) · <项目名> · 单镜单条版 v2

> **✅ 生成约定(单镜单条·主选)**：每镜独立抽卡，平台选 5s 档，单条素材从 0s 起（时间轴 0–5s）；
>   成片在剪映剪至该镜时长（本片镜1–7/9=4.5s、镜8=4.0–4.5s 按口播实测）；
>   若用 LibTV/Seedance 多镜一次生成，再用「多镜备选切分」（段内整数秒连续，如 0–5/5–9/9–14）后按成片边界裁。
> **风格 token 块(唯一合法·逐字粘贴)**：中文块 + 英文块（与美术定稿版**逐字一致**，每镜都带）
> **本段红线速查**：3–5 条（竞品零出现/禁词/数字口径/外观禁AI/数据AI零碰…按项目实情）
> 依据/口径基准（溯源文件与版本）

## 0. 段N 生成路线与硬约束总表（镜/单条生成/成片/路线/AI角色/参考包@/动感来源）

## 镜 N · 单条生成 0–5s → 成片 0–4.5s｜一句话画面｜口播(大字后期)
### N.1 生成路线与分工（关键：AI 做什么、后期做什么）
### N.2 Seedance 2.5 主 prompt（``` 代码块，可整块复制；含 参考包@ 与 贯穿约束收口）
### N.3 可灵备选行（一行式，含负面）
### N.4 负面 prompt（每镜独立·具体排除项）
### N.5 参考图 / 首帧（含「生成参考静帧」文生图 prompt；无则写"无，用 XX 素材"）
### N.6 抽卡建议 + 翻车改法（变体数 / 失败→修复对照表）
### N.7 一致性衔接（尾帧信息 / 与邻镜动作匹配 / 循环点）
### N.8 补充小节（仅该镜专项内容：后期重绘规范 / 视觉规范 / 循环衔接设计…无则删）

## 段成本清单（抽卡次数 / 生成秒数 · 预注册 #7）
## 📤 传递给下游 (@制片人)
```

## 硬要求（写任何一段前自查）

1. **单镜单条**：每镜一个独立 prompt，单条时间轴 **0s 起**；禁止"段内窗口"标注（如 5–9s）出现在标题或 prompt 标签里——多镜切分只作为"备选"说明放在文件头。
2. **节拍时间戳**：单条内部节拍用 `0-2秒[…]`、`2-4秒[…]`（整数秒、连续）；**不得用"镜头1/镜头2"命名内部节拍**（防平台误判多镜）。
3. **风格 token 块**：每个文件头部给全（中+英），N.2 主 prompt 内逐字嵌入；同一项目三个文件头块**逐字全同**（写完自查一次 diff）。
4. **负面 prompt 独立成节**（N.4）：具体排除项，不写"不要/避免"空泛词。
5. **图生视频只写运动**：外观保真镜头一律 @参考包、禁文生；AI 零数据零文字零外观（图表/数字/大字/logo 全后期）。
6. **内容零漂移**：口播/大字/时间轴以 `screenwriter-口播稿.md`（最新版）与 `storyboard-分镜表.md` 为唯一权威；prompt 工程师不得自行改口径。
7. 代码围栏成对；每份结尾保留 `## 📤 传递给下游 (@制片人)` + 3 行总结。
