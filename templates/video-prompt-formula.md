# 视频镜头 Prompt 公式（Video-Prompt 八股文 · 科生可复用模板）

> 用途：写 **AI 视频生成** 的逐镜 prompt（逐镜视频节点/多镜原生）时，一律套本公式。是 `templates/product-prompt-formula.md`（图片）的视频版。
> 依据：调研（Seedance 2.0/2.5 官方与社区指南、6D AI 视频框架、superprompt methodology、抗"AI 塑料感"实践）+ 科生工艺（动感三来源、时间轴断句、口播独立、图表层、首帧锚定、素材分级）。
> 铁律：产品/设备/科研仪器类逐镜视频 prompt **必用本公式**＋产品铁律（产品=干净/功能=复杂、绝不改造真实造型、参考图取哪部分→放哪位置、精确数据核对=手册原文、无抽象词、单镜≤2运镜+变速）。

## 〇、高手怎么写（先懂"8 维"，再套九段）

**别人写得好视频 prompt 的 8 维**（Seedance 6D 框架 + 反塑料感 + LLM 提示词原则）：
1. **主体 Subject**（是什么，聚焦 1 个，写到底——材质/状态/位置）
2. **动作 Motion**（做什么，肢体部位+幅度+轻重，具体到"缓缓抬起/微微低头"）
3. **镜头 Camera**（景别+机位+焦段+运镜；单镜≤2 运镜，用标准词：推/拉/摇/移/跟/环绕/FPV/子弹时间）
4. **环境 Environment**（场景+背景，写 "深空炭黑底+金属台" 不写 "高级感"）
5. **光影 Lighting**（色温+方向+明暗+体积光；"冷白顶光6500K+45°冷蓝rim" 而非 "好看的光"）
6. **风格/氛围 Style**（一句风格 token 块，全片逐字一致；禁"电影感/震撼"这类抽象词）
7. **物理真实（抗 AI 塑料感）**：材质到色号/纹理级、光与物真实交互（金属高光/玻璃微反/水面倒影/灰尘 bokeh）、轻微瑕疵反而真实。
8. **一致性一致性 Consistency**：产品/人物开头说一遍、结尾再说一遍（"same product design, no distortion"）。

> 反 AI 塑料感三招（source: Seedance 硬核短片拆解）：① 关键词换"物理可感"（高光随角度流动/发丝纹≈0.1mm）② 光有交互（rim/倒影/折射/bokeh）③ 加"真实感修饰"（轻微手抖/镜头呼吸/灰尘微粒）。别只堆"8K超清电影级"。

## 一、视频 prompt 九段公式（顺序写死）

```
【参数】时长(s)｜画幅(16:9/9:16)｜后端模型｜单镜时长档(5s/10s)
【参考】@图N（**标角色＋部位对应**：`@图1 是主体（整机）／@图2 是场景参考（用于背景环境）／@图3 是部件参考（散热鳍片＝主体机身鳍片）／@图4 是质感参考`；**若场景参考含主体→注明"图中<位置>的<主体>是主体，取该主体"**；参考图<部位X>＝主体<部位X'>）｜首帧@图N｜@视频N（运镜参考）｜无则写"无"
【风格】<风格 token 块，全片逐字一致>
【镜头】景别(微距/特写/近景/中景/全景/大远景)｜机位(平视/俯视N°/仰视N°/斜俯N°)｜焦段(mm)｜运镜(单镜≤2+变速/复合)
【时间轴】0-Ns[画面+动作+运镜+光影] N-Ms[...]（分段=动作触发/变速/光效/转场；时段连续无重叠；一段只讲一个动作）
【主体】产品/设备（保持真实造型=@参考图不变，禁改形）｜材质到细节(如"银白拉丝铝≈0.1mm/石英出光窗/高光随角度流动")｜位置（产品=干净/功能=复杂）
【声音】音效(清单+轻重，<10点点睛)｜BGM(情绪段)｜配音读法(数字读法/单位不念/型号逐字母/术语读音/语速档)
【口播】本镜旁白原文（**单独字段，绝不并入画面 prompt**）｜字幕=口播逐句(≤10字/屏)
【负面】具体排除项(文字/数据/刻度/水印/logo/变形/穿模/大光球/激光束/人物/霓虹/暖调/彩色渐变/塑料感)
【强制约束】数据核对=手册原文(±0.2%/10000h/170-2500nm 等)｜无抽象词｜动感三来源(单镜≤2运镜+变速/画面内部运动/剪辑节奏)｜科学红线(0.1mm椭圆/白光非激光/无人物)｜一致性(产品形态/风格token/发光点跨镜不变)
```

## 二、两条铁律（同图片公式）
1. **产品展示＝干净 / 功能展示＝复杂**。
2. **绝不改造设备真实造型**（"保持真实造型=@参考图不变"写进【主体】与【强制约束】）。

## 三、视频特有要点（图片公式没有的）
- **【时间轴】按秒断句**：>6s 或多动作/变速/光效变化镜头必写 `0-Ns[画面+动作+运镜+光影]`；分段点=动作触发/变速/光效/转场；时段连续无重叠；一段只讲一个动作；结尾一句贯穿约束收口；单段≤5s。（Seedance 2.5 整数秒时间戳连续；单次生成 ≤30s，超长分段+延长。）
- **【口播】独立字段**：给配音/字幕，绝不并入画面 prompt；转 TTS 读法批注（数字"±0.2%→误差不超过百分之零点二"、型号逐字母 P-H-O-S-C-四、单位不念、停连重音、语速档）。
- **【声音】**：BGM 情绪曲线（钩子静→身份稳→卖点推→收口回落）；音效 <10 点；混音 AI 原生（一键降噪+智能响度+人声避让：口播>BGM>音效）。
- **【负面】必写具体排除项**，不写空泛"不要/避免"。
- **动感三来源**：①运镜（单镜≤2+变速/复合）②画面内部运动（光扫/粒子/前景遮挡）③剪辑节奏（动作匹配/快慢相间）——只写"缓慢推近"匀速单运镜=PPT 式视频，不合格。

## 四、分段示例（产品旋转·身份，完整套九段）
```
【参数】5s ｜ 16:9 ｜ Seedance 2.5 ｜ 5s档
【参考】@图片1（产品主视觉，取其<左控制器+右灯室整体形态>→放本图<正中整机>）+@图片2（灯室，取其<出光口+金属接口>→放本图<右机>）
【风格】冷峻工业精密科技风，深空炭黑底（#282828），银白拉丝金属机身（#D6D9DD），冷白顶光 6500K 略偏蓝；冷蓝单色点缀 #2E6BE6（仅数据层），出光口暖白 #F4EFE4（唯一暖源）；浅景深，慢稳准、克制工业可信，8K；禁彩色渐变/霓虹/暖调/文字水印。
【镜头】全景，平视略低 10°，35mm，运镜=360° 环绕由快渐缓收稳（复合，变速）
【时间轴】0-3秒[产品并排居中静止(禁形变)，镜头360°弧线环绕由快渐缓，冷白顶光勾拉丝纹轮廓，深空底留白] 3-5秒[环绕收稳后轻微缓升，一条冷蓝光带扫过机身拉丝纹（不染机身），铭牌=后期叠加]
【主体】两件式银白拉丝产品（左控制器+右灯室，保持真实造型=@参考图不变，禁改形/新增/歪曲）；产品=干净（留白、单一主体）
【声音】音效：无；BGM 身份段(低频 pad+稀疏电子打击进入)；配音读法：型号逐字母 P-H-O-S-C-四，全称匀速不吞字
【口播】玦芯 PHO-SC4，激光驱动等离子体宽谱光源。（字幕=口播逐句）
【负面】变形，扭曲，文字，字幕，数据，数字，刻度，水印，logo，模糊，抖动，过曝，死黑，卡通化，彩色渐变，霓虹，暖调，大饱和色光洗墙，产品形变，机身染色，机身发光，人物，手
【强制约束】产品静止禁形变｜冷蓝不染机身｜无人物｜无抽象词｜动感三来源(复合运镜+光带扫过+动作匹配)｜一致性(产品=@参考图、风格token=全片)
```

## 五、校验清单（video prompt 交付前）
```
[ ] 八维/九段齐全（主体/动作/镜头/环境/光影/风格/物理真实/一致性；或 参数/参考/风格/镜头/时间轴/主体/声音/口播/负面/强制约束）
[ ] 时间轴按秒断句（>6s或动感变化=分段；时段连续；一段一动作；结尾收口）
[ ] 口播独立字段（不并入画面prompt）；字幕=口播逐句
[ ] 产品=干净/功能=复杂；保真实造型=@参考图不变（主体+约束）
[ ] 参考图"取哪部分→放哪位置"显式；水印/竞品/团队照/商标原理图已排除
[ ] 抗 AI 塑料感：物理可感关键词（材质到细节/光交互/轻瑕疵）、不是堆"8K电影级"
[ ] 声音：音效<10点点睛；BGM 情绪曲线；AI 原生配音/降噪/响度
[ ] 精确数据 核对=手册原文；无抽象词；单镜≤2运镜+变速（动感三来源）
[ ] 科学红线（0.1mm椭圆/白光非激光/无人物）｜一致性（产品/风格token/发光点跨镜）
```
