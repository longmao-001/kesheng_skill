# 科学调查报告（对话 · docx 报告）

> **用途**：科学调查官 M2 调查完成后，把**完整调查报告写入对话**（不是只写文件+3行总结，供直接先读后谈），并据此产出 **docx 报告** + **PPT**。
> **铁则**：讲透、无术语门槛、每条有出处；不确定标"待确认"，**绝不编造**；面向目标受众（不是专家）。

## 一、一句话定位（≤20 字）
> 让完全外行听懂这是啥。

## 二、重点 / 核心看点（3-5 条）
每条 = **是什么 + 为什么重要**（这条值得做视频里的什么）。

## 三、时间（时间线 / 关键节点）
- 发展脉络：该主题/产品/技术的来龙去脉（起源 → 关键里程碑 → 现状/趋势）。
- 关键时间点：年份 + 事件 + 意义（做成可上视频的时间轴）。

## 四、产品原理（怎么工作 / 构成）—— 把主体**上上下下讲透**
- 构成：核心部件/模块/材质（能上图就配产品图/结构图/爆炸图）。
- 工作原理：输入 → 操作 → 输出；关键创新点（去掉这个环节会怎样）。
- 参数口径：核心规格（数值+单位+出处，±误差/范围写实测基准）。

## 五、产品卖点（用户得到的好处，3-5 条）
- 每条 = 目标受众**任务 → 需求 → 卖点 → 证据**（数据/实测/对比）。
- **别只说参数**：讲"用户拿到什么结果"（效率/精度/省时/降低成本/可靠性/体验）。

## 六、科学原理（背后科学 / 机理 / 因果链）
- 为什么成立：原理/机理/定律，讲清因果链，不夸大（红队会打）。
- 有误导读者的类比 → 指出并换。
