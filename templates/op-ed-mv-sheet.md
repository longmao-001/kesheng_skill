# 🎬 OP/ED 卡点表·填法说明（**通道 C ∩ 通道 B 特化**）

> ## ⚠️ 本表不重复字段
> **卡点表／镜头表／素材复用清单 = 只做一份，唯一模板 `templates/mv-beat-sheet.md`。**
> **本文＝OP/ED（C∩B）的"特化填法说明"**：告诉你**在 C∩B 场景下，那张表的每一格该怎么填、哪些格被收紧、哪些格被锁死**。
> **禁**：另建第二套字段表（两套字段＝两套事实＝漂移源·承 `docs/USER_SOP.md` §2.6③「共用底层只有一份」）。
>
> **通用填法** → `templates/mv-beat-sheet.md`（表 0／一／二／三／四）
> **通道 C 通用纪律** → `playbooks/mv-production.md`
> **C∩B 特化纪律** → `playbooks/op-ed-mv.md`

## 一、怎么用（三步）

| 步 | 动作 |
|---|---|
| **1** | 复制 `templates/mv-beat-sheet.md` → `runs/<季slug>/series/mv-beat-sheet.md`（**跨集共享资产·项目级目录**，**禁每个 EP 目录各存一份**·承 #40②） |
| **2** | 在**表 0·交集判定**勾 **`☑ C∩B（剧集侧）`**，并填 **OP/ED 段的时间码范围** |
| **3** | **按本文 §二 的"逐格特化填法"填那张表**；填完过本文 §四 的**交付前核对清单** |

> **OP/ED 可共用一张表**：OP 与 ED 若为同一支曲的不同段落，**同一张表分段填**（表一注段落）；若为两首不同的歌，**各出一张表**（文件名 `mv-beat-sheet-OP.md`／`mv-beat-sheet-ED.md`），**时长各为独立固定资产**。

## 二、逐格特化填法（表 0 → 表四）

> 左列＝`templates/mv-beat-sheet.md` 的原格；右列＝**C∩B（OP/ED）怎么填**。

### 表 0 · 曲目与契约

| 原格 | **OP/ED（C∩B）填法** |
|---|---|
| 交集判定 | **必勾 `☑ C∩B（剧集侧）`**（硬规则 #44②）；**并在 `brief.md` 同步写明** |
| 本片属 C 段的时间码范围 | 填 **OP 段**与**ED 段**各自的范围（两段都是 C 段）；**正片不在 C 段内** |
| 谁在唱 | **OP 主题歌＝叙述层**（本项目裁定）；**剧中人唱段须另立**（本项目：剧中人唱段唯一＝〈好了歌〉）——**不得混权**（承 #31 六维①） |
| 歌词是否摘用既有文本 | 是 → **歌词／引文闸已过**（`playbooks/animation-motion-design.md` §2b.4）；**同句在正片的出声点须实测标出**（避免重复消耗） |
| 编曲终稿（唯一事实源） | **锁定后波形＝卡点表唯一依据**；**禁"按旧版编曲排镜头、后来换编曲"** |
| 时长版本 | **不是"选一个版本"，而是"写入季契约"**——`op_seconds`／`ed_seconds`（见 §三 收紧项 1） |
| 契约秒数（母表＝最长版） | **OP 与 ED 各一个契约秒数**；**二者互不换算**（OP 90s ≠ ED 90s 的义务） |
| 时长契约落点 | **`series-config.json` 的 `op_seconds`／`ed_seconds`**（＋`feature_min_seconds`／`feature_tolerance`）→ **D-S1** |
| 母题回环位（写死） | **必须写"OP 出现 → ED 回环"这一对**（承 #36 §⑦ 母题登记；`playbooks/series-production.md` §4.2 母题纪律：**宁少勿滥、复用必须可辨认、禁止无功能复现**） |
| 总镜头数 | 与 **圣经 §⑧ 登记的镜数**一致（两处不一致＝先收敛再开抽·承 #31 版本锁定） |

### 表一 · 卡点表

| 原格 | **OP/ED（C∩B）填法** |
|---|---|
| 段落 | 与**编曲终稿**段落一致（前奏／A段／B段／桥段／副歌／末副歌／末句） |
| 时间码 | 起止都写（0.1s 精度）；**相邻段落首尾相接** |
| 卡点／静默点 | **静默点必须显式标出**（`○`）——**OP/ED 尤其容易"用镜头填满静默点"**（＝E-17） |
| 镜头数 | 与表二行数对账；**另须与圣经 §⑧ 镜数一致** |
| **合计行** | **`Σ段落时长 ≡ op_seconds`（或 `ed_seconds`），误差 0** —— **`浮动＝0`**（§三 收紧项 1） |

### 表二 · 镜头表

| 原格 | **OP/ED（C∩B）填法** |
|---|---|
| 镜号 | 建议带 **`OP-`／`ED-` 前缀 ＋ 集号无关的季级编号**（**固定资产全季同一套镜号**·承 `playbooks/series-production.md` §9.2 命名规范）；**定制位镜另标 `SLOT-`** |
| 画面内容 | **OP/ED 是"意象"不是"情节"**——画面写"意象＋音乐事件"，**不写"因为→所以"的剧情因果** |
| 素材来源 | **正片/剧集镜号优先（P1）**；固定资产（P2）；新产（P3·逐条写理由）。**复用率 ≥60%** |
| 动作与动机 | **`动作动机＝……` 必须指向音乐**（如"副歌重音处的鼓点"），**不是剧情因果**（承 #28⑤ 的 C 段变体） |
| 文字（白名单内） | **OP/ED 白名单写死＝①片头标题字（片名＋注音副题＋落印）②物件上的字（玉面镌字／石面刻字／印章）**；**谶语／诗词句逐字上屏一律移入正片**（硬规则 #33） |
| 声音脊椎 | 与**声音方案／编曲终稿**同源；**OP/ED 内人声＝0 句**（旁白移入正片·本项目裁定） |
| 抽卡建议 | **季一次**：`OP 镜数 × 4–6 抽 ＋ ED 镜数 × 4–6 抽`（高风险：坠落／墨浪／扩散类）——见 `playbooks/series-production.md` §10.1⑥ |
| 状态 | 待抽／已选／已采纳；**采纳版 prompt 须回贴唯一索引**（承 #41） |

### 表三 · 素材复用清单

| 原格 | **OP/ED（C∩B）填法** |
|---|---|
| 来源类型 | **P1 正片/剧集素材复用优先**（本项目 OP/ED 29 镜中约 60% 可同素材变体复用） |
| 复用形态（二次构图） | 换景别／速度／**方向见 §三 收紧项 3**／调性 |

## 三、四处收紧项（C∩B 比通用通道 C 更严）

| # | 收紧项 | 通用通道 C | **C∩B（OP/ED）** |
|---|---|---|---|
| **1** | **时长契约** | **每版各自契约**（15/30/60/90s 各自唯一） | **逐集逐秒相等、浮动＝0**（`series-config.json` 的 `op_seconds`／`ed_seconds` → **D-S1**） |
| **2** | **可变格** | 版本矩阵（画幅×时长）＋片别定制位 | **只有"集别定制位"三格**（集号／回目小字／定制镜）；**版本矩阵退化为一行**（季级固定资产） |
| **3** | **镜像禁用面** | 含文字／logo／印章的镜禁镜像 | **同左，且更严**：OP/ED 素材含**片名墨迹／印文／器物镌字**的概率高——**凡含任何字形笔画的镜一律禁镜像**（字会反） |
| **4** | **文字白名单** | 按交集定（C∩A 允许 slogan／参数卡） | **只允许 ①片名＋注音副题＋落印 ②物件上的字**；**禁浮空字卡**（硬规则 #33）＋机器门控 **D12** |
| **5** | **红线继承** | 按项目主约束 | **全季红线跨集继承**（无光之戏禁亮词／OP 禁浮空字卡／无后期）——**不得因"C 段特殊"临时开口**（承 #36⑩） |

## 四、集别定制位（OP/ED 唯一可变格·详表）

> 这是"逐集逐秒相等"的**唯一出口**：**定制位之外逐格冻结**。

### 4.1 三格定义

| 定制位 | 可变内容 | 不可变约束 | 谁来定 |
|---|---|---|---|
| **集号** | "第 N 集"／"EP0N"（**若采用；本项目未采用**） | **字形锁字帖**；**镜长固定**；不得挤压契约时长 | 分集大纲（季契约） |
| **回目小字** | 本集回目（承 `playbooks/series-production.md` §3.4 回目体系） | **字形仍锁字帖**；**回目体例＝跨集契约**（不得每集自造）；镜长固定 | 分集大纲＋圣经 §⑥ |
| **定制镜** | **1–2 镜"本集专属闪帧"**（如本集关键意象一帧） | **Slot 内换素材，Slot 外不动**；**换素材不改镜长**；素材须在唯一索引可查 | 单集简报（`templates/episode-brief.md`） |

### 4.2 逐集登记表（复制到项目 `runs/<季slug>/series/` 下维护）

| 集 | 集号文本 | 回目小字 | 定制镜镜号 | 定制镜内容 | 镜长（**契约内·不可变**） | 素材（索引 ID） | 状态 |
|---|---|---|---|---|---|---|---|
| EP01 | `______` | `______` | `SLOT-01` | | `_._s` | | ☐ |
| EP02 | `______` | `______` | `SLOT-01` | | `_._s` | | ☐ |
| … | | | | | | | ☐ |

**填表自检**：
- [ ] **三格之外，OP/ED 逐格冻结**（未列入本表的任何镜／时间码都不得逐集变动）
- [ ] **定制镜秒数从自身预算里扣**——**契约总秒数未变**（`Σ` 仍 ≡ `op_seconds`／`ed_seconds`）
- [ ] **换素材未改镜长**（改了镜长＝改了卡点＝违约）
- [ ] **回目体例跨集一致**（不得每集自造体例·承 #39③／E-09）
- [ ] **逐集逐秒相等**——**D-S1 通过**（`scripts/check_series_consistency.py`）
- [ ] 本表与 **圣经 §⑧**、**分集大纲**、**单集简报**三处**同源**（不一致＝先收敛再开抽·承 #31 版本锁定）
