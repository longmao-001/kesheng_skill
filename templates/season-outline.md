# 全季分集大纲（Season Outline）

> **用途**：剧集项目**全季规划的单一事实源**（KSP-E1 产物）。制片人＋导演＋编剧填；**用户拍板后冻结**，之后每一集的剧本/分镜/prompt 都**引用本表、不得另写一份**。
> **来源**：**红楼梦 EP01 暂停复盘（用户裁定 20260917）**。
> **铁则**：**没有本表，不许开第一集。** 本表未过闸 → 不许写剧本、不许抽锚图、不许出字帖。
> **配套**：`playbooks/series-production.md` §三（全季规划纪律）／`templates/show-bible.md`（风格圣经）／`templates/episode-brief.md`（分集简报）／`playbooks/animation-motion-design.md`（动画类逐集必读）。

## 三、逐列填写规则（写死）

| 列 | 填什么 | 硬要求（不过即打回） |
|---|---|---|
| **集号** | `EP01`…`EPnn`（两位数字，**跨集唯一**） | 集号进镜号前缀，不许与季 slug 混写 |
| **改编范围** | 母体回目/事件；**写明模型**：`第N回`＝一集 ／ `第x–y回` ／ `第N回→EPnn–EPnn+2` | **切点必须是事件边界**（不在情绪中间切）；切点写得出依据（回目/行号/事件名） |
| **主线** | 本集**讲完的那一件事**：一句话，有主语、有结果 | 不许写"承接上集、铺垫下集"这类无结果句 |
| **钩子·开集** | 前 15 秒抓什么（接住上集钩／本集独立钩） | 剧集版"前 5 秒钩子"＝**前 15 秒**；必须写具体画面/事件 |
| **钩子·集尾** | 类型（悬念/预告/伏笔回收/情绪/章回体）＋钩的是什么＋**兑现责任人（哪一集哪一拍）** | **写不出兑现集号＝空钩＝FAIL**；一集一主钩 |
| **情绪曲线** | `起__→峰__（第__分）→谷__→收__`（0–10，标峰谷落点） | 与 `show-bible.md` §⑩ 的情绪节拍规则一致；谷底不许演轻快 |
| **新增角色/场景** | 本集**首次出现**的角色/场景/道具（**必须同时登记进圣经拿 ID**） | **未登记进圣经的新增项不得写进本集 prompt**（先入册后开抽） |
| **复用资产** | 从 `series-asset-index.md` 取 ID：`C1a`／`S3`／`#22`／`M-转场01`… | 一律写 ID（不写"那个主角图"）；用完回写索引"复用集"列 |
| **时长结构** | `OP__s / 正片__分__s / ED__s`，总时长 | **OP/ED 逐集逐秒相等**（固定资产）；正片在容差内；超限走拍板卡 #14 |
| **状态** | 图例取值 | 每完成一段即更新（STATE.md 同步） |

> **回目写法**（改编范围列内）：原著回目**逐字照录底本**；自拟回目须满足**四条判据**（字数相等／对仗工整／尾字仄平合律／**事实可回指底本行号且不暗示原著没有的因果去向**）并过**文学闸（六维）**——参见 `playbooks/series-production.md` §3.4 与本项目 `m4-回目复核.md`（「元宵夜烈火焚甄家」时间错位、「双影赴北邙」去向误导均被判必改）。

## 五、门控自检（KSP-E1 全季规划闸 · 逐条打勾）

- [ ] 剧集判型已完成（`brief.md` 无"先做1集样片"类单条口径）
- [ ] 集数 N 与单集时长（含 **OP/ED 固定资产时长**）已定且**用户拍板**
- [ ] 改编边界模型已选定（A/B/C 择一），**全表切点均在事件边界**且写得出依据
- [ ] **每一集**五项齐：主线（有结果）／钩子（开集＋集尾）／情绪曲线（含峰谷落点）／新增角色场景／时长结构
- [ ] **每个集尾钩都写了兑现集号**（钩子账本无空项）
- [ ] 回目体系三层分清（原著回目照录／自拟回目过文学闸＋对仗平仄＋行号依据／章节卡版式见圣经）
- [ ] 新增角色/场景已**登记进 `show-bible.md`**（拿到 ID）
- [ ] 复用资产一律写 ID，且已在 `series-asset-index.md` 存在
- [ ] OP/ED 时长逐集一致；正片在容差内
- [ ] 用户已拍板（选项卡：按此全季规划执行 (Recommended)／改集数与时长／改改编边界／改分集大纲／自定义）
- [ ] 落盘 `runs/<series-slug>/season-outline.md`；STATE.md 已更新；后续变更走 **KSP-C** 并登记圣经 §⑪
