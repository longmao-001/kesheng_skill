# Prompt Sheet 统一交付格式 · 严格规范 v1.2（机器校验）

> **铁则**：交付给用户的所有 prompt 文件**必须**符合本规范；**每次交付前跑门控，FAIL 不得交付**：
> `python -X utf8 scripts/check_prompt_sheet.py <runs/<项目>>`（格式与一致性）＋ `python -X utf8 scripts/check_prompt_sop.py <runs/<项目>>`（十步证据）＋ **`python -X utf8 scripts/check_prompt_delivery.py <runs/<项目>>`（交付口径 D1-D10）**。字段名、顺序、文件命名、风格 token 一致性全部写死，禁止任何变体/别名/自创写法。
>
> **⚠️ v1.2 变更（红楼梦EP01·用户裁定 20260915，最高优先）**：**交付格式＝单一 SOP 合并块**——正文即 `【参考】【风格】【时间轴】【口播】【声音】【负面】【参数】` **合并为一个代码块**，**整块复制即用＝终稿**；**负面内嵌同块末尾**；**⛔ 禁止再另写"平台prompt"第二版本**（两套写法＝用户困惑源）。字段规范新增 **动作动机** 与 **字卡字形要求**；新增规则 **R12–R16**。
>
> **机器门控的容错范围（F-30）**：`check_prompt_sheet.py` 强制的是**核心字段完整且非空**（参考/风格/时间轴/口播/声音/负面/参数）＋ 口播单独成字段且与口播稿一致 ＋ 风格 token 全片一致 ＋ 参考 `@` 引用 ＋ 负面非空；**兼容两代字段标记**（本模板的 `**字段**：` 与实务常用的 `【字段】`）与**合法新增字段**（镜头/主体/强制约束等，不因多字段而报"顺序错"）；参数关键词与图文对位为**提示**不阻断。**R2 严格顺序仅在字段集合恰为七段核心时强制**。

## 一、文件命名（严格）

```
runs/<项目>/m4-prompts/
├── README.md                  ← 必须：全片索引
├── prompts-Seedance2.5.md     ← 平台名固定词表: Seedance2.5 / Jimeng / Kling /
├── prompts-Jimeng.md             LibTV / Vidu / Hailuo / Wan / Runway
├── prompts-Kling.md
└── prompts-LibTV.md
```
（每平台一个文件；平台名固定词表，不用别名/大小写变体；未用平台不建文件。）
> **平台差异靠"一平台一文件＋块内调词序"表达**——**不是**靠在同一文件里写第二条"平台prompt"（R12）。

## 二、单文件结构（严格，顺序写死）

````markdown
# <项目名> · <平台名> Prompt 表
> 风格基线：<宫格确认的风格token块，逐字复用>
> 参考资产：@图片1=<实际文件名> / @图片2=<实际文件名> …
> 平台版本：<固定词表> · 画幅：16:9 · 单镜时长档：5s

### 镜头 A7 · 5s · 参考生视频
<!-- 以下整段放进同一个代码块，整块复制即用＝终稿 -->
```
【参考】@图片1=<实际文件名>（取<哪部分>→放<哪位置>）＋@图片2=<实际文件名>（取<哪部分>→放<哪位置>）
（上传顺序：@图片1=<实际文件名>；@图片2=<实际文件名>）
【风格】<风格token块，逐字复用>
【时间轴】0-2秒 <主体预备/蓄势>…；2-4秒 <主体发力/动作>…；4-5秒 <跟随→回收>，动作动机＝<对应台词/谶语/情绪：含义/说的是/象征/对位/意味着/谶/执/梦/命>；末段做余动处理：主体动作渐慢回稳，余摆未歇即转入下一镜。
【口播】<本镜旁白原文，单独成字段；无则写"无">（口播稿必带**读法批注**：数字读法±0.2%→"误差不超过百分之零点二"／单位不念／型号逐字母PHO-SC-4／停连重音／语速档——配音直接照读）
【声音】<BGM/音效/口吻，全部由视频模型原生生成；无则"无">
【负面】<通用负面词块> ＋ <该镜专属附加词>（内嵌同块末尾，禁另起块）
【参数】5s档 · 抽卡4次 · 失败改法：<改参考组／改措辞／重抽，三选一>
```
````

**❌ 禁止**：在同一个镜头条目下**再写第二条可复制 prompt**（`【视频prompt】`／`【平台prompt】`／`【对照】`／"可灵版：…"）——**两套写法＝用户困惑源**（R12）。**负面不得另起代码块**（R2/D3）。段首公共块（风格token／通用负面）可在文件头部以代码块给出，但**每镜条目内仍须内嵌**（复制即用）。

## 三、硬性规则（校验项）

| # | 规则 | 校验 |
|---|---|---|
| R1 | 每镜块标题 `### 镜头 <id> · <数字>s · <路线>`；路线 ∈ T2V/I2V/参考生视频/首尾帧/多镜原生 | 正则 |
| R2 | 每镜字段**严格按序**：参考→风格→时间轴→**口播**→声音→负面→参数 | 顺序 |
| R3 | **风格 token 块全片逐字一致**（所有文件×所有镜头，与 README 基线一致） | 一致性 |
| R4 | 时间轴至少 1 段，格式 `\d+-\d+秒 [..]`（或平台原生写法"镜头N/时间戳"且跨镜连续） | 分段 |
| R5 | 参数必须含：时长档 · 抽卡 · 失败改法 三项 | 关键词 |
| R6 | 参考字段 `@图片N（用途）`（无参考写"无"） | 语法 |
| R7 | 负面词不得为空；无则写"无" | 非空 |
| R8 | README.md 存在且含 平台×路线×风格基线 三要素 | 必存 |
| R9 | 文件名 ∈ 固定词表 `prompts-<平台>.md` | 命名 |
| R10 | 风格基线=宫格确认版（与 brief 重点协议中记录的 token 相同） | 一致性 |
| **R11** | **口播字段必在**：`口播：<该镜头旁白原文，无则"无">`；若存在 `screenwriter-口播稿*.md`，每镜头口播文本（去标点归一化）必须出现在口播稿中 | 必在+一致性 |
| **R12** | **交付＝单一 SOP 合并块**（红楼梦EP01·用户裁定 20260915）：`【参考】【风格】【时间轴】【口播】【声音】【负面】【参数】` **在同一代码块内**；**负面内嵌同块**；**禁止另写"平台prompt"第二版本**（同一镜只允许一条可复制文本） | 单块+禁第二版本（门控 `check_prompt_delivery.py` **D11**，默认关，项目内配 `check_second_prompt=true` 启用） |
| **R13** | **@标记贯穿＋实名上传顺序**：素材指代段与正文同步 `@图片N`；【参考】逐条写 `@图片N=实际文件名（取哪→放哪）`，字段末另起一行 `（上传顺序：@图片1=…；@图片2=…）`；**库内未生成件标【库内未生成·待补】**，禁编造文件名 | 贯穿+实名 |
| **R14** | **动画性（动画类项目必含）**：时间轴须含 **`动作动机＝…`**（动机句指到台词/谶语/情绪）＋**三层动**（主体表演／次级运动／动作曲线，曲线词≥2）；负面须含动画性禁项 ≥2 ＋ `与叙事无关的空洞特效, 无意义的风吹草动` | 动机+三层动 |
| **R15** | **字卡字形要求**：字卡由**模型原生生成**，prompt 内**逐字写出文字**并写明**字形**（碑刻楷/繁体/笔画完整/位置/字号），时间轴写"**逐字书写而出**"（禁 弹出/叠加/上屏）；**字卡镜**负面钉 `简体字, 字形残缺, 字形错误`；**非字卡镜**保留 `文字, 印章, 题字` | 书写性+分档 |
| **R16** | **无后期**：全文（含参数与失败改法）不得出现 `后期配音/后期叠/后期合成/后期字卡/后期调色` 等表述；失败改法只有 改参考组／改措辞／重抽；声音类工序写「**声音工序处理**」 | 禁词 |

## 四、使用

- 编剧→口播、分镜师→分镜表之后，prompt 工程师**直接产出** `prompts-<平台>.md`（不再先写草稿再整理）；**一镜一块到底，不产出第二版本**。
- 全部写完 → 制片人跑三门控（`check_prompt_sheet.py`＋`check_prompt_sop.py`＋`check_prompt_delivery.py`）→ PASS 才进 M4 出口 / 用户拍板
- FAIL 项回传给对应段的 prompt 工程师修改（≤2 循环）
- 动画类项目：时间轴与负面按 `playbooks/animation-motion-design.md` 写；故事板按 `playbooks/storyboard-grid.md` 故事板五铁律写。

> **来源标注**：R12–R16 与 §二 合并块结构，来源＝**红楼梦EP01·用户裁定 20260915**（交付格式／@映射／无后期／字卡口径／动画性纪律）。
