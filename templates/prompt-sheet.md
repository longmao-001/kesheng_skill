# Prompt Sheet 统一交付格式 · 严格规范 v1.1（机器校验）

> **铁则**：交付给用户的所有 prompt 文件**必须**符合本规范；**每次交付前跑 `python F:/AI/kesheng/scripts/check_prompt_sheet.py <runs/<项目>>` 校验，FAIL 不得交付**。字段名、顺序、文件命名、风格 token 一致性全部写死，禁止任何变体/别名/自创写法。

## 一、文件命名（严格）

```
runs/<项目>/m4-prompts/
├── README.md                  ← 必须：全片索引
├── prompts-Seedance2.5.md     ← 平台名固定词表: Seedance2.5 / Jimeng / Kling /
├── prompts-Jimeng.md             LibTV / Vidu / Hailuo / Wan / Runway
├── prompts-Kling.md
└── prompts-LibTV.md
```
（每平台一个文件；平台名固定词表，不用别名/大小写变体；未用平台不建文件。）

## 二、单文件结构（严格，顺序写死）

```
# <项目名> · <平台名> Prompt 表
> 风格基线：<九宫格确认的风格token块，逐字复用>
> 参考资产：@图片1=<官方渲染> / @图片2=<三视图> …
> 平台版本：<固定词表> · 画幅：16:9 · 单镜时长档：5s

### 镜头 A7 · 5s · 参考生视频
**参考**：@图片1（唯一外观锚定）+ @图片2（结构）
**风格**：<风格token块，逐字复用>
**时间轴**：
0-2秒 [画面+动作+运镜+光影]
2-5秒 [画面+动作+运镜+光影]
**口播**：<本镜旁白原文，单独成字段；绝不并入上画面 prompt 正文；无则写"无">（口播稿必带**读法批注**：数字读法±0.2%→"误差不超过百分之零点二"／单位不念／型号逐字母PHO-SC-4／停连重音／语速档——配音直接照读）
**声音**：无
**负面**：<具体排除项>
**参数**：5s档 · 抽卡4次 · 失败改法：<1句>
```

## 三、硬性规则（校验项）

| # | 规则 | 校验 |
|---|---|---|
| R1 | 每镜块标题 `### 镜头 <id> · <数字>s · <路线>`；路线 ∈ T2V/I2V/参考生视频/首尾帧/多镜原生 | 正则 |
| R2 | 每镜字段**严格按序**：参考→风格→时间轴→**口播**→声音→负面→参数 | 顺序 |
| R3 | **风格 token 块全片逐字一致**（所有文件×所有镜头，与 README 基线一致） | 一致性 |
| R4 | 时间轴至少 1 段，格式 `\d+-\d+秒 [..]`（或平台原生写法"镜头N/时间戳"且跨镜连续） | 分段 |
| R5 | 参数必须含：时长档 · 抽卡 · 失败改法 三项 | 关键词 |
| R6 | 参考字段 `@图片N（用途）`（无参考写"无"） | 语法 |
| R7 | 负面词不得为空；无则写"无" | 非空 |
| R8 | README.md 存在且含 平台×路线×风格基线 三要素 | 必存 |
| R9 | 文件名 ∈ 固定词表 `prompts-<平台>.md` | 命名 |
| R10 | 风格基线=九宫格确认版（与 brief 重点协议中记录的 token 相同） | 一致性 |
| **R11** | **口播字段必在**：`**口播**：<该镜头旁白原文，无则"无">`；若存在 `screenwriter-口播稿*.md`，每镜头口播文本（去标点归一化）必须出现在口播稿中 | 必在+一致性 |

## 四、使用

- 编剧→口播、分镜师→分镜表之后，prompt 工程师**直接产出** `prompts-<平台>.md`（不再先写草稿再整理）
- 全部写完 → 制片人跑校验 → PASS 才进 M4 出口 / 用户拍板
- FAIL 项回传给对应段的 prompt 工程师修改（≤2 循环）
