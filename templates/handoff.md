# 📤 交接块规范（Handoff 轻引用）

> 每个 worker subagent 的产出文件**末尾必须有** `## 📤 传递给下游 (@制片人)` 块。
> 目的：防"电话游戏"——agent 之间只传轻引用（路径+摘要+置信度），全文在黑板文件里，下游按需读取。
> 参考：Anthropic 制品落盘模式、A2A Agent Card（谁来/拿什么/验收什么）。

## 格式

````markdown
## 📤 传递给下游 (@制片人)

- **角色/文件**：<角色> → `runs/<项目slug>/<角色>-<制品>.md`
- **关键产出（≤3 条）**：
  1. <结论或制品要点>
  2. <结论或制品要点>
  3. <结论或制品要点>
- **置信度自评**：高 / 中 / 低
- **待确认清单**：
  - [ ] <需要制片人拍板/查证的事项>（如涉及科学数据：标注出处或"待确认"）
- **下游建议**：<建议下游角色读哪个文件、做什么>
````

## 填写规则

1. **必须带**：路径 + 关键产出摘要 + 置信度自评。缺一不可，否则制片人打回补写。
2. **只传轻引用**：摘要 ≤3 条、每条 ≤25 字；全文不得复制进 📤 块。
3. **科学准确铁律生效**：摘要中的数字/结论必须与正文一致，有出处；待确认项必须显式列出。
4. **下游建议**指向明确的下一角色与文件路径（如"建议编剧读 director-分镜表.md"）。
5. 每里程碑结束时，制片人把该里程碑的全部 📤 汇总成交接卡：**谁来、拿什么、验收什么**，附在会议纪要里。

## 示例

```markdown
## 📤 传递给下游 (@制片人)

- **角色/文件**：科学顾问 → `runs/20260901-基因编辑/scientist-理解报告.md`
- **关键产出**：
  1. 深度等级 L2（机制层），7 步理解全文见报告
  2. 关键数据 5 条均有文献出处（Nature 2023 等）
  3. 待确认 2 项：CRISPR 递送效率数字、脱靶率口径
- **置信度自评**：中
- **待确认清单**：
  - [ ] 脱靶率数据需制片人查证或向用户要材料
- **下游建议**：编剧提案前先读报告"类比库"一节，避免误导性类比
```
