# 大项目拆分模板（Breakdown）

> 项目过大（>6 分钟、多主题、多受众）时，先拆成多个独立视频子项目，再逐个走 M1-M5。

以科研视频产品经理的身份执行拆分。

## 拆分原则
- MECE：子项目之间不重叠、不遗漏
- 每个子项目都能独立成立
- 合起来有协同效应
- 推荐单视频时长：1.5-6 分钟

## 拆分维度（可组合使用）
A. 按技术模块拆　B. 按受众层级拆　C. 按叙事线拆　D. 按问答对拆　E. 按时间线拆

## 输出格式

### 项目总览
- 拆分策略、子项目总数、预计总时长、优先级排序

### 每个子项目 Brief

| 属性 | 内容 |
|------|------|
| 定位 | 一句话概括 |
| 受众 | 专家/领导/公众/学生/产业 |
| 时长建议 | X min |
| 优先级 | P0/P1/P2 |
| 内容要点 | 3-5 个关键信息点 |
| 推荐钩子 | 开头 5 秒抓人的点 |
| 素材需求 | 已有/需生成/需补充 |

### 制作路线图
Phase 1 (P0) → Phase 2 (P1) → Phase 3 (P2)
