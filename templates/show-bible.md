# 风格圣经（Show Bible）

> **用途**：剧集项目**跨集统一固定资产的单一事实源**（KSP-E2 产物）。美术指导主笔，导演会签，制片人汇总，**用户拍板**。
> **来源**：**红楼梦 EP01 暂停复盘（用户裁定 20260917）**。
> **铁则**：**新增设定必须先入圣经**——任何本集新出现的角色／场景／道具／色值／字体／帖／母题／叙事层变化，**先在本册登记拿到 ID，才允许写进本集 prompt／出图／抽卡**。未入册即出图＝流程事故。
> **未过圣经闸（十节齐＋红线表写死＋美术会签＋用户拍板）→ 不许抽任何一张锚图／字帖／母题素材。**
> **配套**：`playbooks/series-production.md` §四（圣经纪律）／`templates/season-outline.md`／`templates/episode-brief.md`／`templates/visual-baseline.md`（单条项目的风格基线，本册是其剧集版）／`playbooks/animation-motion-design.md`（动画性＋文学闸＋字帖铁律）。

**填写说明**：每节先给「本册口径」，再给「**示例（仅供格式参照）**」。示例取自红楼梦 EP01，照抄时**内容必须按本项目改写**。

## ⓪ 本册版本与引用登记（**必填** —— 跨项目/衍生片引用圣经必须 pin 版本）

> **规则（用户裁定 20260921 · 与硬规则 #36③ 联动）**：**跨项目/衍生片引用本圣经时必须 pin 版本**，**防圣经改版后静默过期**——引用方（某集 / 某支衍生宣传片 / 海报 / 预告）若只写"见圣经"，圣经一改版就无从判断它用的是哪一版，色值/字形/母题/红线会**静默漂移**。
> **三处必须写死**：①**版本号**（`v1` 起递增）②**生效日期**（`YYYY-MM-DD`）③**生效集号**（`EP__–EP__`）。

| 项 | 写什么 |
|---|---|
| **本册版本号** | `v__`（每次改版递增，禁就地覆盖不留痕） |
| **本册生效日期 / 生效集号** | `____-__-__` ／ `EP__–EP__`（承 #36③「版本与生效集号写死」） |
| **本册落盘路径** | `runs/<series-slug>/show-bible.md`（引用方按此路径 ＋ 版本号 pin） |
| **引用登记（谁 pin 了哪一版）** | 逐条：`引用方（EP__ / 衍生片 slug）｜引用路径＋版本号｜引用日期｜用途` |
| **改版影响清单** | 每版一行：改了哪节（色板/字形/母题/红线…）｜受影响引用方｜回炉范围｜处置状态 |
| **衍生片（通道 A）引用** | 剧集衍生宣传片/先导预告走通道 A 时**引本圣经即可、不另做全季大纲**（硬规则 #42③），但**必须同样 pin 版本** |

**示例（格式参照）**：`v3｜2026-09-21 生效｜EP01–EP08｜runs/20260917-红楼梦动漫/show-bible.md`；引用登记：`EP05｜v3｜2026-09-22｜该集色板/字帖基准`；`衍生片-先导预告｜v3｜2026-09-23｜片头口号卡用色与片名字形`。

**写不出＝不通过**：引用方找不到"路径＋版本号/日期"＝该引用**不可判过期**，按 #36③ 视为口径未收敛（回 KSP-C）。

**示例（红楼梦 EP01）**：*(1) 宪法*——「把《红楼梦》拍成一部'开场就剧透完结局、观众却眼睁睁看角色一步入谶中'的水墨章节体动画；谶语是碑文，水是命运的可见形态，**墨的浓淡代替光**，眼泪是全片唯一烧不毁的朱砂。」*(2) 根植于*——受众＝大众国风动漫爱好者＋红学爱好者（画面给大众、字卡给红学）。*(3) 不可动摇项*——①**无光之戏**（明暗只来自墨的浓淡）②**留白不破**（神话甲级≥55%）③**单一转场语法**（枯笔扫）。

## ② 色板与色彩语义（**语义绑定＋配额＋豁免**，三者缺一不可）

> **只写色值不够**——剧集的色是"语言"：每个点睛色必须绑定语义、写明配额上限、写明豁免条款；**跨集不得改动语义**。

### 2.1 主色阶（按风格自定义命名，例：墨五色）

|---|---|---|---|---|
| 一 · 焦墨 | `#1a1714–#2b2620` | 宿命刻痕 | 题字/瞳仁/最重处/字卡书法 | — |
| 二 · 浓墨 | `#3a352c–#524c40` | 压迫·神明在场 |  | — |
| 三 · 重墨 | `#6b6455–#8a8272` | 现实重量·谷底 |  | — |
| 四 · 淡墨 | `#a89f8d–#c4bcaa` | 远观·日常 |  | — |
| 五 · 清墨 | `#d8d2c2–#ece7d8` | 空·幻·悟 |  | — |

### 2.2 点睛色（每个都须"语义＋配额＋豁免"三件套）

| 点睛色 | 色值 | **语义（必须在全季一致）** | **配额** | **豁免条款** | 落点 |
|---|---|---|---|---|---|
| 点睛 · 泥金 | `#b8934a–#cfa85e` | **幻** | ≤5% 画幅 | 仅幻境/幻物 | 通灵宝玉/太虚 |
| 点睛 · 朱砂 | `#b5432f–#c8544a` | **劫 / 情** | 限段（见下） | **「泪＝全片唯一不褪之朱」永久豁免褪色法则** | 判词/灯笼/大火/绛珠泪 |
| 点睛 · 赭石 | `#9c7a52–#b09066` | 人间体温 | — |  | 木构/皮肤 |
| 点睛 · 花青 | `#5d7a80–#77938f` | 冷灰·谶 | — |  | 僧道影/雨 |

**色域边界条款（逐条写死，逐集负面钉死）**：
1. **限段条款**：`<色> 的爆发只发生在 <第N集第X–Y分钟>（全季唯一一次）`；火场/高潮段前后用"冷灰版/着色版"双版本锚图衔接。
2. **豁免条款**：`<色> 永久豁免褪色法则`——验收口径逐镜检查（除豁免位外，该色像素不得跨章/跨集保持同饱和度）。
3. **过渡色**：半褪态/中间态色值各 `__` 档，进 prompt 模板与负面词对照表。
4. **专属空间标记**：`<某视觉标记>＝<该集/段> 专属`——**不得串场**，须在各集【负面】钉死（本项目例：墨浪＝OP 专属）。

### 2.3 色彩纪律

- 强调色**只用规定的几支**；每镜平均出现次数上限 `__`；
- 语义（幻/劫/情/冷）**不得跨集换绑**；换绑＝全季回归验证（KSP-C）；
- 变化**只能用该风格的语言**表达（例：水墨＝**无光之戏**，禁「一亮/发亮/闪光/高光/辉光/反光/发光」，改"沉深一分/墨色渐浓/洇开一瞬/焦墨凝住/映墨/褪淡"；见硬规则 #34）。

## ⑥ 字体与字帖登记

> **字帖铁律（硬规则 #32）**：**凡画面要出现文字（谶语/回目/片名/落幅/镌字/黑底字卡等），必须先做一张"文字参考图（字帖）"作为参考图挂载；没有字帖的镜不得开抽。**

### 6.1 字形分档（全季统一）

| 用途 | 字形 | 负面分档 |
|---|---|---|
| 片名 / 改题 | 例：**魏碑意** | 简体字、字形残缺…（古典体例一律繁体） |
| 一般字卡（谶卡/回目/定场诗） | 例：**碑刻楷**（禁印刷宋体） | 同上 |
| 玉面镌字 | 例：**馆阁体** | 同上 |
| 印文 | 例：**篆书** | **印帖**移除 `印章`，改钉 `闲章, 杂印, 印泥飞溅, 印面残破, 楷书印` |
| 功能提示（黑底字卡/注音副题） | **简体**（现代功能提示） | **移除** `简体字`，改钉 `繁体字` |

**字系分体例（建议固化为剧集通用口径，来源：本项目甲方裁定）**：**古典体例一律繁体，现代功能提示用简体**；同一帖内简繁混用＝口径事故，**须上报拍板，禁静默处理**。

### 6.2 字帖登记表（帖号跨集唯一；**同一文本跨集只出一帖**）

| 帖号 | 文本（逐字照录底本/剧本） | 用途（哪些集/哪几镜） | 字形 | 颜色 | 版式 | 出处（行号/段号） | 文件（`_shared/锚图/字帖/`） | 状态 |
|---|---|---|---|---|---|---|---|---|
| `#01` |  |  | 碑刻楷 | 焦墨 | 竖排右1/3 | L__ | `字帖-<文本>.png` | ✅ |
| `#02` |  |  |  |  |  |  |  | ⏳ |
| `#21` |  | 黑底字卡（**集尾吊钩**·功能简体组） | 简体 | 白 | 黑底白字 | L__ |  | ✅ |
| `#22` |  | 片名 | 魏碑意 | 焦墨 | 居中/叠角 | L__ |  | ✅ |
| `#__` |  |  |  |  |  |  |  | 备而不用 |

**字帖纪律**：
1. **统一出图规格**：`宣纸暖白底(#ece7d8)，竖排书法字帖，逐字清晰完整；字形＝<分档>；墨色＝焦墨/朱砂/白；无装饰无底纹无边框无印章无水印；字距匀整、笔画完整、繁体`＋负面 `简体字, 字形残缺, 错别字, 装饰纹样, 边框, 印章, 水印, 模糊`（按上表两条置换）；
2. **去重合并**：同一句多处出现（例：既作对联又作落幅）**并为一帖**，多集挂载同一文件；
3. **字帖只锁字形，不得当画面底/底纹**（防"空版贴纸"作废事故重演）；
4. **OP 文字白名单**（硬规则 #33）：OP 只允许①片头标题字②物件上的字；**浮空字卡一律移入正片**——被移出的镜**同步移出字卡镜清单**，失去挂载镜的帖标"备而不用·留档"；
5. **未到件不得开抽**：字卡镜的参考组＝**场景锚＋字帖（＋故事板）**，缺帖即卡开抽。

**示例（红楼梦 EP01）**：26 帖／最终 **19 镜**挂载（口径推导：24 镜 − OP 禁字卡 4 镜 − 非字卡镜 1 镜 ＝ 19）；`#08–#11`＝四章回目（**碑刻楷**）；`#22《讖》`与`#24 好了`＝**魏碑意**；`#16 玉面四字`＝**馆阁体**；`#25/#26 印文`＝**篆书**；`#21/#23`＝**简体功能组**；同文本跨集复用（含 `#01/#02` 标"备而不用"）。

## ⑦ 母题登记册（转场 / 音效 / 构图 / 色彩母题）

> **母题是"观众认出这是同一部剧"的最低成本手段**；**ID 全局唯一**，**宁少勿滥**，**禁止无功能复现**（复现须声明 `【复现·回环】`＋依据＋限次）。

| 母题 ID | 类型 | 内容 | 首次出现（集/镜） | 复用集 | 使用纪律 |
|---|---|---|---|---|---|
| `M-转场01` | 转场母题 |  | EP01/__ | 全季 | **全季唯一转场语法**，不另造 |
| `M-音效01` | 音效母题 |  | EP01/__ | 全季 | 换材质不换语法 |
| `M-构图01` | 构图母题 |  | EP01/__ | EP__ | 回环呼应（同构图预告↔应验） |
| `M-色彩01` | 色彩母题 |  | EP01/__ | 全季 | 语义绑定（见 §②） |

**示例（红楼梦 EP01）**：
- **转场** `M-转场01 枯笔扫`——**全片唯一转场语法**（水态变化只发生在其后的首镜内部）；
- **音效** `M-音效01 十记落`——**换材质不换语法**：石磬×2→步点鼓→掌心闷击→衣袂＋靴雪→全配器抽空→墨滴入水「嗒」→极轻一洇→墨点「咚」→印「嗒」；**"之后不再有落"本身成为收束语法**；
- **构图** `M-构图01 露泪直通镜`——**全季版权镜**（露珠坠落慢镜，落底水面换成绛珠化形女子眼睫，同一滴轨迹接续成第一滴泪）；`M-构图02 人形留白缺口`（丢女＝留白，防模型自动填补人形）；
- **色彩** `M-色彩01 泪＝唯一不褪之朱`——永久豁免褪色法则，**全季最后一个可见的朱点**。

## ⑧ OP / ED 固定资产

> **OP/ED 不是"每集现做"，是"一次做完、逐集复用"的固定资产**；**时长为先、内容为后**，全季逐秒相等（见 `series-config.json` 的 `op_seconds`/`ed_seconds`）。

### 8.1 OP

| 项 | 值 |
|---|---|
| **时长 / 镜数** | `__s / __ 镜`（**满时长，禁静场/叠化填充**） |
| **脊椎（一句话）** |  |
| **段序** | `A-01…A-0n`（逐段名/秒数/镜数） |
| **逐镜清单** | 见附页或 `EP00-OP逐镜表.md` |
| **主题歌** | 曲名/段落（前奏/主歌/副歌/桥段/末句）／是否唯一人声 |
| **文字白名单** | ①片头标题字（片名＋注音副题＋落印）②物件上的字（镌字/刻字/印章） |
| **全季固定件** | 片名/注音/印/母题镜——**中途不得改字形/版式** |
| **逐集允许变化** | 集号提示（如需） |
| **卡开抽前置件** | 逐项列（锚图/字帖/母题素材）——**未到件不得开抽** |

### 8.2 ED

| 项 | 值 |
|---|---|
| **时长 / 镜数** | `__s / __ 镜` |
| **设计定位** | **回收位**（褪色回放/母题复现/片名改题），不是"再来一段画面" |
| **复用率** | ED 素材中来自本集已产素材变体的比例：`≥60%`（目标，成本≈0） |
| **片尾曲** | ／与 ED 画面的对应关系 |
| **逐集允许变化** | 下集预告位（10–20s，**只用本集素材剪，禁剧透结果**） |

**示例（红楼梦 EP01）**：OP＝90s／24 镜／A-01~A-07（脊椎「**被携带·入红尘**」：石阵如城·阵末一格空缺→僧道踏雪携石·托石于掌·袖石而去→墨滴入水→群像两拍→落纸→题名）；**OP 内人声＝0 句**（旁白全部移出 OP，落正片开场 0:00/0:04/0:08 三句约 11s）；OP 唯一人声＝女声有词主题歌；ED＝ED 雪盖四执＋片名《讖》被墨笔划去改题《好了》。

### 8.3 OP/ED 纪律

1. **不许当填充物**（本项目 OP 曾为"65s 素材＋25s 静场/叠化填充"，被裁定重写为 90s 满时长）；
2. **逐集复用**＝逐集核对**逐秒相等**（机器门控 D-S1）；
3. OP/ED 的**母题**入 §⑦、**文字**入 §⑥、**锚图**入 §④⑤（同一套登记，不另建体系）。

## ⑨ 叙事层（旁白 / 说书人）规则

> **写死三件事：谁在说 · 什么时候说 · 说多少。** 叙事层**不得与剧中人混权**（谁在说这句台词）。

| 项 | 本册口径 |
|---|---|
| **叙事层身份** | 例：旁白（说书人）／无叙事层（纯对白）／二者混用（写明分工） |
| **音色/语速** | 音色、语速档（例：230–240 字/分）、混响标记（叙述层专属） |
| **出现位（全季固定）** | 例：OP 内＝`0 句`；正片开场 `0:00/0:04/0:08`；章节引子＝每章首镜 |
| **上限** | 每集旁白字数/占比上限（防"旁白盖画面"） |
| **文体纪律** | 唱词/念白/引文：**逐字不改、零衬字、不为押韵改字**；文体不得混称（偈≠谶）；剧中人文本不得被叙述层直接唱用 |
| **排版纪律** | 字卡/字幕：**字幕＝口播逐句同步**；任何进成片的文字必须是口播稿原文/用户确认文案/数据卡，**禁自创** |
| **集尾语气** | 集尾是否留旁白（推荐：**集尾留白，钩子交给画面/字卡**） |

**示例（红楼梦 EP01）**：叙事声音＝**旁白轻、对白重**，旁白只做章节引子；**OP 内人声＝0**；三句旁白（白话钩/主钩/定场白，约 11s）落正片开场 0:00/0:04/0:08；章4 好了歌**必须"唱"**（归声音设计师）。
