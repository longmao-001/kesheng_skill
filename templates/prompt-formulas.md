# Prompt 公式库（可复制 · 调用即用）

> 用法：写 AI 图片/视频 prompt 时，**直接复制对应公式模板套用**。这是"公式本身"的独立保存区；概念的解读与出处见 `knowledge/image-gen-formulas.md`，纳入知识图谱的概念由 `packs/prompt-kg` 承载。
> 调用习惯：产品/设备/科技类镜头 → 默认套「产品八段公式」；具体平台再套对应平台公式（Seedream 5.0 / GPT Image 2 / 即梦 4.5）。

---

## ① 产品八段公式（科生默认，最常用）
```
【参数】画幅(16:9/9:16)｜分辨率(2K/4K)｜风格(写实摄影/CGI)
【镜头】焦段｜景别(微距/特写/近景/中景/全景/大远景)｜机位(平视/俯视N°/仰视N°/斜俯N°带倾斜)｜光圈｜景深(焦点)
【灯光】主光(色温K/方向)｜轮廓光(rim 角度)｜补光(挡位)｜特殊光(等离子/自发光 hex)
【主体】产品名｜材质到位(如"银白拉丝铝，发丝纹≈0.1mm，哑光颗粒")｜部位位置(如"出光口置右1/3")
【场景/构图】背景(深空炭黑)｜构图(对称居中/三分法/对角线/满幅/留白比例/引导线)
【动效】运镜(缓推/环绕/聚焦转移)＋画面内部运动(光扫/光轨/粒子/呼吸)＋剪辑节奏(单镜≤2运镜+变速)
【文字】AI 直出的字(写死+位置)｜不直出则写"后期"
【强制约束】无人物｜无变形无穿模｜无霓虹/暖调/彩色渐变｜数据核对=原文｜一致性(产品形态跨镜不变)
```
**两条铁律**：① 产品展示＝干净（留白多/单一主体）／功能展示＝复杂（加机制/结果/环境细节）；② 绝不改造设备真实造型（参考图锁定真实几何/部件/logo/材质，只动布光机位构图加字）。

## ② Seedream 5.0 / 5.0 Pro / 5.0 Lite 公式（摄影级，产品片首选）
```
【场景】___________________(精密测控实验室/深空炭黑底)
【镜头】_____mm，f/____，景别____，机位____，浅景深焦点____；快门 1/____，ISO ____
【主体/细节】____(产品名)，材质____(到色号级，如"银白拉丝铝≈0.1mm/石英出光窗微反光")；部位____(位置)
【文字】____(直出型号/标签/数据卡，写死+位置)
【约束】无变形无穿模｜一致性(____跨镜不变)｜数据核对=原文
```
- 参考图编辑（5.0 Pro）：`以 @参考图 为基准，保持[主体/材质]不变，只改[布光/构图/加字]`——主体还原度最高。

## ③ GPT Image 2（Image2）公式（指令遵循/中文小字/参考编辑最强）
```
场景 → 主体 → 细节 → 约束（定序，别写成长句）
```
- 示例：`以 @参考图 为基准，保持[产品形态/材质/logo]不变，只改[布光/构图/加字]；画面____；约束：无人物/无霓虹/无变形。`
- 单格重画：`只重画第 N 格，改成…，其余格子保持不变。`
- 中文小字 ≥2K 清晰，可直出铭牌/标题/数据标签；比例 16:9/2K。

## ④ 即梦 Seedream 4.5 公式（多图一致性/宫格最强）
```
多图一致性：上传@角色+@产品+@场景多张参考，一条 prompt 出 3×3 宫格，或切片当首帧。
```
- 配合 `playbooks/storyboard-grid.md`：一次出全片分镜图，整图喂多镜原生或切格图生视频。

## ⑤ 参考图用法（标"角色" + 部分↔部位对应 + 放哪位置）

**① 一镜一主体 · 参考按"角色"分类（别把所有图都当主体）**：
| 角色 | 写法 | 例 |
|---|---|---|
| **主体参考（只能 1 个，且匹配景别）** | 该镜最核心的东西，写在【主体】段，其它参考不是主体 | `@图1 是主体（系统整机，全景）` |
| **主体细节参考** | 同一主体的更近/局部细节（补充主体的细节质感） | `@图2 是主体细节参考：出光窗内等离子球` |
| **镜头/构图参考** | 学机位/运镜/构图，不是画面内容 | `@图3 是镜头参考：平视微距 90mm 环绕` |
| **场景/氛围参考** | 用于背景环境，不参与主体（若含主体→注明其位置） | `@图4 是场景参考（深空底+金属台）；图中【右1/3】机台是主体，取该机台` |
| **质感/光效参考** | 学某种材质/光 | `@图5 是质感参考（银白拉丝高光随角度流动）` |

**核心原则**：**近景/特写 → 主体=那个细节**（如出光口/光点/材质），远处"整机"参考**不作主体**（要么作镜头/构图参考，要么不用）；**全景 → 主体=整机**。别把三张参考都标"主体"（显得乱、且近景里远主体没用）。
**若场景参考"包含主体"**：注明主体在图中位置——`@图2 是场景参考，但图中【右上角】的量测机台是主体，取该机台；其余为背景`。

**② 若参考图"包含主体"——注明主体在图中的位置**（场景/环境图里也有主体时必写）：
```
@图N 是场景参考，但图中<位置>的<主体>是主体，取该主体；其余为背景。
例：@图2 是场景参考，但图中【左上角】的量测机台是主体，取该机台；右侧为实验室背景。
例（若含人物）：@图2 是场景参考，但图中【右上角】的人物是主体，取该人物。
```

**③ 再写部分↔部位对应 + 位置**：
```
@图1 是主体：参考图【出光窗】＝主体【出光口】；参考图【控制面板】＝主体【左控制器前脸】。
@图2 是场景参考（含主体）：图中【左1/3 机台】是主体＝主体【该机台/帧面】，其余为背景。
@图3 是部件参考：取参考图【散热鳍片】＝主体【机身鳍片】。
```
- 产品镜头必须参考图锚定（避免 AI 凭空改形）；图片节点上限 3 张/次（选最需要的 3 张）；逐镜视频节点可更丰富。
- 禁入镜/禁作参考喂模型：水印图、竞品图、团队合影（人物）、带商标的原理示意图（只作内容参考）。

## ⑥ 校验清单（交 prompt 前）
```
[ ] 选对公式（Seedream 5.0 / GPT Image 2 / 即梦 4.5）
[ ] 八段齐全（参数/镜头/灯光/主体/场景构图/动效/文字/强制约束）
[ ] 产品=干净 / 功能=复杂
[ ] 真实造型锁死（@参考图不变）
[ ] 参考图"取哪部分→放哪位置"；水印/竞品/团队照/商标原理图已排除
[ ] 文字：AI 直出写好+位置；精确数据（±0.2%/10000h/170-2500nm 等）生成后核对=手册原文
[ ] 无抽象词（无"高级感/震撼/电影感"）｜单镜≤2 运镜+变速（动感三来源）
[ ] 科学红线（发光点=0.1mm 椭圆非大光球/出光=白光非激光束/数据核对/无人物）
```
