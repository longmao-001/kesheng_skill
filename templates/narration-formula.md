## 句与句的节奏配方（一段口播的骨架）

```
钩子句(F01) 1句 → 痛点/场景(F02/F12) 1-2句 → 定义(F03) 1句
→ 结构段: 层级(F04)/因果(F10)/属性(F05) 3-5句(一镜一句)
→ 价值段: 价值(F06)/对比(F07) 2-3句
→ 证据段: 参数(F08)/证据(F09) 1-2句(带条件)
→ 信任段: 安全(F11) 1句 → 承诺(F13)+CTA(F14) 1句
```

## 句内纪律

- 单句 ≤20 字；一句只一个信息点；数字与转折前留停顿
- 每句能回答"这句告诉观众什么"——答不上来的句子删
- 冷峻基调=短句+中性词；温润基调=长短交替+温度词
- 术语数不清的段落在写之前先做"术语换人话"清单（F03 前置）
- 全段信息点 ≤3 个/分钟，留白=呼吸

## 自检清单（交用户看稿前）

- [ ] 每句能归属一个公式（F01-14），无"感觉句"

- [ ] 结构段按 F04 层级/因果，一镜一句
- [ ] 数字都有量级词+口语参照（F08），证据带条件（F09）
- [ ] 无炫技词，最大形容词不超"独特"
- [ ] 结尾 F13+F14 齐
- [ ] 语速按档位（宣传片 240-260 字/分）
