# 写 Prompt 固定 SOP（Prompt Writing SOP）

> **用途**：把「**怎么一步步写出一个合格 prompt**」锁死成固定步骤（`agents/prompt-engineer.md` 的十步 + 本详表）。**格式**在 `templates/prompt-sheet.md`（R1-R12）；**类型公式**在 product/video-prompt-formula；**合规/科学/参考图**在本 SOP。
> **铁则**：十步不可跳；每镜 prompt 必须**带参考图挂载清单**、**口播独立字段**、**动作动机标注**、**字卡写出法＋字形要求**、**无禁用词**；交付前过 `check_prompt_sheet.py`（格式与一致性）**＋ `check_prompt_sop.py`（十步执行证据）**＋ **`check_prompt_delivery.py`（交付口径 D1-D10）**。
>
> **⚠️ 交付格式铁则（红楼梦EP01·用户裁定 20260915，最高优先）**：**交付格式＝单一 SOP 合并块**——正文即 `【参考】【风格】【时间轴】【口播】【声音】【负面】`（＋参数）**合并为一个代码块**，**整块复制即用＝终稿**；**负面词内嵌同块末尾**（禁另起块）；**⛔ 禁止再另写"平台prompt"第二版本**（两套写法＝用户困惑源）。详见 §「交付格式：单一 SOP 合并块」。
>
> **机器门控（写 prompt 必须过）**：
> - `python -X utf8 scripts/check_prompt_sheet.py <runs/<项目>>` —— 格式与一致性（核心字段完整/口播单独且与口播稿一致/风格token一致/参考@/负面非空）
> - `python -X utf8 scripts/check_prompt_sop.py <runs/<项目>>` —— **十步执行证据**（逐镜核对十步各自留下的产物证据；缺证据=该步没走）：
>   步2 路线∈词表 / 步3 参考非裸引用（须带角色或"取哪→放哪"）/ 步5 风格逐字一致 / 步6 时间轴按秒分段 / 步7 口播与口播稿同源 / 步8 负面非空 / 步10 有 README —— 这些是 **FAIL**；
>   挂载缺"部位对应/位置"、产品镜缺"保真实造型"、参数缺项（真镜头/人工免抽卡与失败改法）为 **WARN**（交红队/检察官人工核）
> - **`python -X utf8 scripts/check_prompt_delivery.py <runs/<项目>>`** —— **交付口径门控**（红楼梦EP01·用户裁定 20260915）：D1 SOP字段完整／D2 @标记贯穿／D3 负面同块／D4 禁词／D5 故事板纪律／D6 字卡口径／D7 校勘红线／D8 后期表述归一／D9 字卡镜负面分档／**D10 动画性（a 曲线 b 主体表演 c 负面 d 字卡书写性 e 动作动机）**／D11 交付格式（"第二版本"硬拦，默认关）；**动画类项目日常用 `--animation-baseline`，收口用默认全套**。项目专属词表（专属空间标记/字卡镜号/校勘红线/动画阈值）走 `runs/<项目slug>/prompt-delivery-config.json`——见 `scripts/README-check_prompt_delivery.md`。
> 三项都在 `scripts/check_all.py` 体系内，出口前必跑。

## 交付格式：单一 SOP 合并块（写死，红楼梦EP01·用户裁定 20260915）

> **判定**：一镜出现**两个可复制 prompt 块** ＝ 交付格式判废（用户不知道复制哪条；两条不一致时无从裁决）。

**✅ 正确（唯一形态：一个代码块到底）**：

```markdown
### 镜头 <段号>-<镜序> · <N>s · <路线>
【参考】@图片1=<实际文件名>（取<哪部分>→放<哪位置>）＋@图片2=<实际文件名>（取<哪部分>→放<哪位置>）
（上传顺序：@图片1=<实际文件名>；@图片2=<实际文件名>）
【风格】<风格 token 块，全片逐字复用>
【时间轴】0-2秒 <预备/主体蓄势>…；2-4秒 <发力/主体动作>…；4-5秒 <回收>，动作动机＝<对应台词/谶语/情绪>；末段做余动处理：主体动作渐慢回稳，余摆未歇即转入下一镜。
【口播】<旁白原文，无则"无">（读法批注：停连/重音/语速档）
【声音】<BGM/音效，全部模型原生生成；无则"无">
【负面】<通用负面词块> ＋ <该镜专属附加词>
【参数】<N>s档 · 抽卡<N>次 · 失败改法：<改参考组／改措辞／重抽>
```

**❌ 错误（禁止）**：上述合并块之外，**另起** `【视频prompt】`／`【平台prompt】`／`【对照】`／「可灵版：…」等**第二条成句 prompt**；或把负面另放一个代码块。

- **平台差异不靠第二条 prompt 表达**：一平台一个文件（`prompts-<平台>.md`）；平台语法差异在**同一块内调整词序**（海螺运镜方括号置顶、即梦运镜放句首、可灵 I2V 只写运动）；需说明时写在代码块**外**的散文行（散文行不是 prompt 本体，用户不复制）。
- **负面内嵌同块末尾**：`【负面】：…` 必须在同一个代码块内（D3）。

## 十步（每镜必走）

| 步 | 做什么 | 产出 | 硬检查 |
|---|---|---|---|
| 1 取输入 | 分镜六要素+口播+风格基线+摄影方案+素材库 | 该镜需求清单 | 六要素齐 |
| 2 定路线 | 参考包→多镜原生→I2V→首尾帧→文生 | 生成路线 | 与摄影方案一致 |
| 3 选参考图 | 自建库按 对位+高分 挑≤3张，标角色+部位+位置 | 【参考】挂载清单 | **不带清单=不合格** |
| 4 定主体 | 产品=干净/功能=复杂；保真实造型=@参考图不变 | 【主体】 | 无造型改动 |
| 5 写风格 | 全片逐字复用风格 token 块 | 【风格】 | 全片一致 |
| 6 写时间轴 | 按秒断句，口播独立，≤30s，长镜头分段；**先写主体在做什么（三层动）→再写次级运动→最后写运镜**；**必须写 `动作动机＝…`**；段尾写余动 | 【时间轴】 | R4/R11＋**动画性（a/b/e）** |
| 7 写口播 | =口播稿逐句（独立字段，由模型原生生成，不做后期配音） | 【口播】 | R11 |
| 8 写负面 | 具体排除项+科学/品牌红线+广告禁用词；**字卡镜/非字卡镜分档**；动画类加 7 项动画性禁项 | 【负面】 | ad_forbidden_words＋**D9/D10-c** |
| 9 写参数 | 时长档+抽卡建议+失败改法 | 【参数】 | R5 |
| 10 自检交付 | **`check_prompt_sheet.py`＋`check_prompt_sop.py`＋`check_prompt_delivery.py`** ＋挂载清单＋禁用词＋图文对位 → 落盘 | `prompts-<平台>.md`+README | **门控全过才交付** |

> **失败改法只有三种（红楼梦EP01·用户裁定 20260915）**：**改参考组／改措辞／重抽**——**禁止写"后期配音/后期叠/后期合成/若生成不出就后期处理"**（无后期原则；声音/音色类工序统一写「**声音工序处理**」）。

## 每镜填写的字段顺序（prompt-sheet.md 固定）

`标题 → 【参考】（挂载清单＋上传顺序） → 【风格】（token块） → 【时间轴】（含动作动机） → 【口播】 → 【声音】 → 【负面】（内嵌同块） → 【参数】`

## 必含件（缺=打回）

1. **参考图挂载清单＋实名上传顺序**：`@图片N=实际文件名（取哪→放哪）`＋另起一行 `（上传顺序：@图片1=…；@图片2=…）`；提到 `图片N` 却无 `@图片N` ＝脱节写法（D2 FAIL）；裸引用＝不合格（§5-21）。
2. **口播独立字段**：=口播稿逐句，由模型原生生成（不做后期配音）；不进画面 prompt 正文。
3. **动作动机（动画类必含，第6条）**：`动作动机＝…` 标注，且动机句指到具体台词／谶语／情绪；**无动机的动作一律删**。三层动（主体表演／次级运动／动作曲线）同时齐备。
4. **字卡字形要求（第4条）**：凡字卡（回目／谶文／定场诗／片名／印文／镌字）**由模型原生生成**，prompt 内**逐字写出文字**并写明**字形要求**（碑刻楷／繁体／笔画完整／位置／字号）＋时间轴写"**逐字书写而出**"（禁 弹出／叠加／上屏）；**字卡镜**负面钉 `简体字, 字形残缺, 字形错误`；**非字卡镜**保留 `文字, 印章, 题字`。
5. **无禁用词 + 数据不AI生成**：`scripts/ad_forbidden_words.py` 无绝对化/疗效词；精确参数/曲线/logo 走数据卡字卡图参考锁值，画面 prompt 不出现。
6. **字卡镜须带文字参考图（字帖）**〔新增·红楼梦EP01·用户裁定 20260915〕：**凡画面要出现文字（谶语／回目／片名／落幅／玉面镌字／黑底字卡等），必须先做一张"文字参考图（字帖）"作为参考图挂载，让模型照抄字形；没有字帖的镜不得开抽。**
   - **参考组**：字卡镜的参考组 ＝ **场景锚 ＋ 字帖（＋故事板）**；【参考】字段须含 `@图片N=字帖-XXX.png（取字形→照抄该镜字卡文字）`；
   - **正文**：字卡落位句须写 `逐字照录「<文本>」共<N>字，字形照@图片N的〈字帖-XXX〉帖，一字不可增删改`；
   - **并存**：第 4 条的"**逐字书写而出**"照旧必写——**字帖锁字形、时间轴锁笔迹生长**；
   - **铁律**：**字帖只锁字形，不得当画面底／底纹**（避免"字卡空版当贴图"的作废事故）；
   - **判废**：字形出简体／缺笔／连笔糊、出现装饰边框印章、字帖被当底纹用；
   - **清单模板**：逐条 `文本｜用途｜字形要求（碑刻楷/馆阁体/魏碑意/篆书）｜颜色（焦墨/朱砂/白）｜版式（竖排右1/3/叠角/玉面浮凸/黑底白字）｜出处（剧本行号或段号）`＋单块 Image2 prompt（负面内嵌）＋命名 `refs\锚图\字帖\字帖-<文本>.png`。

## 平台差异（写前必查）

- 每个平台公式/运镜语法/参考/首尾帧/单次时长上限不同 → `playbooks/platform-prompts.md`；**别把 A 平台句式丢进 B 平台**。
- **但平台差异不产生第二条 prompt 文本**：一平台一文件，块内调词序；**禁"平台prompt"第二版本**（§交付格式）。
- 动画类项目另须读 `playbooks/animation-motion-design.md`（动画性纪律）；故事板见 `playbooks/storyboard-grid.md`（故事板五铁律）。
