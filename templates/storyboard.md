# 分镜表模板（Storyboard）

> M4 里程碑产出。分镜师填前七列（运镜列与摄影指导合议），prompt 工程师填后四列。每一行都必须能直接拿去工作台执行。
> **对位铁则（重要检查项）**：旁白文稿 ↔ 画面描述 ↔ 参考图/首帧 **三者必须对位**——口播讲的对象/动作/状态，必须在画面描述与该镜参考图中体现或可靠衍生（口播讲"光带扫过控制器→灯室"，参考图就必须有控制器+灯室+光带）；图文脱节=打回，再好看的画面对不上旁白就没用。

## 填写规则

- **景别**：远 / 全 / 中 / 近 / 特
- **运镜**：从 `playbooks/platform-prompts.md` 的运镜词表选，单镜 ≤2 个
- **时长**：3-10 秒；对应口播约 40 字/5 秒
- **旁白文稿**：引用 `screenwriter-口播稿` 定稿原文（逐句带时间）；**字幕=口播逐句同步**——口播念什么字幕显什么（≤10 字/屏可断行）；无口播段不设字幕（信息卡/数据卡属"数字字卡"层）；**禁止自创/缩写字幕文案**（见 knowledge/ad-copy.md §二·五，违反=打回）
- **生成路线**：T2V（文生视频）/ I2V（图生视频）/ 首尾帧 / 参考生视频
- **平台 prompt**：按目标平台公式写（见 platform-prompts.md），必须含全片统一的风格 token 块
- **参考图/首帧**：注明用哪张三视图/锚图/上一镜尾帧
- **备注**：抽卡次数建议、失败改法、与其他镜头的衔接关系
