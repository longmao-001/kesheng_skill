# 入库规则（kb 知识萃取与收录标准）

> 本文件是 `kb/` 的**唯一权威入库规则**，其他地方只引用、不复制本规则。
> 隐私分类与脱敏的详细执行见 [[隐私红线]]（本规则引用它，不替代它）。

## 一、收什么（四条门槛同时满足，缺一条不收）

1. **通用**：换一个客户、换一个项目照样成立。只收科学概念/机制/方法学/表达技巧，不收任何项目内容
2. **公开**：教科书或已公开发表级别；每条数据必须能写出公开出处。写不出出处 → 标"待确认"或丢弃
3. **有用**：必须能服务视频制作——笔记的"类比库"和"视频可视化点子"两节必填，缺了不准入库（这是科生的知识库，不是普通维基）
4. **干净**：通过 [[隐私红线]] 的三分法分拣和脱敏检查清单

## 二、什么时候入

- **项目收尾（主渠道）**：每个项目交付后，科学顾问主导萃取，15-30 分钟
- **项目进行中**：M2 科学理解阶段发现库里有缺口，可先立 🌱 幼苗笔记，收尾时补全
- **日常手动**：用户直接说"把 X 存进 kb"时，按同一套标准执行——手动指令不降低门槛

## 三、怎么入（五步流程）

1. **分拣**：按 [[隐私红线]] 三分法——🟢 公开通用直接整理；🟡 带项目痕迹脱敏泛化；🔴 项目专有一字不留
2. **成文**：复制 `kb/_模板/概念笔记.md`，放入对应领域文件夹，文件名 = 概念名（中文，如 `基因编辑.md`）
3. **脱敏**：逐条过脱敏检查清单；frontmatter 标 `隐私: 公开通用` + 公开来源 + `tags: [kb/领域名]`
4. **织网**：用 ``[[wiki-link]]`` 连接相关笔记（跨领域链接尤其珍贵，如 `[[荧光显微镜]]` 同属光学与生物学）；并在被链接的已有笔记里补上反向链接
5. **登记**：更新领域 `_索引-*.md` 笔记表与状态 → 更新 `kb/index.md` 领域计数 → `git add -A && git commit && git push` 同步仓库

## 四、笔记质量标准

- **一句话定位**：20 字以内，完全外行能懂——过不了这关说明自己没真懂，回去重学
- **机制**：输入→过程→输出，能回答"拿掉这个环节会怎样"
- **类比**：≥2 个，标注适用受众；有误导性的类比必须注明误导点
- **数据**：全部带公开出处；无出处标"待确认"，绝不留裸数字
- **可视化点子**：写实、可执行——景别/运镜说清楚，prompt 工程师能直接拿去写 prompt
- **知识边界**：诚实写"我不确定什么"，防止以后自己或别人编造

## 五、状态与维护

- 状态标记：🌱 幼苗（有框架未补全）→ 🌿 成型（可用）→ 🌳 成熟（多个项目验证过好用）
- 回顾时机：每次复用笔记时顺手校验；发现错误立即修正并更新"最后更新"日期
- 新领域：新建文件夹 + 复制 `kb/_模板/领域索引.md` + 在 `kb/index.md` 领域表登记
- 删除：发现已入库内容含项目痕迹或无法溯源 → **立即删除**，不犹豫

## 六、底线

拿不准一律不入库；发现已入库内容有问题立即删。
知识库缺一条笔记可以补，机密泄一次收不回。
