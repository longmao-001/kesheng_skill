# 植物代谢 科学速查卡

> **最后更新**：2026-05-14
> **适用场景**：黄酮类 / 萜类 / 生物碱 / 次生代谢 / 代谢通路 / 酶 / 化合物 / 作物改良
> **关联笔记**：[[基因编辑]]（基因编辑作物案例在此联动）、[[合成生物学]]（青蒿素细胞工厂案例）、[[_索引-生物学]]

## 一句话定义
**植物代谢 = 植物体内的化学反应网络。** 就像人体有消化系统、循环系统一样，植物也有一套复杂的"化工厂"在体内日夜不停地生产各种化合物——有的用来生长，有的用来防御敌人，有的吸引传粉者。

## 核心区分：初生代谢 vs 次生代谢

| | 初生代谢（Primary） | 次生代谢（Secondary） |
|---|---|---|
| **作用** | 维持生命基本活动 | 适应环境/防御/交流 |
| **产物** | 糖、氨基酸、脂肪酸、核苷酸 | 黄酮、萜类、生物碱等 |
| **所有植物都有？** | ✅ 基本一样 | ❌ 因物种而异（特色所在！） |
| **类比** | 基础设施（水电网）| 装修风格（每家不同）|
| **科生常碰到的** | 较少 | **几乎每次都是这个** |

> **记忆口诀**：次生代谢 = 植物的"特色菜"。每家餐厅（物种）的招牌菜不一样，这就是为什么不同植物有不同药效/香味/颜色。

## 核心概念图谱

### 概念1：黄酮类化合物（Flavonoids）
- **学术定义**：以2-苯基色酮为骨架的一类多酚化合物
- **大白话**：植物界最常见的一类"保健成分"——你喝茶、吃水果、喝红酒时摄入的就是它。抗氧化、抗炎、抗癌...好处一大堆
- **类比**：
  - 🛡️ **植物的防晒霜+防弹衣**：黄酮帮植物挡紫外线、抗虫抗菌——人吃了这些"防护装备"也受益
  - 🎨 **植物的化妆品**：黄酮让花有颜色（花青素是黄酮的一种）、让果实有味道
- **关键分类**：
  | 类别 | 代表物 | 特点 | 食物来源 |
  |------|--------|------|---------|
  | 黄酮醇 | 槲皮素、山奈酚 | 最常见的黄酮 | 洋葱、苹果、茶 |
  | 黄酮 | 木犀草素、芹菜素 | 抗炎活性强 | 芹菜、辣椒 |
  | 黄烷-3-醇（儿茶素） | EGCG | 茶多酚主力 | 绿茶 |
  | 花青素 | 矢车菊素 | 红/蓝/紫色来源 | 蓝莓、葡萄 |
  | 异黄酮 | 大豆异黄酮 | 植物雌激素 | 大豆 |
- **关键数据**：已鉴定的黄酮类化合物超过9000种（公开综述数据），是植物中分布最广的多酚家族之一；黄酮C2=C3双键是其抗氧化活性的结构基础
- **常见误区**：
  - ❌ "黄酮都是好的" → 有些黄酮在高剂量下有毒性；生物利用度普遍较低
  - ❌ "越多越好" → 黄酮在植物体内有平衡，过度积累可能影响生长
- **相关概念**：苯丙烷代谢通路、CHS酶、代谢工程

### 概念2：萜类化合物（Terpenoids）
- **学术定义**：由异戊二烯（C5）单元聚合而成的天然产物，是最大类的天然有机化合物
- **大白话**：自然界种类最多的化合物家族——从薄荷的清凉味（单萜）到橡胶（多萜）到胡萝卜素（四萜），全是萜类家族的成员
- **类比**：
  - 🧱 **乐高积木**：异戊二烯(C5)就是一块基础积木：
    - 2块拼一起(C10)=单萜（薄荷醇、柠檬烯→柠檬香味）
    - 4块拼一起(C20)=二萜（紫杉醇→抗癌药）
    - 6块拼一起(C30)=三萜（人参皂苷）
    - 8块拼一起(C40)=四萜（β-胡萝卜素→橙色）
  - 👨‍👩‍👧‍👦 **家族树**：同一个祖先（异戊二烯），但分支越来越多，每个分支的后代长得完全不同
- **关键分类与代表物**：
  | 碳数 | 类别 | 代表物 | 用途 |
  |------|------|--------|------|
  | C10 | 单萜 | 薄荷醇、柠檬烯 | 香料、日化 |
  | C15 | 倍半萜 | 青蒿素（抗疟疾！）| 药物 |
  | C20 | 二萜 | 紫杉醇（抗癌）| 药物 |
  | C30 | 三萜 | 人参皂苷 | 保健品 |
  | C40/C50 | 多萜 | 类胡萝卜素、橡胶 | 天然色素、材料 |
- **关键数据**：萜类占所有天然产物的~60%；青蒿素（倍半萜）拯救了数百万人的生命 → 屠呦呦诺贝尔奖2015
- **常见误区**：
  - ❌ "萜类=精油" → 精油只是萜类的一小部分（主要是单萜和倍半萜）
  - ❌ "萜类只存在于芳香植物中" → 几乎所有植物都合成萜类，包括很多没有香味的
- **相关概念**：MVA/MEP通路、TPS酶（萜类合酶）

### 概念3：代谢通路（Metabolic Pathway）
- **学术定义**：一系列连续的酶促反应，将起始底物转化为最终产物
- **大白话**：一条"流水线"——原料A经过酶1变成B，再经酶2变成C...最终变成产品Z。每一步都有一个专门的工人（酶）负责
- **类比**：
  - 🏭 **工厂流水线**：原料进厂 → 工序1 → 工序2 → ... → 成品出厂。每道工序=一个酶催化的反应
  - 🚃 **地铁线路**：起点站（底物）→ 中间各站（中间产物）→ 终点站（终产物）。可以换乘（通路交叉）
- **关键特征**：
  - [ ] **级联反应**：前一步的产物是后一步的底物（像接力赛）
  - [ ] **调控点**：某些步骤可以被激活或抑制（像水龙头开关）
  - [ ] **通路交叉**：不同通路共享中间产物（像地铁换乘站）
- **黄酮核心通路**（简化）：苯丙氨酸 → 肉桂酸 → 对香豆酸 → **查尔酮(CHS)** → **黄酮(C4H)** → 各类黄酮
- **萜类核心通路**（两条路线）：
  - MVA通路（细胞质）：乙酰-CoA → ... → IPP/DMAPP → 萜类
  - MEP通路（质体）：丙酮酸 → ... → IPP/DMAPP → 萜类
- **常见误区**：
  - ❌ "通路是一条直线" → 实际上是网络，有很多分支和环路
  - ❌ "改一个基因就能控制整条通路" → 通常需要协调多个步骤（限速步骤是关键）

### 概念4：酶（Enzyme）— 代谢通路的工人
- **学术定义**：催化生化反应的蛋白质，降低反应活化能
- **大白话**：代谢通路上的每个"工人"——每种酶只负责一种特定的化学反应，而且效率极高
- **类比**：
  - 🔧 **专用工具**：每种酶是一把专用扳手，只能拧特定大小的螺丝（底物特异性）
  - 👷 **工厂工人**：每个工人只做一道工序，但做得极快极准（催化效率可达非酶反应的10^17倍）
- **科生常遇到的酶**：
  | 酶 | 全称 | 作用 | 所在通路 |
  |----|------|------|---------|
  | CHS | 查尔酮合酶 | 黄酮合成的第一步（关键入口！）| 苯丙烷/黄酮通路 |
  | CHI | 查尔酮异构酶 | 查尔酮→黄烷酮 | 黄酮通路 |
  | FNS | 黄酮合成酶 | 黄烷酮→黄酮 | 黄酮通路 |
  | TPS | 萜类合酶 | IPP/DMAPP→各类萜类骨架 | 萜类通路 |
  | CPR | 细胞色素P450还原酶 | 给氧化反应提供电子（辅因子）| 多个通路 |
- **常见误区**：
  - ❌ "酶越多越好" → 酶之间需要平衡，一种过量可能抢走底物导致其他产物减少
  - ❌ "改了酶的编码基因就一定有效表达" → 转录后修饰、蛋白折叠、亚细胞定位都可能出问题

### 概念5：转录因子（Transcription Factor, TF）
- **学术定义**：结合DNA特定序列以调控基因表达的蛋白质
- **大白话**：代谢通路的"总开关"——不是直接参与生产的工人，而是控制哪些工人上工、上多少班的管理者
- **类比**：
  - 🎛️ **调音台的推子**：TF不发出声音，但它控制每个音轨（基因）的音量（表达量）
  - 📋 **项目经理**：不亲自写代码，但决定哪个程序员做什么模块、给多少资源
- **关键意义**：**改造TF往往比逐个改造酶更高效**——因为一个TF可以同时调控整条通路上的多个基因
- **常见误区**：
  - ❌ "TF就是基因" → TF是调控基因的蛋白，它本身也是基因编码的
  - ❌ "改TF一定比改酶好" → TF调控复杂（可能有多个靶基因、组织特异性等），效果更难预测

## 经典研究案例（科生必知）

### 案例1：黄金大米——把"金色通路"搬进水稻
- **背景**：精米胚乳几乎不含β-胡萝卜素（维生素A前体），维生素A缺乏影响全球数亿人
- **做法**：把类胡萝卜素合成通路的关键酶（PSY、CRTI）导入水稻胚乳，让米粒自己合成β-胡萝卜素
- **意义**：代谢工程改造作物营养的教科书级公开案例；黄金大米2号的β-胡萝卜素含量较初代提升20倍以上
- **视频钩子**："科学家把水仙花的'颜色密码'写进了大米的基因——白米从此变成了'金米'"

### 案例2：青蒿素的微生物合成
- **团队**：Jay Keasling (UC Berkeley) + Amyris
- **过程**：将青蒿素合成通路（来自黄花蒿）转入酵母 → 发酵生产
- **意义**：证明复杂植物次生代谢产物可以用细胞工厂生产
- **视频钩子**："他们把一棵草的DNA搬到了酵母里，让一个小小的真菌变成了制造抗疟良药的工厂"

### 案例3：紫杉醇（Taxol）合成挑战
- **问题**：紫杉醇是从红豆杉树皮提取的抗癌药，1kg需要砍3000棵树
- **尝试**：多年尝试用代谢工程在微生物中合成
- **现状**：部分成功（半合成路线已工业化），全合成仍在攻关
- **视频钩子**：为了救癌症患者，我们曾经要砍掉一片森林。现在科学家正在教酵母学会怎么造这种药

## 这个领域的"黄金问题"
1. **如何精确调控代谢流而不影响植物正常生长？** （代谢负担问题）
2. **能不能从头设计全新的代谢通路来生产自然界不存在的化合物？**
3. **不同物种间的代谢通路移植有多通用？** （A植物的酶放到B植物里能工作吗？）

## 我可能不懂的地方
- 具体物种的代谢通路细节差异极大（拟南芥≠水稻≠小麦≠烟草）
- 酶的动力学参数（Km、Vmax）对实际产量影响的定量预测
- 亚细胞定位对代谢工程的具体影响（质体vs内质网vs线粒体的区隔效应）
- 最新发现的酶功能（每年都有新酶被鉴定）
