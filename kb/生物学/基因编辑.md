# 基因编辑 科学速查卡

> **最后更新**：2026-05-14
> **适用场景**：CRISPR / 基因敲除 / 基因敲入 / Base editing / Prime editing / 作物改良
> **关联笔记**：[[合成生物学]]、[[植物代谢]]（基因编辑作物案例在此联动）、[[_索引-生物学]]

## 一句话定义
**基因编辑 = 用分子剪刀对DNA进行精准的剪切、修改或替换。** 就像文字处理软件的"查找-替换"功能，只不过操作对象是生命的源代码。

## 核心概念图谱

### 概念1：CRISPR-Cas9
- **学术定义**：利用细菌适应性免疫系统的Cas9核酸酶和向导RNA（gRNA）实现靶向DNA切割的技术
- **大白话**：一种能精确定位到基因组上某个位置并"剪一刀"的工具。gRNA是GPS导航，Cas9是剪刀
- **类比**：
  - ✂️ **剪刀+GPS**：gRNA告诉剪刀去哪剪（导航），Cas9执行剪切。想改哪段就设计对应的gRNA
  - 🔍 **查找替换**：Word里的"Ctrl+F找到位置→删除/替换"，CRISPR就是基因组的这个功能
  - 📝 **橡皮擦+铅笔**：先擦掉错的（Cas9切割），再写上对的（细胞修复时插入新序列）
- **关键数据**：2012年发明；2020年诺贝尔化学奖；成本从$5000降到<$100；全球数千个实验室在使用
- **常见误区**：
  - ❌ "CRISPR只能做敲除" → 配合供体模板可以做精确插入（敲入）
  - ❌ "CRISPR完美无缺" → 有脱靶效应（切错位置）、PAM序列限制、大片段插入效率低等问题
  - ❌ "所有生物都能用CRISPR" → 效率因物种而异，植物比动物难很多
- **相关概念**：Base editing、Prime editing、脱靶效应

### 概念2：碱基编辑（Base Editing）
- **学术定义**：将一个碱基直接转换为另一个碱基（如C→T、A→G），不产生双链断裂（DSB）
- **大白话**：CRISPR是把DNA剪断再修（暴力但有效）；碱基编辑像是用橡皮擦掉一个字母然后写上新字母——更精细、更安全
- **类比**：
  - ✏️ **单字修改**：CRISPR=删掉整个词再重打；Base editing=只改一个拼写错误
  - 🔄 **换轮胎**：CRISPR=把整辆车拆了重装；Base editing=只换一个瘪掉的轮胎
- **关键数据**：David Liu实验室2016年发明；C→T转换效率可达60%（vs CRISPR HDR通常<10%）；不产生双链断裂→更少意外突变
- **常见误区**：
  - ❌ "可以任意改任何碱基" → 目前主要支持C→T/G→A和A→T/G→C四类转换，不能插入/删除
  - ❌ "完全无脱靶" → 脱靶模式不同（RNA编辑窗口内的off-target）但仍存在
- **相关概念**：CRISPR-Cas9、Prime editing

### 概念3：引物编辑（Prime Editing）
- **学术定义**：使用逆转录酶和pegRNA引导的"搜索-替换"式基因编辑，可实现所有12种可能的碱基转换、小片段插入/删除
- **大白话**：基因编辑的"瑞士军刀"——理论上能做所有类型的精确修改：换字母、删几个、插几个、全换
- **类比**：
  - 🔧 **瑞士军刀**：CRISPR是大砍刀（适合大改动），Base editing是圆珠笔（只改字母），Prime editing是全套工具箱
  - 📋 **文本编辑器的全部功能**：查找替换、删除、插入——它都有
- **关键数据**：David Liu实验室2019年发明；被称为"下一代基因编辑"；效率仍在优化中（低于Base editing）
- **常见误区**：
  - ❌ "已经取代了CRISPR" → 各有适用场景，Prime editing更适合小规模精确修改
  - ❌ "什么都能改" → 大片段编辑（>100bp）效率仍然很低
- **相关概念**：CRISPR-Cas9、Base editing

### 概念4：脱靶效应（Off-target Effect）
- **学术定义**：基因编辑工具在非目标位置产生意外的DNA修饰
- **大白话**：你想改第5页第3行的一个字，结果不小心把第8页也改了一个——这就是脱靶
- **类比**：
  - 🎯 **射偏了**：瞄准靶心但打到了旁边的环上
  - 💊 **药物副作用**：药治好了病但也带来了其他问题——不是药不好，是不够精准
- **关键数据**：高保真Cas9变体（eSpCas9/HF1）可将脱靶降低90%以上；检测方法：GUIDE-seq、CIRCLE-seq等
- **常见误区**：
  - ❌ "脱靶一定有害" → 大多数脱靶发生在非编码区或不表达的区域，不一定有实际影响
  - ❌ "新技术没有脱靶" → 所有编辑技术都有，只是模式和频率不同

### 概念5：基因敲除 vs 基因敲入（KO vs KI）
- **学术定义**：KO = 破坏/移除基因功能；KI = 在特定位点插入新的基因序列
- **大白话**：敲除 = 把某个基因关掉（让它不工作）；敲除 = 在某个精确位置装上一个新基因
- **类比**：
  - 🔌 **拔插头 vs 换零件**：KO = 把电器插头拔了（不工作了）；KI = 把旧零件换成新的（有了新功能）
  - 🚪 **拆门 vs 换锁**：KO = 把门拆了（进出自由但没安全感）；KI = 把锁换成智能锁（升级了）
- **关键数据**：KO效率通常30-80%；KI效率通常1-20%（低很多！这是行业痛点）
- **常见误区**：
  - ❌ "敲除比敲入简单所以不重要" → 很多疾病需要精确插入（如修复突变），不只是关掉

## 技术对比速查表

| 特性 | CRISPR-Cas9 | Base Editor | Prime Editor |
|------|------------|-------------|--------------|
| **原理** | 双链断裂+修复 | 单碱基直接逆转录 | 逆转录+ flap切割 |
| **能做什么** | 敲除/敲入 | C→T/A→G/G→A/T→C | 所有12种转换±小indel |
| **精度** | 中（依赖HDR） | 高（单碱基级别） | 最高 |
| **效率** | KO高/KI低 | 中高 | 中（优化中） |
| **DSB？** | ✅ 有 | ❌ 无 | ❌ 无 |
| **脱靶风险** | 中 | 低 | 极低 |
| **成熟度** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐ |
| **最佳场景** | 基因敲除/大改造 | 点突变修复 | 精确的小规模编辑 |

## 这个领域的"黄金问题"
1. **体内递送怎么做？** 工具很好用，但怎么送到人体内正确的细胞里仍是最大瓶颈
2. **脱靶能不能彻底消除？** 目前只能降低不能根除
3. **伦理边界在哪？** 生殖系编辑（改变可遗传的基因）在全球大部分国家被禁止
