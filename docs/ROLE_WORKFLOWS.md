# 科生 · 角色工作流程手册（Role Workflows）

> 每个角色的**专属 SOP**：什么时候介入、做什么、产出什么、交给谁、被谁查。
> 与编排手册（`orchestration/ORCHESTRATION.md` 的 M1-M5 派活清单）配合使用：手册管"全局怎么排"，本文管"角色自己怎么做"。
> 图谱侧：每个角色流程 = `RoleWorkflow` 实体（工艺域），查询 `kg_query.py --domain 工艺 <角色名>`。
> **判型先行**（`docs/USER_SOP.md` KSP-01 同卡判型 · 硬规则 #42④／#43／#44）：**下面的 M1-M5 矩阵＝通道 A 基准**；
> **判为通道 B（剧集）或含通道 C（音乐驱动）段时，按文末「附A／附B」给对应角色加动作**——**通道 A 的职责一条不减**（硬规则 #42③）。

## 1. 制片人（主 agent / orchestrator）

- **触发**：用户提出需求。
- **流程**：① 定档(S/M/L) → ② 简报卡+预注册标准（`templates/brief.md`）→ ③ 派活（照编排手册 §4，并行 subagent）→ ④ 汇总各 📤 → ⑤ 判决/门控（对照预注册标准）→ ⑥ 用户关卡（ask_user_question）→ ⑦ 纪录：decision-log → ⑧ 知识萃取收尾。
- **产出**：brief.md / 各里程碑 decision-log / 每关 📤 汇总交接卡。
- **门控**：被用户查（甲方）；自己不得代庖任何角色内容（S 档除外）。

## 2. 导演（Director）

- **触发**：M1 简报定稿后。
- **流程**：① M1 出**导演阐述**（一句话主题+三句核心信息+风格关键词+节奏曲线）→ ② M2 艺术基调与可拍性调研 → ③ M3 概念先行（总艺术方案）+ 交叉质询 + **整合四份提案出总方案 v1** → ④ M4 审核分镜表/摄影方案/声音方案（各部门方案经你手才可定稿）→ ⑤ M5 **定剪**（画面/声音/节奏三遍+回炉清单）。
- **产出**：director-艺术阐述.md / director-概念先行.md / 整合 m3-proposal.md / director-定剪意见.md。
- **门控**：被制片人+用户查（艺术不越界：艺术表达不得偏离简报）。

## 3. 编剧（Screenwriter）

- **触发**：M3 定稿（或 M2 若做叙事角度调研）。
- **流程**：① 读理解报告+受众模型 → ② M3 概念先行（叙事角度）→ ③ 质询 → ④ 定稿后 M4 出**口播稿 v2**（钩子→意义→核心→收尾→CTA；单段≤10s≈40字；术语首次解释）→ ⑤ **制片人提交用户拍板（重要：口播稿影响分镜设计，确认后才跑分镜）** → ⑥ 配合配音/朗读版核对。
- **产出**：screenwriter-概念先行.md / screenwriter-口播稿.md。
- **门控**：被观众代言人（一次看懂率）+ 科学顾问（数据出处）+ 用户（口播稿拍板 #16）查。

## 4. 分镜师（Storyboard Artist）

- **触发**：方案确认后（先出**九宫格风格预览**）；口播稿用户拍板后（再出分镜表）。
- **流程**：① 方案确认后：宫格技法（`playbooks/storyboard-grid.md`：Image2 生图九宫格）一次出**九宫格风格预览**（构图/配色/材质/光效/画风对标方案），交美术指导批复 → 用户拍板 #15 → **风格基线固化**（风格token/色板/画风/构图倾向，写入分镜表表头）→ ② 口播稿拍板后：读口播稿+导演阐述+美术方案+**风格基线** → ③ 分镜拆分（单镜 3-10s，按口播切段）→ ④ 构图/景别/视觉隐喻/招牌镜头（**严格尊重九宫格风格基线，禁止另起风格——防后续出图同质化**）→ ⑤ 运镜列**与摄影指导合议** → ⑥ 标记需**参考包（多角度）/首帧**的结构镜头与三视图需求 → ⑦ 按质控意见修改。
- **产出**：九宫格风格预览图（+风格基线）/ storyboard-分镜表.md。
- **门控**：被导演（叙事顺序）+ 摄影指导（可拍）+ 用户（九宫格 #15）+ 红队前置闸查。

## 5. 美术指导（Art Director）

- **触发**：M1 简报定稿后（M2 可选做风格方向调研）；KSP-04.5 九宫格风格批复。
- **流程**：① 出**美术方案**（风格关键词/色板/字体/VI 引用/风格 token 块视觉部分）→ ② 关键主体多角度示意图清单与素材分级 → ③ 图表层视觉规范（参数卡/曲线/覆盖图/结构图解）→ ④ **KSP-04.5 批复九宫格风格口径**（色板/光效/材质对格论，固化基线）→ ⑤ M4 分镜/摄影方案逐项批复风格口径 → ⑥ 出口闸前 VI 逐项过（色彩/字体/转场）。
- **产出**：art-director-美术方案.md / 九宫格风格批复 / 资产与示意图清单 / 图表层规范。
- **门控**：被导演（风格漂移）+ 红队出口闸查。

## 6. 摄影指导（DoP）

- **触发**：M1（可拍约束）/ M3（概念先行）/ 分镜表定稿后（摄影方案）。
- **流程**：① M1 一页可拍约束清单（平台边界/拍法/风格禁区）→ ② M3 概念先行（影像质感角度）→ ③ M4 每镜**摄影方案**：运镜（≤2 带变速/复合）+光影氛围+动态设计+拍法路线（**参考包优先→多镜原生→I2V 仅兜底**）+参考资产需求+首尾帧衔接链（仅支持平台） → ④ 与 prompt 工程师结对（你定"要什么画面"→他写）→ ⑤ 分镜表运镜列合议定稿。
- **产出**：dop-摄影方案.md（分镜表摄影扩展列）/ 一致性方案。
- **门控**：被导演（质感统一）+ 观众代言人（画面可读）+ 红队查"动感缺失/不可制作"。

## 7. 声音设计师（Sound Designer）

- **触发**：口播稿 v2 到手（与分镜师并行）。
- **流程**：① 读导演阐述+口播稿+受众模式 → ② **声音方案**：BGM 情绪曲线（起/落/留白）+曲风方向+商用素材库 → ③ 音效清单（环境/拟音/转场/UI）+配音建议（音色/语速/术语发音检查）→ ④ 分镜表声音标注（每镜音乐情绪/音效/转场音）→ ⑤ 卡点表（哪镜切点接哪个重音）→ ⑥ M5 混音三遍听（闭眼/看画面/外放）。
- **产出**：sound-声音方案.md / 卡点表 / 混音审查意见。
- **门控**：被导演（情绪符不符基调）+ 红队（配音准确度维度/版权）。

## 8. 剪辑师（Editor）

- **触发**：M3 定稿（预计划）/ M4 分镜表（备注）/ M5 素材（执行）。
- **流程**：① M3 剪辑预计划（节奏曲线/转场策略/字幕与图表层工作量）→ ② M4 分镜表补剪辑备注 → ③ M5 **剪辑/后期执行单**（素材顺序/转场/字幕/图表层/文案层/调色 LUT/片头片尾）→ ④ 交付前自查（字幕术语/图表数值=原文/响度/时长/总一致性）。
- **产出**：editor-剪辑预计划.md / 执行单 / 自查清单。
- **门控**：被导演（节奏/定剪）+ 红队（节奏感/信息密度/图表数据红线）。

## 9. 科学顾问（Science Advisor）

- **触发**：M1（硬约束）/ M2（理解报告）。
- **流程**：① M1 科学硬约束清单 → ② M2 **7 步深度理解法**（先查 kb/，自评 L2 底线，待确认清单）→ ③ M3 事实复核（参与质询与提案审）→ ④ M4 涉科学镜头/表述复核（subagent_fork 独立上下文）→ ⑤ M5 终审全片 → ⑥ **知识萃取入库**（kb/入库规则.md+隐私红线.md）。
- **产出**：scientist-理解报告.md / 事实审查意见 / kb 新笔记。
- **门控**：L2 底线不过不许放行；事实争议一律查证或升级（不折中）。

## 10. prompt 工程师（Prompt Engineer）

- **触发**：分镜表+摄影方案定稿。
- **流程**：① 读分镜表（每镜六要素）→ ② 分段（5-8 镜/段）→ ③ 每段按平台公式写 prompt（风格 token 块逐字复用/负面词/参考图需求/时长档/抽卡建议）→ ④ 按摄影方案的运镜光影写法执行 → ⑤ 查"常见失败→修复表"自检 → ⑥ 出片阶段接到翻车反馈 → 改 prompt 重跑。
- **产出**：prompt-<section>.md（+一致性方案）。
- **门控**：被摄影指导（画面写法）+ 科学顾问（科学表述）+ 红队前置闸（硬性违规）。

## 11. 观众代言人（Audience Advocate）

- **触发**：M1（受众模型）/ M2（语境）/ M4（审查）/ M5（过审）。
- **流程**：① M1 受众证据模型（消费场景/最先看的指标/证据可视化优先）→ ② M2 受众语境与证据映射 → ③ M3 提案质询（一次看懂视角）→ ④ M4 口播稿+分镜审查（逐段以受众口吻复述/术语负担/5 秒钩子兑现/留置尿点）→ ⑤ M5 成片/朗读版过审。
- **产出**：audience-受众模型.md / audience-审查意见.md。
- **门控**：被用户（真实受众感受）+ 红队（信息密度/错位模式）。

## 12. 红队（Red Team）

- **触发**：三个闸点之一（M3 对抗 / M4 前置闸 / M5 出口闸）。
- **流程**：① 只读制品+预注册标准（**不听任何角色辩护**）→ ② 轮换视角（科学/传播/制作/甲方/伦理）→ ③ 前置闸=硬性违规 pass/fail；出口闸=七维评分单(0.0-1.0)+三态裁决 PASS/CONDITIONAL/BLOCK → ④ 每条反对带推翻条件 → ⑤ 少数派报告原样入纪要。
- **产出**：red-team-<闸>.md（致命反对/违规清单/评分单）。
- **门控**：BLOCK ≤2 次循环后升级用户；被制片人复核（只评制品不评人）。

## 协作边界（防越界）

- 分镜师管"画面是什么"；摄影指导管"怎么拍"；美术指导管"长什么样/什么规范"——三者冲突找导演。
- 声音设计师与剪辑师共管节奏：BGM 重音对切点（卡点归剪辑，音效层归声音）。
- 科学顾问只对事实负责；对"待确认"有否决权但无创作权。
- 红队只出现在闸点，不参与创作。
- **通道 C 段例外**：卡点归**声音设计师**（卡点表主笔），镜头表归**分镜师**，装配验收归**剪辑师**——判为 C 段时"卡点归剪辑"改为"**卡点表由声音设计师出、剪辑师负责逐卡点装配对齐**"（`playbooks/mv-production.md`）。

## 附A · 各角色在「通道 B（剧集）」／「通道 C（音乐驱动·横向）」下的额外职责

> 用法：KSP-01 判型后（纵向 A/B ＋ 横向是否 C），按本表给角色**加动作**。空栏＝该角色在該通道无额外动作（原职责不变）。

| 角色 | 通道 B（剧集）额外职责 | 通道 C（音乐驱动·横向）额外职责 |
|---|---|---|
| **制片人（主）** | E0 判型写死 `brief.md` → E1 全季大纲拍板 → E2 风格圣经拍板 → E3 逐集循环编排 → **E4 派"未参与该集创作"的独立上下文检察官** → E5 发布节奏与追更；**未出大纲/圣经不得开工任何单集**（#35/#36）；A→B／A+B 混用走 KSP-C | 在 `brief.md` 写明 **C∩A／C∩B／纯 C** 并**标出哪几段属 C 段（时间码）**（#44②）；**不新增关卡**——C∩A 挂 A 的 KSP-01~07，C∩B 挂 KSP-E2 圣经＋KSP-E1 时长预算；C 段验收以**卡点表＋时长契约**为准（#43③） |
| **导演** | 全季叙事弧与集间节奏；每集定剪对齐圣经；**集尾钩子↔下集开场**的接法背书（#39） | C 段**母题回环与情绪曲线**——每个镜头的理由必须能在歌里找到依据；**禁给 C 段编"四场脊椎／剧透结构"**（#43③） |
| **编剧** | 全季分集大纲（每集梗概/叙事功能/伏笔回收表/钩子↔下集开场）；逐集剧本；**集尾钩子写法**（回目式/意象钩/情绪悬置） | **C 段不写对白／口播**（人声只属于歌）；OP·ED 歌词文本走**歌词／引文闸**（出声账本 F-48／引句探针 F-49／体裁判据 F-50）；**剧透边界**：OP/ED 不得预告本季未播关键反转 |
| **分镜师** | 逐集分镜；**锚图/场景锚/字帖一律原文复用**（#37，禁重抽、禁凭记忆重画）；跨集视觉母题的复现声明 | MV：**卡点表 → 镜头表**（每镜标注卡点号/重音/时长）；二次构图、留白呼吸、母题回环；OP/ED 只换"集别定制位" |
| **美术指导** | **风格圣经（Show Bible）主笔**——色板/字形语义/角色锚/器物锚/母题；**版本与生效集号写死**（#36③）；新设定先入圣经（禁单集先定圣经后补） | C 段**色语义与专属空间标记逐段负面钉死**（禁串场）；MV 视觉与 A/B 的品牌 VI 取色一致（**官方源，禁自造**·拍板 #18/#19） |
| **摄影指导** | 跨集影像一致性（同场景同光位/同拍法）；**OP/ED 与正片的接法**（转场/调色衔接） | MV 运镜服务卡点（≤2 带变速/复合）；**不新增对白镜**；对素材三类来源做可拍性判断 |
| **声音设计师** | 全季音乐母题表（角色主题/场景主题）；集间音效延续；**OP/ED 时长为固定资产**（逐集逐秒相等·D-S1） | **C 段主责**：词曲 → **卡点表**（唯一模板 `templates/mv-beat-sheet.md`）→ 重音/切点；混音验收按卡点逐一核对 |
| **剪辑师** | 逐集节奏；**跨集时长结构一致**（OP/正片/ED 契约）；集尾钩子落点 | MV：**装配验收**——逐卡点对齐、留白呼吸、**禁卡点轰炸**；无对白段的字幕纪律（只允许文字白名单内文字） |
| **科学顾问** | 剧集科学设定**入圣经**（禁单集自定）；跨集事实一致（同文本同帖） | C 段无科学表述义务；涉成果/数据的 MV 仍走事实核验（数值人工锁值） |
| **prompt 工程师** | 逐集 prompt，**引用圣经与锚图版本**（`check_bible_pin.py`）；剧集专属项 D12/D13 | MV prompt 按**卡点表逐镜**写（时间轴＝卡点秒位）；C 段**无口播字段**、负面禁"对白/说话" |
| **观众代言人** | 集尾钩子的"想追下一集"力；跨集认知负担（新观众能否上车） | MV 的"一遍记住一句"（歌与画面互不解释也能懂）；OP/ED **不得塞叙事信息** |
| **红队** | **E4 跨集一致性由独立上下文执行**（未参与该集创作）；全季红线继承 | C 段专项：**卡点是否真有音乐依据**／是否把 MV 当叙事片做／**C 规则是否外溢**到 A 口播片与 B 正片 |
