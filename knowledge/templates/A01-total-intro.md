# 📋 A-01 总体介绍片脚本模板（申报/立项用）

> **适用场景**：预研阶段、立项答辩、首次对外介绍
> **时长**：3-5分钟
> **目标**：让评审/领导在5分钟内理解"这是什么、为什么重要、凭什么你们做"

---

## 模板结构

### 【镜头1】🎯 国家战略切入（0:00-0:25）
**画面建议**：宏大航拍→科技感数据流→项目名称浮现
**文稿模板**：
```
在{国家战略关键词}的宏大背景下，{行业领域}正迎来前所未有的变革机遇。
{项目名称}，正是回应这一时代召唤的{核心定位}。
投资{金额}亿元，占地{面积}，汇聚{人数}名科研人员——
这不是一个普通的实验室，而是一座{比喻性定位}。
```

**钩子变体**：
- "中国每年在XX上花费XXX亿，但核心技术仍被卡脖子..."
- "如果能把XX的效率提升10倍，意味着..."
- "过去XX年，人类在XX领域取得了X次革命性突破，而第X+1次，正在这里发生..."

### 【镜头2】📍 痛点与使命（0:25-1:00）
**画面建议**：问题可视化（痛点动画）→ 过渡到解决方案轮廓
**文稿模板**：
```
但我们也面临着一个根本性的挑战：{核心痛点描述}。
传统方案存在{痛点1}、{痛点2}、{痛点3}三大瓶颈。
{项目名称}的使命只有一个：{一句话使命}。
简单来说，就是实现从"{旧范式}"到"{新范式}"的跨越。
```

### 【镜头3】💫 四大系统/核心架构（1:00-2:30）
**画面建议**：架构图逐层展开 → 每个系统配标志性画面 → 汇聚动效
**文稿模板**：
```
为实现这一使命，我们构建了{数字}大核心系统：

第一，{系统1名称}——{一句话定位}。
{通俗化解释 + 类比}。

第二，{系统2名称}——{一句话定位}。
{通俗化解释 + 类比}。

第三，{系统3名称}——{一句话定位}。
{通俗化解释 + 类比}。

第四，{系统4名称}——{一句话定位}。
{通俗化解释 + 类比}。

四大系统不是孤立的，而是形成了一个完整的{闭环比喻}。
从{输入}，到{处理}，再到{输出}——每一步都经过精密设计。
```

### 【镜头4】🔥 核心优势与竞品对比（2:30-3:30）
**画面建议**：对比图表（柱状图/雷达图）→ 关键数据跳动 → 优势标签弹出
**文稿模板**：
```
那么，我们的核心竞争力在哪里？

首先是{优势1}——{数据支撑}。相比国际同行{具体对比对象}，我们实现了{提升幅度}的提升。

其次是{优势2}——{数据支撑}。这项指标直接决定了{应用价值}。

更重要的是{优势3}——{战略意义描述}。这意味着我们不仅是在做{技术层面的事}，更是在为{更大格局}奠定基础。
```

### 【镜头5】🚀 预期成果与愿景（3:30-4:15）
**画面建议**：时间线展开 → 成果图标逐一亮起 → 愿景画面（震撼收尾）
**文稿模板**：
```
展望未来，{项目名称}将在三个层面产生深远影响：

科学层面——{预期科学成果}。预计在{时间框架}内，{具体预期}。

产业层面——{预期产业影响}。{具体应用场景}将因此受益。

国家层面——{战略意义}。这将使我国在{领域}方面达到{国际地位}。

{金句收尾}。
```

### 【镜头6】CTA（4:15-结尾）
**画面建议**：Logo + 项目名称 + 联系方式 + Slogan
**文稿模板**：
```
{项目名称}——{Slogan}。
期待各位专家的支持与指导。谢谢！
```

---

## 填空检查清单
- [ ] 国家战略关键词（至少1个权威出处）
- [ ] 投资金额/规模/人员数据
- [ ] 一句话使命（能用类比讲清）
- [ ] 四大系统的通俗化解释（每个都有类比）
- [ ] 至少3个硬核对比数据
- [ ] 三层预期成果（科学/产业/国家）
- [ ] 金句收尾（值得被引用的那句）
