# 🎭 C类：分受众定制适配指南

> 核心原则：**同一份技术内容，5种完全不同的讲法**

## 适配总表

以"CRISPR基因编辑番茄提高GABA含量"为例（日本已上市的高GABA番茄，公开商业化案例）：

### 👨‍🔬 专家/评审版（EXP）
```
叙事策略：技术驱动，数据说话
开头：直接切入科学问题
"本研究利用CRISPR-Cas9系统靶向编辑GABA代谢通路关键基因，
 使番茄果实中GABA（γ-氨基丁酸）含量达到普通品种的4-5倍。"
术语处理：保留全称，不加解释
数据密度：高（每30秒≥2个数据点）
类比使用：极少（1-2个，点到为止）
语气：客观、精炼、不废话
时长：可较长（8-10min），专家有耐心看细节
结尾：指向后续研究方向/开放问题讨论
```

### 🏛️ 政府领导版（GOV）
```
叙事策略：成果导向，突出战略意义
开头：国家战略高度切入
"在'种业振兴'和'健康中国'的双重战略背景下，
 粮食与果蔬营养强化成为保障国家粮食安全的新路径。"
术语处理：首次出现加3-6字通俗注解
 "CRISPR基因编辑（一种精准的分子育种技术）"
数据密度：中（选最震撼的3-5个关键数据）
类比使用：适中（每个核心概念配1个生活化类比）
语气：大气、有格局、强调"国内领先/国际先进"
时长：3-5分钟（领导时间宝贵）
结尾：强调社会效益/经济效益/带动就业
 "这类技术若推广至主产区，预计每年创造产值XX亿元..."
```

### 🌍 公众/科普版（PUB）
```
叙事策略：故事化叙事，类比驱动
开头：反常识钩子或悬念提问
 "你吃的番茄里，藏着一种能帮你放松下来的物质。
 但普通番茄里它少得可怜。
 现在，科学家找到了一把'钥匙'——"
术语处理：全部翻译成口语 + 类比
 CRISPR → "分子的精准剪刀"
 GABA → "大脑的'放松信号'"
 基因编辑 → "给基因改错别字"
数据密度：低（只留最震撼的1-2个数字）
 "含量翻了好几倍！"（够了吗？够了）
类比使用：大量（每个概念都必须有类比）
语气：有趣、温暖、"像在和朋友聊天"
时长：1-3分钟（短视频黄金时长）
结尾：情感升华 + 关注引导
 "科学的魅力在于——它比你想象的更疯狂，也更有温度"
```

### 🎓 学生/青年研究者版（STD）
```
叙事策略：启发式，展示前沿性和可能性
开头：激发好奇心 + 展示领域前景
 "想象一下：你能设计出一种从未存在于自然界的番茄。
 它不仅好吃，还能帮人缓解压力。
 这不是科幻——这是基因编辑正在做的事情。"
术语处理：出现时简短解释（比公众版深一点但不用全称）
数据密度：中偏低（选有意义的数据，不求全）
类比使用：较多（帮助理解新概念）
语气：激励性、展示"这个领域很酷"、降低门槛
 "你不需要现在就懂所有细节，但你应该知道这个方向存在"
时长：3-5分钟
结尾：招生态 + 展望感
 "如果你是生命科学专业的学生，这就是你未来可能工作的方向。
 欢迎加入我们，一起编写生命的代码。"
```

### 🏭 产业合作伙伴版（IND）
```
叙事策略：应用导向，强调商业价值和ROI
开头：痛点直击（市场机会/行业瓶颈）
 "功能性食品市场正以每年15%的速度增长。
 但原料成本高、产量不稳定一直是行业痛点。
 我们的技术方案可以解决这个问题。"
术语处理：商业化表达替代学术术语
 "基因编辑" → "精准育种技术平台"
 "代谢通路优化" → "产物合成效率提升"
数据密度：聚焦商业指标（成本/产量/周期/市场规模）
类比使用：商务类比为主（生产线/供应链/投资回报）
语气：务实、专业、强调"我们已经验证了可行性"
时长：2-4分钟
结尾：明确合作邀请 + 下一步行动
 "我们正在寻找产业合作伙伴进行中试放大。
 如果您所在的企业对高附加值农产品感兴趣，欢迎对接。"
```

## 快速适配检查清单

拿到一份技术内容后：

1. **确认受众** → 选定上述一个模式
2. **改写开头** → 从对应模式的钩子库中选
3. **过滤术语** → 该保留/该翻译/该删除
4. **筛选数据** → 只留受众关心的那些
5. **调整类比** → 用目标受众熟悉的参照物
6. **重写结尾** → 匹配受众的核心诉求
7. **VI调整** → 按受众选择色彩/字体/转场风格
