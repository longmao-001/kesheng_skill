# 视频反推方法论（看到好视频 → 拆成 prompt）

> 来源：GitHub 调研（2026-08-12）。[luozhilzh/video-prompt-reverse](https://github.com/luozhilzh/video-prompt-reverse)（视频反推提示词工程师 skill，v1.2.0），内容已改编消化，非原文照抄。
> 用途：看到竞品/参考好视频时，系统拆解成可复现的 prompt；或把粗糙意图结构化。与我们 `playbooks/platform-prompts.md` 的分工：那边是"从零写"的公式，这边是"从片拆"的逆向工程。

## 一、核心洞察：视频的惊艳 = 运动设计

拆静态图只看布光/色彩/质感；拆视频必须多拆一层**运动**——多数反推只描述"画面里有什么"，不描述"怎么动"，产出就是"静态美图+乱动"。运动设计四个子维度（反推时必答）：

| 子维度 | 拆什么 | 词例 |
|---|---|---|
| 运镜 Camera | 机位怎么动 | 固定/摇/推拉/跟/环绕/升降/手持/变焦/FPV/甩 |
| 时序 Timing | 时间怎么流 | 实时/慢动作/延时/速度渐变/定格 |
| 主体运动 | 主体怎么动（幅度/速率/方向） | 走/旋转/流动/坠落/互动 |
| 物理与连续 | 重力/流体/布料/毛发真实感，帧间稳定 | 受重力的烟/风吹的火焰；无 flicker/morph |

## 二、反推工作流（6 步）

1. **看片拆维**：按场景套维度表（下文三），产出结构化"分析块"——只分析，不写 prompt。长视频先抽帧：
   ```bash
   ffmpeg -i input.mp4 -vf "fps=1/2" frames/frame_%03d.png        # 每2秒1帧
   ffmpeg -i input.mp4 -vf "select='gt(scene,0.4)',showinfo" -vsync vfr frames/scene_%03d.png  # 按场景切换抽
   ffmpeg -i input.mp4 -frames:v 1 first_frame.png                # 首帧（图生视频用）
   ```
2. **还原版 prompt**：忠实还原原片，一段一段写。密度纪律用**反事实测试**过滤——"这个元素不在画面里，场景还成立吗？"不成立→必写（主体/关键场景光/支撑叙事的动作）；成立→一句带过，防"写肿"。
3. **惊艳增强版**：在还原版上叠专业词块（运动设计+电影布光+色彩分级+负向约束），把"同款"变"升级版"。
4. **3 个变体**：每次只改一个维度——V1 改构图、V2 改光影、V3 改风格，多抓手试方向。
5. **平台适配**：转成目标平台语法（下文四）。
6. **迭代回路**：不满意不推倒，按诊断矩阵定位维度单点修（下文五）。

## 三、拆解框架：场景维度速查

通用七要素（主体/风格/色彩/光影/构图/质感/氛围）+ 运动 + 时长。各场景加拆：

| 场景 | 加拆维度 | 运动侧重 |
|---|---|---|
| 产品广告 | 材质反光/棚拍光/hero角度/背景过渡/产品占画面比例 | 360°环绕、缓慢推近、旋转展示 |
| 人物/口播 | 镜头焦段/光线/景深/色调 | 跟随/手持/固定；表情动作连贯 |
| 风景/空镜 | 前中远景/时间光线/氛围（雾云雨） | 航拍滑行/慢摇/延时 |
| 叙事故事片 | 分镜表/镜头衔接/情绪曲线 | 运镜语法+节奏，每镜一主运动 |
| 电商带货 | 前3秒钩子/卖点展示/证明动作 | 快速运镜+特写切换+紧凑节奏 |
| 风格片 | 风格词+对应运镜 | 赛博=霓虹摇移；国风=水墨缓推 |

分镜逐段记录表（分析块核心）：`| # | 时段 | 画面内容 | 运镜 | 主体运动 | 时序 | 音频 |`。

### 色彩分级拆法

主色调/光质（硬柔、方向、色温）/质感（胶片颗粒、锐度）/情绪基调。增强方向 14 选 1+：电影大片感、低调奢华、纪实纪录片、日系自然光、赛博朋克、国风东方、动漫、梦幻、蒸汽波、超写实产品级、史诗奇幻、胶片复古、杂志商业高级、暗黑戏剧。可组合（"电影感+胶片味"）。导演风格可拆成"构图+色彩+运镜+节奏+颗粒"五要素当词块用（如王家卫=慢动作+浓饱和+霓虹光斑+浅焦+胶片颗粒）。

## 四、各平台语法差异速查（反推视角）

同一段反推结果，到不同平台要改写的点（参数以各平台当前文档为准，2026-08 核实值会过期）：

| 平台 | 语法特征 | 反推适配要点 |
|---|---|---|
| 可灵 Kling | 自然语言 + **相机控制六轴**（水平/垂直/摇/俯仰/翻滚/变焦，[-10,10]）+ Motion Brush | 运镜可翻译成数值（单轴先试 ±5~±7，组合 ≤2 轴）；局部运动用运动笔刷 |
| 海螺 Hailuo | **方括号运镜指令**：`[推进][拉远][左摇]`… | 同组 ≤3 条；顺序运镜用"然后"连接 |
| 即梦 Jimeng | 中文自然语言，运镜可写量化参数 | "镜头高度1.6米，匀速前推，速度0.8米/秒，焦段24毫米"这种最稳 |
| 智谱清影 | `主体+场景+运动` 基础式，可叠美学控制 | 结构最简单，适合快速验证 |
| 通义万相 | 多镜头公式 `总体描述+镜头序号+时间戳+分镜内容`；声音公式（人声=内容+情绪+语调+语速+音色） | 多镜头叙事、character 引用锁角色 |
| Sora | 自然语言，懂电影术语（镜头/胶片/画幅） | 分析块可全展开写，最长 60s |
| Runway | Camera presets + Motion Brush | 迭代编辑工作流强 |
| Veo 3 | 5 块结构（camera/subject/action/setting/audio），原生音频 | 对话用引号、≤2 个音频事件；每段迭代只改一块 |
| Seedance（即梦Pro/LibTV 后端） | 见 `playbooks/platform-prompts.md` 官方核实专章 | @引用参考、时间戳/镜头序号多镜写法 |

模型路由思路（一段一模型）：运镜段→可灵，音频段→Veo3，长连贯段→Sora，某段做砸了就路由到该维度更强的模型。

## 五、迭代回路：六维诊断矩阵

不满意的成片**先归维度再改**，不整段推倒：

| 维度 | 典型失败 | 修订动作 |
|---|---|---|
| 内容 | 主体错/元素缺失多余 | 开头重述主体+锁定词；多余元素进负向 |
| 运动 | 运镜没按意图、抖动、动作卡 | 换原生控件写法；加 `stable camera`；显式标时序 |
| 音频 | 缺失/错位/口型不同步 | 显式写环境音；对白用"角色说：…"结构 |
| 物理逻辑 | 变形 morphing、闪烁、多肢体 | 负向必加 `no morphing, no flickering, no extra limbs` |
| 人物真实感 | 脸漂移、身份不一致、表情僵 | 首帧图生视频兜底；加微表情描述 |
| 风格一致性 | 跨镜色彩/光跳变 | 全局风格锁词逐镜重复；固定平台路由 |

配套动作：**锁 seed 单维微调**（沿用接近版的 seed 只改出问题维度，失败模式加进负向）；**分层验收**（内容✓→运动✓→风格✓→音频✓ 全过才锁段）；**经验沉淀**（记录"片型→失败维→有效修订→平台/seed"，越用越准）。

视频专属负向词库（图像负向覆盖不了视频翻车模式）：`no morphing, no flickering, no jitter, no melting, no warping, no temporal distortion, no extra limbs, no identity drift, no text drift`。

## 六、多镜头一致性：双锚定规则

与我们的 [[首帧锚定]] [[全能参考三用法]] 互补的一个硬规则——**不要只在首镜定义锚点、后续镜靠共享风格词隐式继承**（长序列里风格词会被模型遗忘）。每个后续镜头 prompt 显式重嵌两样：

```
[Original Lock] + [Prev-shot Token] + [本镜新增内容]
例："same male, short dark hair, black jacket"（原始锁定）
  + "continuous from shot 2, same location, same wardrobe"（上镜承接）
  + 本镜新动作
```

人物一致性最可靠做法仍是图生视频+参考图（即 [[首帧锚定]]）；维护 prompt log，新镜头从成功版改而非从零写。

## 七、责任边界（源仓库护栏，值得保留）

反推不等于抄：不抄真实 logo/水印/具名创作者/受保护角色；不帮克隆可识别真实人物容貌冒充本人（用户自有肖像权除外）；检测到未成年出镜拒绝复刻其身份。视频深伪风险比静态图高一个量级，务必守。
