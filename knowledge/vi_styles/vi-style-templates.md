# 🎨 VI规范模板库

## 模板一：科技蓝+生物绿（高校/科研院所风格）

> 适用：国家大设施/高校研究所/生物医药企业
> 感觉：严谨、创新、有国家高度

### 色彩体系
```
主色：
  - 科技蓝:    #1a56db  (RGB 26,86,219)   → 标题/关键数据/强调
  - 生物绿:    #00b67a  (RGB 0,183,122)   → 生命元素/生长/正向指标
辅助色：
  - 设备银灰:  #e8ecf1  (RGB 236,236,241) → 背景/分隔/次要信息
  - 警示橙:    #ff6b35  (RGB 255,107,53)   → 痛点/挑战/注意
  - 成就金:    #FFD700  (RGB 255,215,0)    → 成果/亮点/第一
系统标识色（四系统各一个）：
  - 系统A:    #3B82F6  (蓝)
  - 系统B:    #10B981  (绿)
  - 系统C:    #8B5CF6  (紫)
  - 系统D:    #F59E0B  (琥珀)
背景：
  - 主背景:    #0a0e27  (深夜蓝，近黑)     → 有科技感
  - 浅背景:    #f8fafc  (近白)             → 数据图表/文字密集场景
渐变：
  - 主渐变:    linear-gradient(135deg, #1a56db, #00b67a)
  - 光效:      radial-gradient(circle, rgba(26,86,219,0.3), transparent)
```

### 字体
- **中文标题**：思源黑体 Heavy / 阿里巴巴普惠体 Bold（字号≥36）
- **中文副标题**：思源黑体 Regular / Medium（24-32）
- **中文正文**：思源黑体 Regular（16-20）
- **英文/数字**：Roboto / Inter（与中文字号匹配）
- **数据标注**：Roboto Mono 或 DIN（等宽，数字对齐）

### 转场风格
- **主转场**：粒子流（蓝色→绿色粒子从左至右流动扫过屏幕）
- **次转场**：光轨（光线沿图形边缘勾勒轮廓后炸开）
- **章节切换**：数据流汇聚（四角光点向中心汇聚→闪白→新章节标题）

### 片头模板（5秒）
```
[0.0s] 纯黑 → 微弱蓝色粒子开始出现
[1.0s] 粒子汇聚形成校徽/Logo轮廓（居中，白色线框）
[2.0s] Logo下方淡入项目全称（白色，思源黑体）
[2.5s] 四个系统图标从四角飞入，排列在Logo两侧
[3.5s] 主渐变色光扫过整个画面
[4.5s] 定格，进入正文
```

### 片尾模板（3秒）
```
[0.0s] 正文最后一帧
[0.5s] 画面渐暗，中央保留Logo+项目名
[1.5s] 下方淡入联系方式/Slogan
[2.5s] 渐黑结束
```

## 模板二：医疗洁净风

> 适用：医疗器械/临床研究/制药公司/CRO
> 感觉：洁净、可信、专业、温暖

### 色彩体系
```
主色：
  - 医疗蓝:    #0077BE  (信任、专业)
  - 生命粉:    #E91E63  (关怀、温度)  
  - 纯净白:    #FFFFFF  (洁净、简约)
辅助色：
  - 安静灰:    #F5F5F5  (背景)
  - 活力青:    #00BCD4  (健康、活力)
  - 提示红:    #EF4444  (重要警示)
背景：
  - 主背景:    #FAFBFC  (极浅灰白)
  - 对比背景:  #0077BE  (深蓝块用于文字)
字体：
  中文：思源黑体（标题Heavy/正文Regular）
  英文：Roboto / Poppins
转场：柔和模糊过渡 + 细线条延伸（非粒子爆炸式）
片头：心跳线(ECG)动画→Logo浮现→项目名称
```

## 模板三：自然暖色调（科普向）

> 适用：公众科普/开放日/学生/新媒体传播
> 感觉：亲切、有趣、不 intimidating

### 色彩体系
```
主色：
  - 阳光橙:    #FF9500  (活力、能量)
  - 天空蓝:    #5AC8FA  (开阔、清新)
  - 草地绿:    #34C759  (自然、生命)
辅助色:
  - 云朵白:    #F2F2F7
  - 樱花粉:    #FF2D55  (趣味点缀)
  - 薰衣草紫:  #AF52DE  (神秘感/高端科学)
背景：
  - 主背景:    渐变(浅蓝→浅绿/浅黄) 或 纯白
  - 避免纯黑背景（太严肃，吓跑路人）
字体：
  中文：更圆润的字体（如果可用）/ 思源黑体 Round
  英文：Nunito / Quicksand（圆润友好）
转场：弹性变形 / 可爱元素弹入 / 自然过渡
片头：卡通化Logo + 可爱吉祥物(如有) + 活泼音乐提示
```
