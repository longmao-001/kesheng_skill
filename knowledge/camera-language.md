## 一、运镜：情绪效果与适用场景

| 运镜 | 情绪/效果 | 什么时候用 |
|---|---|---|
| 推（dolly-in） | 建立紧张、聚焦注意力、情感逼近 | 戏剧性揭示、情绪时刻、开场建立 |
| 拉（dolly-out） | 释然、孤独、交代全貌 | 收尾、揭示环境规模、情绪抽离 |
| 摇（pan/tilt） | 扫视信息、跟随视线 | 展现场景宽度/高度、跟视线引导 |
| 移（truck） | 平行观察、展示场景深度 | 跟随角色侧面移动、空间关系 |
| 跟（tracking） | 陪伴感、行动感 | 角色行进、动作场面、低机位跟拍显步伐 |
| 环绕（orbit） | 英雄时刻、全方位审视 | 产品展示、人物高光、主角登场 |
| 升降（crane/jib） | 史诗感、规模揭示 | 建立全景、开场/收尾的格局拉开 |
| 变焦（zoom） | 突然强调、快速转向 | 强调关键元素（比推更"硬"更主观） |
| 希区柯克变焦（dolly-zoom） | 眩晕、心理冲击、世界塌陷感 | 震惊瞬间、转折揭示、背景虚化焦点回缩主体 |
| 手持（handheld） | 纪实、紧迫、亲密 | 纪录片感、UGC 真实感、追逐 |
| FPV 穿越 | 沉浸、速度、探索 | 第一人称体验、穿空间、开箱/跑酷 |
| 甩（whip pan） | 节奏、转场冲击 | 快速切换场景且保持视觉连贯 |
| 固定（locked-off） | 稳定、客观、仪式感 | 对话、产品细节、数据/落版镜头 |
| 探针/微距穿梭 | 奢侈、解压、微观奇观 | 首饰手表贴面滑行、穿缝隙、个护微观效果 |
| 低角度环绕 | 力量感、时尚感 | 潮流服饰、模特全身、产品英雄化 |
| 鱼眼贴脸 | 畸变张力、街头感 | 潮流/重音卡点片头，配合重影闪烁 |

速度修饰即情绪修饰：缓慢=奢侈/沉思，中速=自然/功能展示，快速=科技/活力。**单镜 ≤2 种运镜**，要动感靠变速和复合，不靠堆数量——见 [[动感三来源]]。

### 旋转速度与节奏（产品 360° 专用）

- 慢速（360°/10-15s）：奢侈品、腕表——观众吸收每个细节
- 中速（360°/5-8s）：时尚、美妆——形式与功能兼顾
- 快速（360°/2-4s）：科技、动感产品——传达速度与现代性
- 多速度：主角度慢起，加速制造冲击（变速即高级）

## 二、景别：叙事功能与焦段参考

| 景别 | 焦段参考 | 叙事功能 |
|---|---|---|
| 远景 | 16-24mm | 交代环境、空间关系、格局 |
| 全景 | 35mm | 人物全身动作、场景全貌 |
| 中景 | 50mm | 人物上半身、产品与人的交互（带货演示主力景别） |
| 近景 | 50mm | 面部表情、情绪反馈 |
| 特写 | 85mm | 产品细节、关键动作（卖点演示主力景别） |
| 大特写 | 135mm | 微观细节：水珠、气泡、纹理、膏体 |

经典景别动线：远→中→近→特写（推进式叙事），或特写→远（悬念式揭示）。

## 三、拍摄角度：权力关系速查

- 平视：客观、平等，对话与产品展示默认
- 俯视（高角）：弱势、脆弱、孤立；也用于产品俯拍摆阵
- 仰视（低角）：权力、胁迫、英雄感；产品显得"大"
- 过肩：对话、对抗、互动关系的标配
- 居中固定：仪式感、落版专用

## 四、景深与焦点

| 策略 | 视觉效果 | 情感影响 |
|---|---|---|
| 浅景深（f/1.4-2.8） | 主体锐利背景奶油化 | 隔离、亲密、聚焦；产品片默认 |
| 中景深（f/2.8-5.6） | 主体与部分背景清晰 | 平衡叙事 |
| 深景深（f/8+） | 全部清晰 | 环境信息、全景交代 |
| 移动焦点（rack focus） | 焦点在画面中转移 | 揭示信息、引导注意力 |
| 光学光斑（bokeh） | 背景光点失焦 | 梦幻、浪漫、电影质感 |

## 五、转场：什么转场配什么片

| 转场 | 效果 | 适用 |
|---|---|---|
| 硬切 | 干脆、节奏 | 对话、快节奏带货 |
| 匹配剪辑（match cut） | 高级、流畅穿越 | 主体轴向一致换场景（产品不变背景变） |
| 鞭甩转场 | 速度、张力 | 潮流/运动片场景切换 |
| 溶解（dissolve） | 柔和、时光流逝 | 礼盒揭示、回忆、情绪过渡 |
| 遮挡转场 | 无缝、一镜到底错觉 | 前景物体掠过镜头后换场景 |
| 粒子消散/重组 | 科技感、变装 | 极速变装、材质转换 |
| 冻结帧→爆发 | 节奏中断再炸开 | 钩子段、卡点片头 |

## 六、打光基调与色彩心理

### 打光基调

- 高调打光（明亮均匀少阴影）→ 希望、安全、乐观
- 低调打光（高对比、戏剧性阴影）→ 神秘、危险、悬念
- 背光/轮廓光 → 主体从背景分离，三维感
- 单一光源 → 戏剧性、形式感
- 多色光源（冷暖对比）→ 复杂情绪、动态场景
- 场景光源（霓虹/火焰/灯具入画）→ 真实感、地点可信度

### 色彩心理

```
金色/琥珀 → 温暖、怀旧、浪漫        冷蓝 → 孤立、科幻、不安
红/橙 → 紧张、危险、激情            绿色 → 不自然、病态、科幻
低饱和褪色 → 绝望、疲惫、年代感      高饱和 → 能量、兴奋、戏剧性
黑白单色 → 永恒、经典、形式感
```

电商配色另有转化语义：红=紧迫热卖，蓝=信任安全，金=高端奢华，黑=高端权力（黑背景让产品发光），白=干净极简。

## 七、运动节奏（时序设计）

- 实时：默认
- 慢动作：强调细节与情绪（"放慢至 1/6"）
- 延时：云/人流/生长（生长类带货玩法核心手法）
- 速度渐变（speed-ramp）：慢→快或快→慢，**广告片动感的关键来源**
- 定格：强调、收尾、卡点

运动形态的潜台词：线性=目的与决心，抛物线=自然优雅，急促角动=冲击紧张，缓冲运动=重量与权力。

## 八、2 秒钩子框架（开场结构设计）

源 4 全 15 个 skill 共用的开场公式，钩子=**一个强有力的视觉承诺 + 一个独特的美学声明**，前 2 秒必须交代清三件事：视觉类型（这是什么画面）、情感基调（感觉如何）、运动承诺（接下来会发生什么）。

```
0-1秒：视觉冲击 + 打光特征
1-2秒：运镜启动 + 深度线索
```

例（科幻史诗）：0-1s 宏大未来城市天际线，极致景深，金色日落 → 1-2s 吊臂升起揭示城市规模，光线扫过摩天楼。电商变体（产品跌落、纹理 ASMR、前后对比、开箱揭示等 12 种钩子模式）见 `knowledge/tvc-ad-templates.md` 与 `knowledge/hooks/opening-hooks.md`。
