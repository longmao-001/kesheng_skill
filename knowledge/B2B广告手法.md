# B2B 广告手法

> 国际精密仪器厂商的公开打法：教育先行、证据上屏、按客户的指标语言说话。

- **痛点先行**：最强 B2B 视频不以产品功能开场，而以尖锐定义的问题开场；铁律 one message / one audience / one CTA
- **证据上屏**：实测曲线、对数坐标对比图、专利号清单直接当内容（Hamamatsu/Energetiq 产品页实测手法）
- **指标翻译**：用客户的语言（wph/uptime/CoO/recipe matching）而不是自家参数说话；按应用垂直分页/分段
- **误区澄清做内容**：把销售中最常见误解直接做成 FAQ 内容（"LDLS 是激光产品吗？不是。"）
- **漏斗配形式**：认知期 <60s explainer，考虑期 2-4min demo，评估期 webinar/案例
- **需求→实测对照**：左列"检测需要什么"，右列"我们实测多少"，配对高亮——规格书受众的最优格式
- **应用段手法：机台工作感+屏内证据**——应用端机台 CAD/实拍叠加工作动感（光路流动、载物台扫描），镜头推向显示屏，屏内放测量结果图+实时数据波动（全后期矢量）；"在工作中"比任何形容词都有说服力
- 权威正文：项目调研（KLA/Hamamatsu/Energetiq/Coherent 公开页观察，来源在 kb [[半导体量测的光源需求]]）
- 项目验证：PHO-SC-4 广告 R2（2026-08）
