# 按秒时间轴断句 · 范例（Seedance 2.5 统一版：玦芯 PHO-SC-4 英雄镜）

> 总原则：多动作/长动态(>6s)/变速/光效变化的镜头必须**按秒分拍**（一段一动作，结尾贯穿约束收口）。
> **统一采用 Seedance 2.5 写法**：整数秒时间戳（0-2秒/2-5秒…必须连续），单镜只指定 1 种运镜，画幅用 adaptive（编辑/延长/首尾帧任务必须）。
> **⚠️ 最大时长**：2.5 单次生成 4-30s（可多轮延长）——**时间轴总长 ≤30s**；超 30s 走"长镜头分段生成"（分段+首尾帧衔接/参考包+延长）。2.0 仅旧后端兼容（单次上限 15s，不响应秒以下精调）。
> 官方推荐结构：素材指代 → 一句话概述 → 分镜逐段 → 贯穿性约束收口。

```
【风格】冷峻工业精密科技风，深空炭黑背景（物理层 #282828，数据层/氛围压向 #16181D），
白铝拉丝金属机身（官方冷中性 #D6D9DD），冷白顶光约6500K略偏蓝；
冷蓝单色精密点缀（#2E6BE6 仅数据层/图表层，禁落产品本体），
出光口暗葡萄紫（#5F3448 仅做画面内光源记忆点），浅景深隔离主体，
慢稳准、克制工业可信，8K超精细；禁彩色渐变、禁霓虹、禁暖调、禁大饱和色光洗墙。
一句话概述：两件式白铝产品（左控制器、右灯室）英雄镜，冷白光带环绕镜头扫过拉丝机体，
冷峻工业精密科技风，深空炭黑底。

【时间轴】
0-2秒   [中景定格] 两件并排居中，产品静止，冷白顶光金属反光定妆感；冷白光带在控制器边缘亮起。
2-5秒   [环绕+上升·中速渐快] 镜头绕两件中线 360°环绕并同步上升转入侧面；光带顺拉丝铝壳划过，
        高光随角度流动——扫过环形 logo 与散热栅格；产品本体保持静止，仅镜头与光带运动。
5-8秒   [光效转折·渐减速] 环绕至灯室一侧；光带划过金属接口与蓝色水冷软管；出光窗亮起暗葡萄紫
        微光（全片唯一画面内光源记忆点）；镜头由高速渐转慢，开始收稳。
8-10秒  [收稳定格] 光带滑出画面右缘；镜头缓收，稳定在开场双件并排构图
        （尾帧≈首帧，便于全场衔接/参考包一致性）；冷色轮廓光边缘分离。

【声音】无对白；精密仪器低频环境底 + 光带擦过金属的细微声；配乐由声音设计师方案决定。

【参考】@图片1（官方渲染：两件式白铝壳——左控制器、右灯室）= 主体唯一外观锚定；
产品外观、两件相对位置与部件（环形 logo、散热栅格、旋钮、出光窗、金属接口、蓝色水冷软管）
全程与 @图片1 一致，不得走样。

【贯穿约束】全片无人物；光谱曲线、数字、文字、水印一律后期叠加，不在此生成；
产品本体始终静止，禁止形变。
```

## 关键注意（2.5 统一版）

| 项 | 规则 |
|---|---|
| 时间轴 | 整数秒时间戳，**必须连续**（0-2/2-5/5-8/8-10）；单镜只指定 1 种运镜 |
| **最大时长** | 单次生成 **4-30s**（可多轮延长）；时间轴总长 **≤30s**；超长→长镜头分段生成（分段+首尾帧衔接/参考包+延长） |
| 参考素材 | 50 个（30图+10视频+10音频）含纯音频；写清每张取什么 |
| 画幅 | 6 档 + `adaptive`（编辑/延长/首尾帧任务必须 adaptive） |
| 旧后端 2.0 | 仅兼容说明：单次 ≤15s，不响应秒以下精调（不使用） |

## 检查清单（自检）

- [ ] 分拍节点=动作触发/变速/光效转折；段内一动作；整数秒连续
- [ ] 时间轴总长 ≤30s（超长已按分段+延长处理）
- [ ] 首尾段有锚定构图（首帧/尾帧≈开场/收稳）
- [ ] 结尾贯穿约束收口（外观锚定/禁项）
- [ ] 官方结构：素材指代→一句话概述→分镜逐段→贯穿约束收口
