# 图生成 Prompt 公式总集（Image-Generation Prompt Formulas）

> 用途：AI 图片/视频生成的通用 prompt 公式（产品/设备/科技类优先）。**写产品镜头 prompt 时选一张公式套用**。
> 配合：`templates/product-prompt-formula.md`（科生产品公式：参数→镜头→灯光→主体→场景构图→动效→文字→约束）、`knowledge/seedance-template-library.md`（分镜模板）、`playbooks/platform-prompts.md`（各平台公式）。
> 来源：2026 调研（Seedream 5.0/5.0 Pro/5.0 Lite、GPT Image 2、即梦 Seedream 4.5、Picsart/GitHub craft 指南）。
> 归档：工艺库（knowledge/）——图生成技法为创作工艺，归本库；可被统一图谱（packs/prompt-kg）引用。

## 〇、三套主流公式（选一套）

### A. Seedream 5.0 / 5.0 Pro / 5.0 Lite 公式（摄影级，最贴产品片）
```
【场景】+【镜头】(焦段/景别/机位/光圈/景深焦点) +【主体/细节】(材质到色号级) +【约束】(无变形/一致性)
```
- **摄影级参数写死**：`85mm f/2.8 微距，快门 1/125，ISO 100，浅景深只留一条清晰焦面；冷白顶光 6500K 主光 + 45° 冷蓝轮廓光 rim + 暗部补 1 挡柔光`。
- **材质到色号级**：`银白拉丝铝（发丝纹≈0.1mm）哑光阳极氧化；石英/蓝宝石出光窗（微反光+边缘冷白辉光）`。
- **中文文字直出**：5.0 中文字/排版强，可直出型号/标签/海报字。
- **参考图编辑**（5.0 Pro 图生图）：`以 @参考图 为基准，保持[主体/材质]不变，只改[某处]`——主体还原度最高。
- **一致性双锚**：产品/人物开头说一遍、结尾再说一遍。

### B. GPT Image 2（Image2）公式（指令遵循/中文小字/参考编辑最强）
```
场景 → 主体 → 细节 → 约束（定序，别写成长句）
```
- **自然语言 + 明确编辑动词**：懂"改/换成/只重画第N格/保持XX不变"。
- **参考图改图极强**：`以 @参考图 为基准，保持[产品形态/材质/logo]不变，只改[布光/构图/加字]`。
- **中文小字 ≥2K 清晰**：适合铭牌/标题/数据标签直出。
- **单格重画**：宫格生成后 `只重画第 N 格，改成…，其余格子保持不变`，不重抽整图。
- **比例自主**：16:9 / 2K / 单格提取成独立 4K。

### C. 即梦 Seedream 4.5 公式（多图一致性/宫格最强）
- **多图一致性**（官方实测 9 宫格角色五官近乎零偏差）：适合宫格分镜/产品多角度。
- 配合宫格技法（`playbooks/storyboard-grid.md`）：一条 prompt 出 3×3，整图喂多镜原生，或切格当首帧。

## 一、通用产品公式（最重要，套这个就八九不离十）
```
【参数】画幅｜分辨率｜风格
【镜头】焦段｜景别｜机位｜光圈｜景深焦点
【灯光】主光(色温/方向)｜轮廓光｜补光｜特殊光(hex)
【主体】产品名｜材质到位｜部位位置
【场景/构图】背景｜构图(对称/三分法/对角线/满幅/留白比例)
【动效】运镜+画面内部运动+剪辑节奏
【文字】AI 直出字(写死+位置)｜或"后期"
【强制约束】无人物｜无变形无穿模｜无霓虹/暖调/彩色渐变｜数据核对=原文｜一致性
```
详见 `templates/product-prompt-formula.md`。

## 二、参考图用法（取哪部分 → 放哪位置）
```
【参考锁定】@图N：取其【具体部位/特征】→ 放在本图【哪个区域/主体】
```
- 产品镜头**必须参考图锚定**（避免 AI 凭空改形）；有真实素材不用文生图硬猜。
- 图片节点参考上限 **3 张/次**（选该镜最需要的 3 张）；逐镜视频节点可更丰富（多用）。
- **禁入镜/禁作参考喂模型**：水印图、竞品图、团队合影（人物）、带商标的原理示意图（只作内容参考）。

---

## 三、两条铁律（套公式必守）
1. **产品展示＝干净 / 功能展示＝复杂**：外观/身份/材质/原理=留白多、单一主体；功能/性能/应用=加机制/结果/环境细节。
2. **绝不改造设备真实造型**：以参考图锁定真实几何/部件/logo/材质（`保持真实造型：位置形态同 @参考图，完全不变；禁任何造型改动/新增部件/歪曲比例/掉色`）。只动布光/机位/背景/构图/加字。

## 四、校验清单（交 prompt 前）
- [ ] 选对公式（Seedream 5.0 摄影级 / GPT Image 2 参考编辑 / 即梦 4.5 多图一致性）
- [ ] 八段齐全（参数/镜头/灯光/主体/场景构图/动效/文字/约束）
- [ ] 产品=干净 / 功能=复杂
- [ ] 真实造型锁死（@参考图不变）
- [ ] 参考图"取哪部分→放哪位置"；水印/竞品/团队照/商标原理图已排除
- [ ] 文字：AI 直出写好+位置；精确数据（±0.2%/10000h/170-2500nm 等）生成后核对=手册原文
- [ ] 无抽象词（无"高级感/震撼/电影感"）｜单镜≤2 运镜+变速（动感三来源）
- [ ] 科学红线（发光点=0.1mm 椭圆非大光球/出光=白光非激光束/数据核对/无人物）
