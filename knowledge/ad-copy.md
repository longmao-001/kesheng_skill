# 产品广告文案法则（B2B 科技/工业产品片）

> 编剧写产品广告前必读。科普片讲"这是什么"，产品广告讲"**这能解决你什么问题**"。

## 一、痛点链公式（叙事脊柱）

每个亮点必须能串成这条链，串不上就删：

```
受众的任务/痛点 → 对产品/指标的需求 → 我们的亮点（数字） → 证据（图表/实测）
```

- ❌ 错误："我们的光源亮度 >75 mW/(mm²·sr·nm)"（所以呢？）
- ✅ 正确："套刻误差每缩小一纳米，对光的要求就苛刻一分。所以光源必须又宽又稳——PHO-SC-4：170–2500nm，±0.2%。"

## 一·二、工业产品的标准叙事型：问题 → 方案 → 证据

B2B 工业产品几乎全部是"针对/面对/察觉行业问题 → 给予解决方案"的类型。标准段式：

```
针对【行业/应用场景】的【具体需求】，【产品】实现【指标】，【实测/认证证据】。
```

- 例："针对半导体量测的全波段需求，PHO-SC-4 实现 170 至 2500 纳米连续覆盖……经十二小时连续实测。"
- 一个需求一段，全片 3-5 段排开；段与段之间不需要过渡修辞
- "需求"必须来自受众真实工况（规格书/招标书/检测报告里的语言），不许自造痛点
- 收口句落在产品价值主张上，用甲方自己的话（如"一个更有效的光源，一个更好的解决方案"）；不堆形容词、不限定场景、不要"欢迎索取/欢迎预约"式客套。收口的"大"靠克制，不靠修辞
- 注意：禁用"远高于行业水平"等绝对化/对比表述（广告法风险+零对比约束）；领先性用可溯源实测值或第三方检测表述

## 二、大字文案规范（广告片必须有文案层，口播稿≠文案）

- **主 slogan**：1 句，10 字左右，能独立成立。公式：数字奇观 + 产品本体（"一万度的光，钉在 0.1 毫米上"）
- **分段大字**：每段 1 句，动词开头优先（"为量测设备，造一束好光"）
- **数据字卡**：数值+单位+条件+出处角标（">75 mW/(mm²·sr·nm) @500nm｜数据来源：产品手册"）
- **落版**：品牌 + 产品全名 + CTA（索取什么、怎么联系）
- 字体规范：无衬线（思源黑体级），亮底深字/暗底白字微发光，品牌色只做点缀

## 三、语气与红线

- B2B 工程师受众：冷静、具体、可验证；拒绝宏大空洞（"重新定义""引领未来"=自杀）
- 不做对比性宣传（不提竞品名、不做踩一捧一）
- 每个数字有出处；没有出处的数字宁可不写
- **口播稿是"听"的文稿**：禁用冒号列举、"备索"式书面语等文档逻辑；定稿前必须朗读测试——念不顺的句子就是病句
- 务实派客户追加：零修辞（无对仗/押韵/比喻/抖机灵），工整修辞会触发"这是广告词"的警觉

## 四、收尾 CTA 公式

情感收口句 + 具体动作 + 利益承诺：
"光的表现，用数据说话。——索取完整规格书与实测报告，预约样机演示。"
